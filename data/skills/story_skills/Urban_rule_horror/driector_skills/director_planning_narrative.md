# 叙事手法 · 都市规则怪谈 · 通用叙事规划

## 一、类型核心机制与创作总则

### 1. 规则怪谈的核心机制
- **冰冷秩序下的因果契约** — 规则怪谈绝非普通闹鬼，而是一种“以文字规则为载体的强制性因果契约”。表面上是日常的《顾客须知》《员工守则》《乘车指南》《入住协议》，实则是诱导活人踏入陷阱、掠夺生机与存在感的闭环。
- **真假规则的逻辑死锁** — 核心谜题通常包含“假规则诱导”或“闭环死循环”（例如不可违逆的强制条款与无限触发条件）。破局点永远建立在**常识洞察、合同法理逻辑或发现规则漏洞**之上。
- **存在的渐进式抹杀** — 触犯规则的代价往往是“被世界遗忘”与“身份同化”——工位名牌模糊、档案变白纸、身体逐渐半透明、亲友记忆剥落，制造深层的心理窒息感。

### 2. 荒诞反差幽默与社畜共鸣
- **极度日常 vs 极度惊悚** — 用现代打工人最真实的痛点（动态溢价、算计性价比、防消费套路、防背锅、拿劳动法维权）对冲诡异阴森的氛围。主角越是在生死边缘一本正经地贫嘴、算账、拆霸王条款，荒诞感和喜剧张力就越强。
- **三人组功能互补模型**：
  - **解谜/吐槽担当（纪衍型）**：极度抠门、法务/合同严谨思维、贪生怕死但关键时刻讲义气。
  - **灵感/感应担当（桃夭型）**：嗅觉敏锐、不谙世事、凭动物/通灵直觉辨认死物与真实因果。
  - **现实/武力担当（苏晓型）**：刑侦实战经验、敏锐洞察现实线索、以客观事实破除幻象。

### 3. 壳核分离与真情救赎
- **恶鬼的壳与核** — 恶鬼的“残暴行为与索命规则”是壳（由执念与偏执扭曲而成），生前“未了的心愿、被辜负的善意或天大的误会”是核。
- **化解执念而非暴力诛杀** — 故事的终极高潮不是法术对轰，而是还原被掩盖的客观真相，用“不可伪造的真实善意与记忆”破除心魔，让执念者释怀往生。

## 二、通用四幕式叙事节奏规划

```
【第一幕：日常切入与违和伏笔】（占比约 15%-20%）
  • 现代都市深夜日常切入（暴雨夜、末班车、加班归途、老旧街区、电梯公寓）
  • 主角的社畜自嘲、精打细算或日常吐槽（快速建立市井烟火气与好感度）
  • 隐蔽埋入异常伏笔（违和的冷清、静止的笑容、隐秘张贴的冰冷规则纸条）
       ↓
【第二幕：异常撕裂与规则陷阱】（占比约 25%-30%）
  • 突发外力打破平静，幻象瞬间褪色，露出破败/死亡的现场真相
  • 受害者已被规则锁死，身陷“机械重复”或“存在感抹杀”的倒计时危机
  • 异常实体登场施压，逼迫主角遵守致命规则（如诱导消费、诱导应答、强买强卖）
       ↓
【第三幕：逻辑拆解与绝境破局】（占比约 30%-35%）
  • 深入推敲规则文本，找出真假规则的矛盾点，或利用合同/常理漏洞化解杀局
  • 关键物理动作打断致命循环（击落契约媒介、阻止违规行为）
  • 实体被激怒导致全场异化升级（封门锁死、气温暴跌、恶灵显露狰狞面目）
       ↓
【第四幕：真情引路与主线余韵】（占比约 15%-20%）
  • 抛出决定性的现实调查铁证，神魂通灵/传递未曾褪色的真实记忆
  • 执念内核被彻底照亮，误会冰释，恶灵在市井温情中释怀消散
  • 规则载体被神秘冷火（黑火）远程自燃销毁，遗留带朱砂印记的残账片，推动宏大主线
```

## 四、镜头运动与构图原则

1. **喜剧段落的冷面反差**：主角进行逻辑吐槽、算账维权时，采用**冷静固定机位**或**猝不及防的面部大特写**，捕捉微表情，放大荒诞喜感。
2. **规则线索的引导特写**：对场景中的“告示牌、手写纸条、关键凭据、关键遗留物”必须给足清晰的大特写镜头，让观众拥有参与解谜的“沉浸视角”。
3. **惊悚降临的失衡构图**：异常降临时采用**大倾斜构图（Dutch Angle）、广角透视畸变、大面积阴影压顶**，传递心理上的失衡与无助。
4. **情感高潮的流动长镜**：在真情回忆与执念消解阶段，多用**环绕慢摇 + 浅景深**，使冷酷破败的背景虚化，将光芒汇聚在角色的眼神交流与情感释放上。
