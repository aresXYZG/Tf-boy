# 都市规则怪谈（反差幽默与执念解谜）· 导演叙事手法技能包

## 简介

本技能包专为 **都市规则怪谈 / 悬疑解密 / 职场社畜反差幽默 / 执念救赎** 题材量身定制。它完美融合了：
1. **规则怪谈核心机制**（伪装成日常告示的致命契约、真假规则博弈、死循环因果锁、存在抹杀危机）；
2. **社畜法务冷幽默与市井反差**（小人物防背锅/防消费刺客本能、急推吐槽反应、荒诞与惊悚交织）；
3. **悬疑刑侦与神魂引路**（线索伏笔、反转揭示、真实记忆引渡化解恶鬼执念）；
4. **宏观轮回与因果账本**（规则自毁、冷黑火、账目清结主线）。

## 核心理念

- **冰冷的契约与善意的扭曲** — 规则怪谈不是无脑暴戾的怪物追杀，而是死者生前未了的执念被冷酷秩序扭曲成了“必须遵守的致命守则”。
- **荒诞喜剧反衬真实惊悚** — 最强的恐惧往往来自极度日常的荒谬反差（社畜还在算6块钱麻辣烫账目，对面老板娘已经变绿了）。用角色的嘴碎与接地气，让惊悚降临时张力拉满。
- **壳核分离与真情解脱** — 规则是“壳”（诱人入局的陷阱），执念是“核”（爱、愧疚、守护、不甘）。破局不仅要靠法理逻辑找漏洞打破死循环，更要靠不可伪造的真实记忆让恶鬼释怀往生。
- **信息遮蔽与视觉线索** — 每一个道具（白雏菊、黄纸条、堆满肉丸的碗）都是破局的关键法门。
