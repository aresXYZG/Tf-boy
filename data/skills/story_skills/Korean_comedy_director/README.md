# 搞笑韩剧 · 导演叙事手法技能包
## 简介
本技能包为 **搞笑韩剧** 类型故事提供一套完整的导演叙事手法参考，涵盖从宏观叙事规划到微观分镜执行的全流程指导。适用于任何视觉风格。
## 核心理念
- **K-喜剧** — 韩式搞笑的三板斧：夸张肢体、表情包式反应、BGM 反转。掌握这三样，就掌握了韩式喜感
- **欢喜冤家** — 搞笑韩剧的核心是"从斗嘴到心动"：碰撞越猛，喜感越强；心动越深，反差越大
- **社死与打脸** — 观众最爱看"主角受苦"与"装X失败"：社死拉满尴尬，打脸拉满快感
- **浪漫+搞笑双线** — 搞笑为浪漫蓄力，浪漫让搞笑有归宿。斗嘴越凶，心动越明显
- **家族群像** — 韩剧独有的家族戏是喜剧的"群像发动机"，个人搞笑在群像中被放大十倍

## 技能文件说明
### 1. 叙事规划手法 (`director_planning_narrative.md`)
导演在 **叙事规划阶段** 使用的技法参考，定义搞笑韩剧在主题立意、笑点节奏、韩式喜感设计、场景喜感与声音方向上的整体规划方法。
| 章节 | 内容概要 |
|---|---|
| 主题立意与喜剧内核 | 欢喜冤家引擎、K-肢体喜剧、表情包式反应、社死与打脸、家族群像 |
| 叙事结构与笑点节奏 | 铺垫→抖包袱循环、三遍法则、误会链、斗嘴对切、浪漫搞笑交替 |
| 分场景喜感设计 | 餐桌食物戏、社死名场面、家族群像戏、职场社死、典型段落表 |
| 声音与音乐方向 | BGM 反转、OS 内心独白反差、夸张音效、定格音效、突然静默 |
| 构图与景别叙事 | 定格反应镜头、表情包式特写、广角变形、群像全景、景别的喜感时机 |
| 镜头运动与节奏 | 急推定格、韩式慢镜头（心动/灾难）、甩镜揭示、冷静旁观 |
### 2. 分镜表叙事手法 (`director_storyboard_table_narrative.md`)
导演在 **分镜表制作阶段** 使用的技法参考，定义搞笑韩剧在分镜表中的景别策略、运镜节奏、时长把控、笑点分镜设计与转场手法。
| 章节 | 内容概要 |
|---|---|
| 分镜表定位 | 分镜表作为韩式喜剧节奏核心工具的定位说明 |
| 景别选择 | 定格反应景别、表情包特写、群像全景、广角变形 |
| 运镜节奏 | 急推定格、韩式慢镜头、甩镜揭示、跟拍失控 |
| 时长把控 | 铺垫时长、包袱节拍、定格反应时长、社死尴尬留白 |
| 笑点分镜设计 | 铺垫→抖落镜头语言、定格反应分镜、斗嘴对切、社死/打脸分镜 |
| 多人喜剧调度 | 群戏反应链、家族群像调度、吃瓜群众围观、旁观者视角 |
| 台词与节奏 | 台词节拍、斗嘴时机、OS 内心独白、沉默的喜感、重复的力量 |
| 转场设计 | 荒谬对比切/硬切笑点/定格转场/BGM 反转转场/反差蒙太奇 |
## 使用方式
本技能包作为导演 AI 的叙事手法参考，在故事创作流程中自动加载，指导：
1. **叙事规划** — 确定韩式喜剧内核、笑点节奏曲线、场景喜感与音效时机
2. **分镜表生成** — 根据叙事规划输出具体的景别、运镜、时长与转场方案
两个文件分工明确、逐层递进，从"为什么这样拍"到"具体怎么拍"形成完整闭环。
