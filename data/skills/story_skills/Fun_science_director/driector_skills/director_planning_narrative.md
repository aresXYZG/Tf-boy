# 叙事手法 · 趣味科普解说 · 技法参考

> 本技法是 `explainer_video` 的**可选风格/叙事参考**，不是跨项目硬规则。科普的第一目标是准确理解；趣味、幽默和视觉奇观只有在降低理解成本或改善节奏时使用。最终执行以项目 `contentFormat`、剧本三阶段和生产覆盖规则为准。

## 一、科普定位与知识内核

- 先用一句话明确：观众要回答什么问题，看完只需记住哪条结论。
- 先判断知识结构，再选择表达方式，不把所有主题都包装成“反常识短视频”。
- 可选结构：
  - **机制解释型**：现象 → 误区 → 问题 → 机制 → 证据/例子 → 结论 → 边界
  - **历史/事件型**：事件 → 背景 → 关键选择 → 因果变化 → 后果 → 争议/误解 → 今天的认知
  - **数据/现象型**：现象 → 数据证据 → 直觉解释 → 机制 → 变量关系 → 限制 → 结论
  - **流程/方法型**：结果 → 步骤 → 瓶颈 → 设计原因 → 结果
  - **谜题/推理型**：规则 → 观察 → 推理 → 信息变化 → 递归/连锁 → 结论
- “反常识”是可选的 Hook 手段，不是知识质量标准；没有反差也可以从真实问题、案例或操作开始。
- 受众默认需要清楚表达，但不要把所有观众简化成只能接受 30 秒和段子的群体。时长按项目配置和内容体量决定。

## 二、VO 语言与证据边界

- VO 先说事实/定义，再用类比、吐槽或拟人帮助理解。
- 专业术语只保留必要部分；第一次出现给最小定义，不为“人话”牺牲准确限定。
- 必须区分：事实、观点、假设、类比、争议和未提供。相关性不能写成因果，可能不能写成一定。
- 每条重要主张最好建立“主张 → 依据 → 能支持到的程度 → 边界”的链条；材料没有证据时明确标记，不自行补研究结果、数据、年份或案例。
- 讲者可以有稳定人设，但人设服务内容，不得压过知识主线；不要求“旁白是唯一主角”，也不要求所有片子使用单一口播。
- 语速、停顿和总时长服从项目配置；本技法中的范围仅作参考，不能覆盖项目设置。
- 开头从一个具体的、当下的现象、事件或问题切入；不用抽象的时代判断或宏大抒情开场（如"在当今…时代""随着…的发展"）。观众需要先看见"这件事"，才听得进"这背后的道理"。
- 疑问句可以作为 VO 的刹车与转向：高密度段落前用问句让观众停半秒准备接收（"为什么会这样？"），复杂概念后用共鸣式问句承接（"听着有点绕对吧，我举个具体的例子"）。只在密度转折点精准投放，不每段都用。

## 三、视觉转译决策

视觉不是 VO 的装饰复读，也不必为了避免幻灯片而强行荒诞化。根据主张选择最能证明或解释它的方式：

| 主张类型 | 优先方式 | 可拍事件示例 |
|---|---|---|
| 可观察现象 | 真实对象/场景 | 同一对象在不同条件下产生可见差异 |
| 因果机制 | 物理过程/结构变化 | 路径改变、结构开合、颗粒碰撞、流体移动 |
| 流程方法 | 连续步骤动作 | 输入依次经过处理并形成输出 |
| 数据关系 | 数量/尺度/时间/空间具象化 | 队列长短变化、柱体升降、时间节点推进 |
| 历史事件 | 有依据的场景重演 | 关键人物在明确处境中作出选择 |
| 抽象关系 | 有边界的类比/空间关系 | 两组对象按规则连接、分离或移动 |
| 微观机制 | 微观模型，必要时有限拟人化 | 概念对象发生材料支持的物理变化 |

- 每个视觉方案都要回答：“正在发生什么？”以及“它证明/解释/对比什么？”
- 拟人化是可选项。使用时锁定概念形象、道具和核心动作，并明确它只是模型/类比，不是事实本身。
- 视觉梗是可选的节奏工具，不得替代机制、证据和边界。连续高密度内容后可安排不新增知识的缓冲，不固定每 30 秒一个梗。
- 数据、公式和精确文字若必须出现，应交给可读图形或后期文字层；不要用不可读的小字堆画面。

## 四、镜头和声音参考

- 按认知转折、证据落点和动作变化切镜，不要求每句 VO 一镜，也不要求每层知识必须换景别。
- 一镜一个主要视觉事件；同一事件可通过动作进展或反应镜延续，不靠无意义换角度。
- 画面和 VO 可以互补，但不能互相矛盾；声音只服务可见动作和语义节奏。
- 具体景别、运镜、Track、资产 ID、无音乐/无光影等制作限制，以通用生产技能和当前形态 overlay 为准。

## 五、快速规划模板

```markdown
## 科普叙事规划
- 核心问题：
- 核心结论：
- 主知识结构：
- 证据/依据类型：
- 结论边界：
- 主要视觉转译：
- 是否使用类比/拟人化/视觉梗：使用/不使用 + 理由
- 认知递进：原认知 → 新证据 → 新认知 → 下一问
```

## 六、禁止事项

- 不把 Hook、常识粉碎、拟人化、脑洞推演、金句升华当成固定五步。
- 不把类比、拟人化画面或视觉奇观冒充证据。
- 不为制造反差编造数据、实验、历史细节、医学结论或人物行为。
- 不以“受众不懂”为理由删除必要限定和边界。
- 不强制固定主角团、游客视角、概念工具人或统一视觉套路。
