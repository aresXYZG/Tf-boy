# 分镜表叙事手法 · 趣味科普解说 · 技法参考

> 本技法面向 `explainer_video` 的 VO/知识内容分镜设计，是可选参考，不替代通用分镜表和项目形态覆盖规则。通用生产契约优先：真实资产、台词/VO、Track、动作连续、XML、音效和禁用项不得被本技法突破。

## 一、分镜定位

- VO 是主要信息时间轴，但画面不必逐句复读；画面应让观众看见现象、过程、证据形态、变量关系或结论回收。
- 每条分镜对应一个主张或认知段，并标出主要视觉功能：`展示现象 / 解释机制 / 呈现证据 / 对比 / 提示边界 / 回收结论 / 缓冲`。
- 一镜一个主要视觉事件。允许一条 VO 跨镜头延续，但每个镜头要有动作进展、信息变化或明确的注意力功能。
- 无角色内容完全成立。不要为了“有戏”强行添加固定主角、游客、拟人角色或群体表演。

## 二、镜头切分

- 按认知转折、证据落点、变量变化、语义停顿和动作进展切镜，不平均切词。
- 一条长 VO 超过通用分镜表规定时，按语义拆镜；可使用对象变化、流程步骤、反应或尺度对比承接声音。
- 连续高信息镜头后，可以安排不新增知识的视觉缓冲；缓冲不固定时长、不固定每30秒出现，也不要求必须有笑点。
- 关键结论前可留短暂视觉停顿，但必须服从项目总时长、Track 和 VO 连续性。
- 镜头运动服务视线与节奏，不把“推近”“拉远”本身当作知识证明。

## 三、视觉转译选择

| 内容 | 首选方式 | 可拍事件 |
|---|---|---|
| 可观察现象 | 真实对象/场景 | 同一对象在两个条件下产生可见差异 |
| 因果机制 | 物理过程/结构变化 | 路径改变、颗粒碰撞、结构开合、流体移动 |
| 流程方法 | 连续步骤/输入输出 | 输入依次经过处理并形成结果 |
| 微观机制 | 微观模型 | 细胞、分子或颗粒发生材料支持的变化 |
| 数据关系 | 数量/尺度/时间/空间 | 队列长短、物体比例、时间节点、位置关系变化 |
| 历史事件 | 有依据的场景重演 | 人物在明确处境中行动并产生后果 |
| 抽象关系 | 有边界的类比/符号关系 | 两组对象按规则连接、分离或移动 |
| 认知缓冲 | 对象停顿/整理/环境动作 | 翻页、归位、清空台面，不新增知识 |

- 拟人化是可选工具，只在明显降低理解成本时使用。使用时锁定概念形象、道具和核心动作，并标注“模型/类比”，不能冒充真实机制。
- 类比必须与真实原理分开；画面不得暗示类比中不存在的因果。
- 数据和精确文字需清晰可读；不要用密集小字或抽象公式作为唯一画面信息。

## 四、VO、画面、声音分工

- VO：定义概念、讲清因果、说明证据、保留条件和边界、回收结论。
- 画面：呈现对象、动作、变化、空间关系和证据形态；画面只能支持它实际呈现的程度。
- 音效：只服务可见动作和语义节拍，如翻页、计数、碰撞、装配、脚步；声音不能单独承担知识证据。
- 不使用音乐/配乐推动理解；其他声音边界以通用分镜表为准。

## 五、不同知识结构的镜头骨架

- 机制解释：现象 → 机制中的关键变化 → 证据/例子 → 条件/边界 → 结论。
- 历史/事件：当时处境 → 关键选择 → 行动后果 → 后世误解/争议 → 今天的认知。
- 数据/现象：现象对比 → 数据形态 → 排除直觉解释 → 变量关系 → 限制 → 结论。
- 流程/方法：最终结果 → 步骤动作 → 瓶颈 → 设计原因 → 输出结果。
- 谜题/推理：规则 → 可见观察 → 第一次推理 → 信息变化 → 连锁推理 → 结论。

以上是选择参考，不是强制顺序；以当前剧本和导演规划为准。

## 六、AI 生成适配红线

- 画面描述必须写具体主体、位置、动作/状态变化和空间，不写“体现深层含义”“营造高级感”等空话。
- 不新增材料未提供的数字、年份、实验结果、人物行为、道具或剧情。
- 不把画面功能写成“震撼”“好看”“有氛围”；要写它证明/解释/对比什么。
- 不用静态角色站立图承载整段机制；若使用静态对象，必须有结构、数量、位置、文字或其他明确的信息变化。
- 资产只引用工作区真实名称和 ID；不在本阶段创建资产。

## 七、输出兼容

本技法不修改通用分镜表表头。若当前表格没有独立的“视觉功能”或“对应主张”列，将短标签写入画面描述或备注，例如：

```text
[C1][功能：解释机制] 透明容器中的液体沿窄管上升，液面高度差正在形成；让观众看见……
```

保持现有场头、组、镜表、`<storyboardTable>` 和面板写入契约不变。
