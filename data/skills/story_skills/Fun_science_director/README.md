# 趣味科普解说 · 导演叙事手法技能包
## 简介
本技能包为 **趣味科普解说 / 知识短视频（旁白口播驱动）** 提供一套完整的导演叙事手法参考，覆盖从选题立意、VO 语言人格、认知递进节奏到 AI 分镜画面执行的全程指导。适用于任何视觉风格。

## 核心差异
- **解说 ≠ 传统剧情剧** — 本形态以 VO（旁白）为知识主轴，但允许固定主角团、本期知识角色和角色资产参与画面；不把科普硬套成传统对白剧。
- **角色资产可复用** — 固定主角可在每个谜题中以游客、观察者、提问者或实验参与者身份出现，沿用同一资产；红眼睛居民、蓝眼睛居民等本期知识角色按故事需要引用或新建，不覆盖固定主角基础卡。
- **耳听逻辑，眼见趣味** — VO 负责把原理讲通，画面负责把抽象变好玩。解说词越严谨，画面越可以荒诞。
- **AI 原生适配** — 所有画面语言必须可直接由 AI 绘图/视频模型生成：具体名词、动态物体、夸张表情，杜绝抽象哲学词与静态幻灯片。
- **单集完整闭环** — 一集一个知识点讲透，黄金 Hook 开场、冷幽默收尾，不做分集付费结构。

## 技能文件说明
### 1. 叙事规划手法 (`director_planning_narrative.md`)
导演在 **规划阶段** 使用的技法参考，定义趣味科普解说在选题立意、VO 语言人格、认知递进节奏、画面气质与声音方向上的整体规划方法。

| 章节 | 内容概要 |
|---|---|
| 解说定位与知识内核 | 单集单点、反直觉选题、受众好奇心挖掘 |
| VO 语言人格 | 讲者人设、语速口径、白话翻译法则、冷幽默金句 |
| 认知递进与信息节奏 | 黄金 Hook→常识粉碎→机制分层→脑洞高潮→收尾的信息峰谷 |
| 画面气质与视觉语言 | B-Roll 互补、概念拟人化、Visual Gag、抽象具象化 |
| 声音设计方向 | VO 主导、拟音段子、停顿留白、BGM 边界 |
| 镜头与运镜叙事 | 面向 AI 视频的动态语言、转场与节奏空镜 |

### 2. 分镜表叙事手法 (`director_storyboard_table_narrative.md`)
导演在 **分镜表制作阶段** 使用的技法参考，定义解说态分镜表的镜头划分、音画节拍、画面构成与 AI 生成适配手法。

| 章节 | 内容概要 |
|---|---|
| 分镜表定位 | VO 为轴：一段解说 = 一组画面；允许固定主角团和本期知识角色参与，不套用传统对白剧逻辑 |
| 镜头划分规则 | 3-8 秒/镜、按 VO 语义停顿切镜、画面随解说词切换 |
| 画面-声音节拍 | 解说严谨时画面荒诞、视觉缓冲、声画先后关系 |
| 景别与画面构成 | 拟人角色、实体隐喻、微观/宏观奇观、图解可视化 |
| 运镜与动态 | 面向 AI 模型的推拉摇移与动态质感设计 |
| 转场设计 | 相似性转场、动作承接、音效转场、节奏空镜 |
| AI 生成红线 | 禁止静态幻灯片、禁止抽象哲学词、每镜必须有动态事件 |

## 使用方式
本技能包作为导演 AI 的叙事手法参考，在科普解说类项目制作流程中自动加载，指导：
1. **导演规划** — 确定解说的知识内核、VO 人格、五步认知节奏与视听互补策略
2. **分镜表生成** — 依据解说词切分 3-8 秒镜头，输出可直接喂给 AI 视频模型的画面与运镜方案

两个文件分工明确、逐层递进，从"为什么这样讲"到"具体怎么拍"形成完整闭环。
