# 趣味科普解说 · 导演叙事手法技能包

## 简介

本技能包为 `explainer_video` 提供可选的科普叙事与分镜参考，覆盖选题、知识结构、VO 语言、证据边界、视觉转译和 AI 生成适配。它不是通用生产硬规则，也不要求每期采用同一种趣味风格。

## 核心原则

- **知识先于形式**：先明确核心问题、主张、依据和边界，再选择 Hook、类比、拟人化或视觉梗。
- **结构服从内容**：可选择机制解释、历史/事件、数据/现象、流程/方法、谜题/推理等结构，不强制五步法。
- **VO 与画面分工**：VO 负责定义、因果、证据、限定和结论；画面负责现象、过程、关系、尺度、时间变化或证据形态。
- **视觉功能明确**：每个主要画面都说明它在展示现象、解释机制、呈现证据、对比、提示边界、回收结论或缓冲中的哪一项。
- **拟人化可选**：只有在明显降低理解成本时才使用；必须和真实原理、类比边界分开。
- **AI 原生但不牺牲内容**：把抽象内容落实为可拍的对象和动作，不用生成难度为理由删除关键因果、证据或限制。
- **资产和声音服从生产契约**：角色是可选的；资产只引用真实数据，音效只服务可见事件，具体禁用项以通用生产技能和项目配置为准。

## 文件说明

### 1. `director_planning_narrative.md`

用于规划阶段的可选叙事参考：

- 核心问题与结论
- 五类知识结构选择
- 主张—依据—边界
- VO 语言与讲者人设
- 类比、拟人化和视觉梗的适用条件
- 视觉转译方式选择
- 认知递进和节奏缓冲

### 2. `director_storyboard_table_narrative.md`

用于分镜表阶段的可选执行参考：

- VO、主张、证据和镜头功能绑定
- 按认知转折、动作和证据落点切镜
- 真实对象、物理过程、流程、尺度、时间和空间关系的视觉化
- 无角色科普和有限拟人化的处理
- 画面、声音、资产与 AI 生成边界
- 与现有 `<storyboardTable>` 表头和 Track 契约兼容

## 使用方式

本技能包只作为风格/叙事参考。实际执行优先级为：

1. 项目 `contentFormat` 和项目配置
2. `content_formats/<format>/` 对应阶段技能
3. 根目录通用制作契约
4. 本技能包中的可选方法

本技能包中的 Hook、拟人化、角色、视觉梗等手法均为可选参考，不构成默认启用的固定模板；使用与否以能否降低理解成本为准。
