# 分镜表美式超级英雄真人电影约束 · 真人电影风格 · 技法参考

---

## 一、分镜表定位

分镜表是导演将剧本转化为镜头语言的核心工具。以下仅提供美式超级英雄真人电影风格在分镜表层面的约束规范。

---

## 二、光影与氛围

- **同场戏光影统一** — 一场戏内不应出现两种以上光影方案，除非有明确的叙事转折（如室内灯光切换→窗外暮色渐深、门打开→爆炸光涌入、能量爆发→光芒充满房间）
- **情绪色盘绑定** — 每场戏至少绑定 1 个情绪场景（英雄登场/战斗冲突/对峙压迫/灾难救援/胜利时刻/内心挣扎/科幻基地），并在镜头组内保持主色+辅色连续性
- **光源角度规范** — 正给镜头光源默认电影级布光或体积光，侧给镜头根据画面需要调整。描述光影时须区分自然光（窗光/阳光/月光）与人造光（灯光/屏幕光/路灯/科技发光/爆炸光）的差异
- **冷暖色调与叙事阶段匹配** — 对峙/压迫/内心挣扎/废弃段落严格使用冷色光（墨蓝 C4 + 墨黑 C9 + 暗影紫 C7），禁用爆炸橙/能量金等暖色调；暖色调（爆炸橙 C8 + 能量金 C5）仅在英雄登场、战斗爆炸、胜利时刻、回忆段落使用
- **光影转场是高级手段** — 从窗外自然光渐变到室内暖灯光 = 日转夜的时间流逝；从明亮办公室到昏暗废弃建筑 = 情绪转折；从正常光到爆炸火光 = 战斗开始。在分镜表中标注光影变化点
- **发光元素是叙事工具** — 能量核心/装置发光/屏幕发光/全息投影/爆炸光的状态变化（亮→灭、正常→诡异、能量充能→释放）可作为叙事信号，在分镜表中标注发光状态变化点
- **高对比是核心** — 明暗反差必须强烈，暗部占比根据情绪调整（英雄登场30-40%、战斗40-50%、对峙/内心50-60%、废弃60%+）

## 三、环境动态

- **环境动态增加画面呼吸感** — 灯光闪烁、灰尘飘落、碎片飞散、雨滴滑过玻璃、窗帘轻摆、电线火花、雾气流动、披风飘动、能量光束流动。每 2-3 个镜头至少安排一个有环境动态的镜头，避免画面"死"掉
- **真人电影环境元素优先** — 环境动态应选用美式超级英雄真人电影世界观内的元素：爆炸火光、烟尘弥漫、碎片飞散、能量光束流动、披风飘动、直升机螺旋桨气流、玻璃碎裂、金属碰撞火花、全息投影波动、城市灯光闪烁，禁止出现古风/奇幻元素（异星场景除外）
- **电影级动态表现** — 环境动态应符合真人电影的表现方式：爆炸的真实物理效果、烟尘的体积感、碎片的重力轨迹、能量光束的光学效果、披风的布料动力学
- **夸张环境动态是史诗工具** — 真人电影常用夸张环境动态强化效果：英雄登场时披风剧烈飘动+体积光+镜头光晕；战斗时爆炸火光+烟尘+碎片飞散；对峙时灯光闪烁+雨幕+雾气。在分镜表中标注此类夸张环境变化

## 四、真人电影人物动作节奏

- **动作要符合情绪** — 英雄登场时动作缓慢/有力/昂首，战斗时动作快速/有力/夸张，日常时动作自然/放松。关键动作（转身、抬手、飞行、战斗、跌倒）标注情绪对应的速度和幅度
- **服饰动态** — 真人电影服饰（披风、外套下摆、围巾、战斗服）的动态是天然的画面资产，可在画面描述中加入衣物随风/随动作的飘动，增加画面的"活"感。披风飘动是英雄登场的标志性元素
- **仪态约束** — 真人电影角色的举止应符合角色性格：英雄沉稳挺拔/反派阴狠含胸/战士力量感/普通人自然。不出现标准化的"优雅克制"仪态
- **表情优先于动作** — 以面部戏剧化表情（愤怒时咬牙、胜利时昂首、坚定时目光如炬）传达情绪，表情幅度必须大但真实。肢体动作为表情和情绪服务
- **预备-动作-反应三段式** — 真人电影动作遵循经典三段式：预备（蓄力/表情变化/肌肉绷紧）→ 动作（执行/速度线/能量聚集）→ 反应（定格/夸张后果/表情变化）。在分镜表中拆解动作时遵循此节奏
- **慢动作的史诗功能** — 升格在真人电影中用于"关键瞬间"：英雄登场、披风飘动、战斗关键一击、爆炸、能量爆发、胜利时刻——慢动作让观众有足够时间感受史诗感，冲击力在慢动作中积蓄
- **英雄动作库** — 经典英雄动作：昂首挺胸、披风飘动、落地震撼、飞行冲刺、能量聚集、重拳出击、盾牌防御、激光眼、拯救市民。英雄动作要有力、夸张、史诗感
- **战斗动作库** — 经典战斗动作：拳击/踢腿/闪避/格挡/投掷/冲刺/跳跃/飞行战斗/能量攻击/武器碰撞。战斗动作要快节奏、有力、配合爆炸和碎片

## 五、运镜禁忌

- **运镜要服务于史诗节奏** — 真人电影运镜可以比其他风格更灵活，但必须服务于史诗感和战斗节奏
- **低角度仰拍 = 英雄登场/高大/压迫** — 英雄登场、高大建筑、反派、力量感，用低角度仰拍强化压迫感和史诗感。这是真人电影英雄场景中最高频的运镜之一
- **缓慢推进 = 悬疑/紧张 buildup** — 悬疑/紧张段落常用缓慢推进，让观众逐渐靠近紧张源，紧张感逐渐积累
- **固定 = 冷静旁观/日常/对峙前的静默** — 日常场景、对话场景、对峙前的静默用固定机位，稳定感。固定后的突然变化 = 最大紧张
- **急推 = 反应放大/情绪爆发/关键瞬间** — 某个角色看到/听到关键信息，快速推向其面部，放大"震惊/愤怒/坚毅"的反应。关键瞬间时急推强化冲击力
- **甩镜 = 信息揭示/战斗转折/爆炸** — 从角色A迅速甩到角色B/爆炸/战斗元素，速度本身带有"等等！那是什么？！"的紧张感
- **跟随 = 追逐/飞行/移动** — 追逐戏、飞行、角色移动，用跟随运镜，保持角色在画面中心，背景流动
- **高角度俯拍 = 渺小/迷失/战场全貌/灾难** — 灾难场景、迷失感、角色渺小感、战场全貌，用高角度俯拍。展示全局混乱和孤独感
- **Dutch角 = 紧张/不安/战斗/怪诞** — 倾斜构图用于紧张场景、不安情绪、战斗、精神异常。真人电影常用Dutch角强化紧张和怪诞感
- **运镜即节奏** — 低角度仰拍 = 英雄登场/高大；缓慢推进 = 悬疑 buildup；固定 = 冷静/日常/静默；急推 = 反应放大/关键瞬间；甩镜 = 信息揭示/转折；跟随 = 追逐/飞行；高角度 = 渺小/全貌；Dutch角 = 紧张/战斗
- **不要过度运镜** — 英雄登场和日常段落保持稳定，战斗和关键瞬间可以灵活运镜。运镜过多会分散对角色和情绪的注意力

## 六、转场设计

- **硬切为主** — 真人电影场景内剪辑节奏偏快，硬切为主，不拖泥带水
- **英雄转场** — 从日常场景硬切到英雄登场，反差本身就是史诗效果。常用：门打开→光芒涌入、披风飘动→慢动作、落地→震撼、飞行→天空
- **战斗转场** — 从对峙静默突然硬切到战斗爆炸，反差本身就是紧张效果。常用：能量聚集→爆发、拳头出击→爆炸、盾牌防御→冲击波
- **光影转场** — 用光影变化做转场：灯光熄灭→全黑→亮起新场景、爆炸光→过曝→新场景、能量爆发→充满画面→新场景
- **匹配剪辑** — 用形状/动作/颜色匹配做转场：盾牌→月亮、眼睛→能量核心、红色→爆炸、飞行→鸟
- **假正经转场** — 用正式/庄重的转场方式（淡入淡出、字幕卡"Meanwhile"、光圈转场）来过渡英雄/战斗内容，反差出戏剧感
- **慢动作转场** — 用慢动作做转场：英雄登场慢动作→正常速度战斗、爆炸慢动作→正常速度 aftermath
- **打破第四面墙** — 角色突然看向镜头/对观众说话的瞬间用正面近景+突然静止，制造"你看到了吧？"的共谋感

## 七、文字画面处理

- **带文字画面必须关键帧先行** — 标题、拟声词、标语、招牌、屏幕显示、全息投影等带文字画面，必须先生成关键帧图片确认文字准确，再用图生视频
- **关键帧作为参考图** — 生成的关键帧图片作为图生视频的参考图传入，文字准确性由关键帧保障
- **视频prompt仍需描述文字** — 视频prompt中仍需描述文字内容和位置，但不依赖视频模型直接生成文字
- **科技屏幕/全息投影是核心元素** — 科幻基地的屏幕显示、全息投影是标志性元素，文字必须清晰可辨，建议先生成关键帧确认文字
- **拟声词** — 战斗用"砰！""轰！""唰！"，英雄登场用"锵！"，拟声词必须先生成关键帧确认文字准确
- **品牌元素后期合成** — Logo/徽标/官方标语等品牌元素建议在视频中预留空位，后期合成（AI直接画品牌物易乱码）
- **画内文字 vs 画外文字** — 故事世界内的道具文字（屏幕显示、招牌、全息投影、标语、海报）属于画内文字，应如实描写；字幕、水印、标题卡、旁白叠字属于画外文字，严禁出现
