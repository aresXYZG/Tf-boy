# 美式超级英雄真人电影约束 · 真人电影风格 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以墨蓝（C4）、墨黑（C9）、中性灰（C10）为基底色，整体色温中性偏冷（5500-6500K），饱和度中高（60-80%），呈现高对比戏剧光影的好莱坞电影基调
- **撞色叙事对比** — 英雄红（C3）、能量金（C5）、爆炸橙（C8）作为叙事转折的视觉信号，用于英雄登场、能量爆发、战斗冲突与胜利时刻。撞色对比应与故事弧线同步，而非随意混用
- **冷暖分配策略** — 对峙/压迫/内心挣扎/废弃段落严格维持冷色调基底（墨蓝 C4 + 墨黑 C9 + 暗影紫 C7），禁用暖黄、爆炸橙等暖色调；暖色仅在英雄登场、战斗爆炸、胜利时刻、回忆段落释放，用冷暖对比做叙事转折
- **色盘先行原则** — 段落规划需先绑定情绪场景（英雄登场/战斗冲突/对峙压迫/灾难救援/胜利时刻/内心挣扎/科幻基地），再确定主色+辅色与光影方案
- **禁用色域** — 低饱和灰调、莫兰迪色、日系清新淡色、高饱和荧光色均与本风格不兼容（能量发光除外）

## 二、光影方案体系

- **光影即叙事** — 7 套光影方案对应不同情绪段落，导演规划阶段应在段落层面确定光影基调方向
- **真人电影光影特征** — 电影级布光、体积光、镜头光晕、浅景深、高对比明暗为核心手段；光影必须服务于情绪叙事，保持好莱坞大片的史诗感

| 光影方案 | 方案名 | 色调倾向 | 适用情绪 |
|---|---|---|---|
| A | 英雄登场光 | 能量金 C5 + 英雄红 C3 体积光 | 英雄登场、张扬、胜利、史诗 |
| B | 硬侧高反差 | 墨黑 C9 + 爆炸橙 C8 硬光分割 | 对峙压迫、愤怒冷峻、战斗冲突 |
| C | 低调冷光 | 墨蓝 C4 + 墨黑 C9 低调打光 | 悬疑紧张、废弃恐怖、内心挣扎、孤独 |
| D | 科幻冷光 | 英雄蓝 C4 + 科技银 C6 冷光 | 科幻基地、未来场景、科技装置、异星 |
| E | 暖光日常 | 中性灰 C10 + 健康肤 C1 侧光 | 室内日间、日常起居、回忆怀旧 |
| F | 夜景灯火 | 爆炸橙 C8 点缀 + 墨黑 C9 暗部 + 墨蓝 C4 | 夜生活、城市夜景、深夜街道 |
| G | 爆炸战斗光 | 爆炸橙 C8 + 能量金 C5 动态光 | 战斗冲突、灾难救援、能量爆发、爆炸 |

- **冷暖光分配** — 暖色光（爆炸橙 C8 + 能量金 C5）适用于英雄登场、战斗爆炸、胜利时刻、回忆段落；冷色光（墨蓝 C4 + 墨黑 C9 + 英雄蓝 C4）适用于对峙、压迫、内心挣扎、科幻基地段落。导演可根据叙事需要调整冷暖切换点
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述光影方案（A-G）的某一方向，确保视觉一致性

## 三、质感方向

- **电影级真实为锚** — 美式超级英雄真人电影的核心：电影级光影、浅景深、真实材质、皮肤毛孔可见、金属反光强烈、体积光、镜头光晕，呈现强烈的好莱坞大片画面
- **面容与表情** — 面容真实立体、表情戏剧化（愤怒时咬牙、胜利时昂首、坚定时目光如炬），皮肤质感真实，毛孔/胡茬/汗水可见
- **体型与比例** — 写实比例为主，7-8.5头身，肌肉发达，倒三角体型，肩宽腰窄。英雄角色偏高，力量感强
- **服饰材质** — 衣物布料质感真实、纹理细节清晰、布料折痕自然、衣物随动态飘逸。英雄战斗服/装甲/西装/休闲装的面料质感须可信，金属装甲反光强烈
- **场景材质** — 场景材质纹理真实、空气透视、使用痕迹、战损灰尘、乱中有序。混凝土/砖墙/木材/玻璃/金属质感均需在电影级光影下清晰呈现
- **真人电影不等于纪录片** — 美式超级英雄真人电影强调在真实基础上叠加戏剧性光影与电影级构图，通过高对比与体积光放大史诗感

## 四、真人电影场景空间元素

美式超级英雄真人电影世界观特有的场景元素及其视觉叙事功能：

- **城市天际线/摩天大楼** — 史诗感的天然载体，玻璃幕墙反光、城市景观、天空背景。摩天大楼 = 现代都市与英雄舞台
- **天空战场/飞行场景** — 史诗战斗的天然舞台，天空/云层/飞行/爆炸/能量光束。天空 = 自由与高速战斗
- **英雄总部/科幻基地** — 科技感的天然载体，高科技装置/全息投影/训练区/装备展示/控制台。基地 = 英雄后方与科技
- **天台/屋顶** — 英雄登场/沉思/对决的经典场景，城市景观为背景，栏杆/水塔/天线。天台 = 开阔与孤独
- **废弃建筑/工厂/工地** — 战斗感的天然舞台，倒塌墙壁/灰尘/碎片/废弃设备/黑暗。废弃 = 战斗与危险
- **灾难/废墟场景** — 紧迫与救援的天然载体，倒塌建筑/烟尘/碎片/火焰/救援。废墟 = 灾难与英雄责任
- **段落间用场景空镜过渡** — 本风格有丰富的场景资产（不同时段/天候变体），段落衔接建议用场景空镜做情绪缓冲，不要硬切。城市天际线、天空战场、科幻基地均可作为过渡空镜
- **转折点用视觉而非台词** — 优先使用画面手段（光影突变、景别跳切、空镜隐喻、表情定格、能量爆发）而非依赖对白解释

## 五、真人电影配乐与环境音

美式超级英雄真人电影世界观下的声音元素约束：

### 配乐乐器选择

- **管弦乐（弦乐+铜管+木管）** — 核心乐器，适用范围最广：英雄登场的辉煌铜管、战斗的紧张弦乐、情感的抒情弦乐、胜利的全奏
- **打击乐（定音鼓+军鼓+大鼓）** — 节奏核心，定音鼓/军鼓用于紧张和战斗，大鼓用于英雄登场和史诗时刻
- **合唱团** — 史诗感的核心，用于英雄登场、胜利时刻、重大转折，人声合唱增强史诗感
- **电子合成器** — 科幻/异星场景的氛围铺底，低频电子pad用于太空/异星/科幻基地，不和谐电子音用于紧张
- **钢琴** — 情感铺底，适用于内心挣扎、回忆、情感段落
- **环境音/音效** — 爆炸音效、能量光束音效、金属碰撞音效、飞行音效、城市环境音

### 配乐组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 英雄登场/张扬 | 铜管全奏 + 合唱团 + 定音鼓 + 大鼓 |
| 战斗冲突/激烈 | 弦乐紧张 + 铜管 + 打击乐全奏 + 电子音效 |
| 对峙压迫/紧张 | 不和谐弦乐 + 低频电子 + 定音鼓 |
| 灾难救援/紧迫 | 弦乐紧迫 + 打击乐 + 铜管 + 环境音效 |
| 胜利时刻/辉煌 | 管弦乐全奏 + 合唱团 + 铜管辉煌 |
| 内心挣扎/深沉 | 钢琴独奏 + 弦乐低沉 + 轻电子 |
| 科幻基地/科技 | 电子合成器 + 轻弦乐 + 科技音效 |
| 日常/铺垫 | 轻钢琴 + 弦乐 或 吉他 + 轻打击乐 |

### 真人电影环境音

- **典型环境音层次** — 城市车流远声 / 直升机螺旋桨声 / 爆炸回声 / 金属碰撞声 / 能量光束嗡嗡声 / 飞行呼啸声 / 人群嘈杂声 / 警报声 / 玻璃碎裂声 / 风声 / 电流滋滋声 / 全息投影嗡嗡声
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越丰富，真人电影场景越有沉浸感
- **静默是紧张核心** — 对峙段落常用突然静默，只保留心跳声/呼吸声/脚步声，静默中的异响 = 最大紧张
- **史诗音效是英雄核心** — 英雄登场常用铜管辉煌+合唱团+定音鼓，战斗常用爆炸+金属碰撞+能量光束，史诗音效是风格标志

## 六、视频生成工作流约束

- **关键帧先行** — 带文字画面（标题、拟声词、标语、招牌、屏幕显示、全息投影等）必须先生成关键帧图片确认文字准确，再用图生视频
- **角色一致性锚定** — 每段视频prompt必须重复角色核心外观锚点（发型/头盔、服装主色、标志性装备/徽章/披风）
- **分段生成** — 单段不超过15秒，长视频按叙事段落拆分
- **后期合成** — Logo/徽标/标语等品牌元素预留空位后期合成
- **英雄史诗处理** — 英雄登场用低角度仰拍+慢动作+体积光，战斗用高对比+爆炸火光+速度感，对峙用低调光影+静默 buildup
