# 美式超级英雄真人电影风格说明

本风格专为**美式超级英雄真人电影风格**题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **真人电影摄影风格**：所有角色、场景、道具均以真人电影摄影为标准，强调电影级光影、浅景深、镜头语言、真实材质、好莱坞大片质感。
- **超级英雄叙事背景**：涵盖都市战斗、英雄登场、反派对峙、灾难救援、科幻基地、天空战场等，杜绝低幼卡通/纯写实纪录片/日系纯爱元素。
- **电影级构图**：画面构图强调电影感，景深虚化、镜头光学特征、空气透视、宽银幕比例。
- **高对比戏剧光影**：整体色调偏饱和对比，明暗反差强烈，突出力量感与戏剧张力，IMAX/好莱坞大片质感。

## 适用范围

- 美式超级英雄真人电影题材的AI美术生成（角色、场景、道具、分镜等）
- 英雄叙事/战斗场面/科幻动作电影风格的视觉创作
- 需要电影级光影、浅景深、真实材质的视觉创作
- 品牌IP动画、科普宣传、动作短片等需要强力量感风格的项目

## 严禁内容

- 卡通/动画/漫画/手绘风格（除非明确要求风格化）
- 低幼Q版/萌系/日系纯爱风格
- 唯美古风/仙侠/奇幻精灵风格
- 直接使用受版权保护的特定超级英雄角色名或形象（提示词中使用风格描述，不出现具体角色名如钢铁侠/蜘蛛侠/美国队长等）
- 暗示性、暴露、低俗等不适宜内容
- 过度血腥/暴力/恐怖内容

## 风格体验

在本风格下，您将体验到：

- 角色面容真实立体、肌肉线条分明、表情戏剧化（愤怒时咬牙、胜利时昂首、坚定时目光如炬），皮肤质感真实，毛孔/胡茬/汗水可见
- 场景空间宏大，城市天际线/天空战场/科幻基地，材质纹理真实，金属/玻璃/混凝土质感强烈，氛围史诗且富有电影感
- 道具、装备、科技装置等均为真人电影级造型，金属质感强烈，发光元件真实，工艺精细
- 分镜与视频均以真人电影为基础，强调镜头语言与动作节奏，IMAX宽银幕质感

## 视频生成工作流（关键帧+图生视频）

本风格推荐使用"关键帧先行"工作流，特别适用于带文字画面和角色一致性要求高的项目：

1. **关键帧生成**：对每段中带文字的关键画面（标题、拟声词、标语、招牌等），先用文生图生成静态关键帧，确认文字准确无误
2. **图生视频**：将关键帧作为参考图传入视频生成工具，配合时间轴分镜prompt生成动态视频
3. **角色一致性锚定**：每段prompt中重复角色核心外观锚点（发型/头盔、服装主色、标志性装备/徽章），防止跨段角色漂移
4. **分段生成**：单段不超过15秒，长视频按叙事段落拆分后拼接
5. **后期合成**：Logo/徽标/标语等品牌元素在视频中预留空位，后期合成
