# 美式超级英雄真人电影场景图生成 · 约束手册

---

## 一、场景美学原则

1. **空间叙事** — 场景承载情绪与叙事功能，不是纯背景板，可加入史诗/战斗/科幻元素
2. **层次纵深** — 所有场景必须具备前/中/后景，杜绝扁平
3. **质感真实** — 材质纹理必须清晰（金属/玻璃/木材/布料/墙面/混凝土/废墟），电影级真实质感
4. **电影级光影为锚** — 所有画面以美式超级英雄真人电影风格为标准，强调电影级光影、浅景深、真实材质
5. **高对比戏剧光影** — 光影服务于情绪，保持高对比基调，明暗反差强烈，体积光、镜头光晕
6. **现代都市+科幻混搭** — 本风格场景常出现现代都市场景与科幻元素的混搭，制造史诗感与未来感

## 五、主视图规范

### 视图定义

> 单画面主视图，从场景中最具代表性的角度拍摄，承载空间叙事与构图重心。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 自然观察视角或夸张透视，构图最能体现场景主体与纵深 | `hero shot`、`representative angle`、夸张透视 |
| 视点高度 | 默认人眼平视高度，英雄登场常用低角度仰拍，战场全貌常用高角度俯拍 | `eye level`（默认）/ `low angle` / `high angle` / `bird's eye view` |
| 构图 | 主体居中或符合三分法，前/中/后景层次清晰，可加入史诗/科幻元素 | `balanced composition`、电影级构图 |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 风格/材质/色调/光线统一 |
| 光线 | 单一光源逻辑或多光源混合（科幻/战斗场景），光影方向一致 |
| 画面比例 | 默认 16:9 横屏或 2.35:1 宽银幕（IMAX/好莱坞大片推荐） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次」 |
| R2 | 室外必须包含「空气透视」 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能代表场景主体并展示前/中/后景层次 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含「美式超级英雄真人电影风格」+「电影级光影」+「浅景深」+「真实材质」+「好莱坞大片质感」关键词 |
| R7 | 材质必须带有使用痕迹/战损/灰尘，禁止全新无瑕的"3D渲染感" |
| R8 | 科幻/战斗场景必须有至少一个非日常元素（科技发光/能量光束/爆炸/废墟/全息投影） |
| R9 | 高对比是核心——明暗反差必须强烈，体积光、镜头光晕 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑/无场景 |
| X2 | 极端天候（暴风雨/雷电/暴雪，除非剧情需要） |
| X3 | 场景无纵深/无层次 |
| X4 | 植被/天候与季节/场景矛盾 |
| X5 | 出现任何人物、人影、人体剪影或人体轮廓 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 卡通/动画/漫画/手绘风格（除非明确要求风格化） |
| X8 | 材质过于干净完美、无任何使用痕迹与岁月感 |
| X9 | 光照过于均匀平坦、无景深虚化、无镜头光学特征 |
| X10 | 低幼Q版/萌系/日系纯爱风格 |
| X11 | 低饱和灰调/莫兰迪色/日系清新淡色 |
| X12 | 过度血腥/暴力/恐怖内容 |
