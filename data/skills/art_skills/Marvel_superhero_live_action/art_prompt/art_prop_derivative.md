## 一、衍生原则

### 文书/告示/纸条类道具文字排版规则（必守）
若道具为文书、告示、纸条、清单、便签、规章制度、卡片等包含明确文字内容的道具：
1. **双引号逐字精准输出**：在提示词中必须使用双引号将文字标题与核心条款逐字精准标出（例如：包含清晰可见的书法/印刷文字标题 "【顾客须知】" 以及逐条清晰排版的规则内容 "1. 禁止投喂" "2. 违者后果自负"）。
2. **文字排版与可读性**：必须明确描述文字的字迹风格（如：深黑墨迹手写体 / 醒目印刷体 / 红色印章）、纸张折痕与排版布局（居中大标题、分行条例清晰、段落整齐），确保生图模型精准逐字渲染，严禁模糊乱码或乱画无意义字符。


1. **造型锚定** — 道具核心造型/轮廓在所有状态中可识别
2. **状态可读** — 状态差异必须一目了然，观众能立即区分
3. **叙事服务** — 每种状态变体服务于特定剧情节点
4. **渐进退化** — 损伤/老化状态应有合理的物理逻辑，可夸张表现
5. **纯道具独立展示** — 画面中只能出现道具本身，严禁出现任何人物、手部、肢体

## 三、状态变体画面规范

### 单状态图

| 项目 | 约束 |
|---|---|
| 背景 | 纯净中性灰 `#808080` 或摄影棚渐变背景（与设定图一致） |
| 光线 | 电影级布光，前方主光 + 侧逆光 + 轮廓光，浅景深，自然阴影，发光状态可加诡异侧光 |
| 角度 | 与原设定图正面图一致 |
| 比例 | 道具占画面主体 70%+ |

### 状态对比图

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面并排展示 2-3 种状态 |
| 标注 | 每种状态下方标注状态名（如需要） |
| 一致性 | 角度/光线/背景完全一致，仅状态不同 |

## 四、材质状态变化规则

| 材质 | 崭新 → 日常 | 日常 → 陈旧 | 损伤表现 | 激活/发光表现 |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 道具核心造型/轮廓在所有状态中可识别 |
| R2 | 状态变化须符合物理逻辑，可夸张但不可荒谬 |
| R3 | 必须使用四宫格（2×2）布局 |
| R4 | 必须指定「纯净中性灰背景」或摄影棚背景，电影级布光，浅景深 |
| R5 | 必须包含「美式超级英雄真人电影风格」+「电影级光影」+「浅景深」+「真实材质」关键词 |
| R6 | 激活/发光/能量状态必须有明确的发光效果描述 |
| R7 | 血迹/恐怖元素必须克制，不能过度血腥 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 状态变化后道具不可识别 |
| X2 | 违反物理逻辑的损伤 |
| X3 | 过度血腥/暴力/恐怖的损伤描绘 |
| X4 | 出现任何人物形象，包括全身、半身、局部（手、手指、手臂等肢体） |
| X5 | 道具处于被持有、握持、佩戴、使用中的状态 |
| X6 | 出现暗示人物存在的元素 |
| X7 | 卡通/动画/漫画/手绘风格（除非明确要求风格化） |
| X8 | 低幼Q版/萌系/日系纯爱风格 |
| X9 | 塑料感材质/不真实的质感 |
| X10 | 在提示词中直接使用受版权保护的特定道具/物品名 |
