## 二、全局色彩盘（风格基线，不是硬锁）

> 目标：统一审美而非限制创作。除「硬约束色」外，其余颜色默认优先使用，可在合理范围内偏移。

| 层级 | 约束强度 | 说明 |

| L1 硬约束 | 高 | 仅锁定角色识别核心：肤色、发色/头盔色、主服底色的审美方向 |
| L2 软约束 | 中 | 场景色、装备色、点缀色优先参考色盘，可按镜头与剧情微调 |
| L3 例外机制 | 低 | 回忆/梦境/异世界可临时突破局部色彩，但需保留整体对比逻辑 |

### 硬约束色（默认锁定）

| 色项 | 对应色 | 规则 |
|---|---|---|
| 角色肤色基准 | C1 健康肤 | 默认优先，允许不同种族有差异化肤色，皮肤质感真实 |
| 暗部基准 | C9 墨黑 | 默认优先，电影级暗部，保留细节不死黑 |
| 主服色基准 | 角色指定色 | 每个英雄/角色有固定主服色，跨镜头不得漂移 |

### 软约束色（推荐优先）

> C3/C4/C5/C6/C7/C8 为推荐英雄色域，用于制服、能量特效、金属装甲、爆炸、反派暗影等。可根据镜头氛围做同色相邻近调整。高对比是本风格核心——明暗并置、互补色相邻。

### 情绪色盘使用规则

| 编号 | 规则 |
|---|---|
| E1 | 每条提示词至少指定 1 个「情绪场景」并绑定主色+辅色组合 |
| E2 | 单镜头主色不超过 2 个，避免颜色叙事失焦 |
| E3 | 情绪切换时优先调整光比与色温，再调整饱和度 |
| E4 | 英雄史诗向默认遵循「高对比饱和色」：鲜艳色彩铺底，力量感为焦点 |
| E5 | 若与剧情冲突，以情绪色盘优先于通用推荐色，但不得突破严禁项 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 中性 5500-6500K（推荐） | 好莱坞电影主基调 |
| 战斗/爆炸色温 | 偏暖 4500-5500K | 爆炸/火焰/能量场景 |
| 科幻/夜景色温 | 偏冷 6500-7500K | 基地/夜景/暗影场景 |
| 对比度 | 高（建议保持） | 明暗反差鲜明，电影级对比 |
| 饱和度 | 中高 60-80%（建议区间） | 高饱和对比是风格核心，但不过度 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|
| 色相偏移 | ±10° |
| 饱和度偏移 | ±12% |
| 明度偏移 | ±12% |

> 例外场景：回忆、梦境、异世界镜头可使用更夸张的色彩偏移；但禁止低饱和灰调与本风格核心冲突。
