## 二、全局色彩盘（风格基线，不是硬锁）

> 目标：统一审美而非限制创作。除「硬约束色」外，其余颜色默认优先使用，可在合理范围内偏移。

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 仅锁定角色识别核心：肤色、发色、主服底色的审美方向 |
| L2 软约束 | 中 | 场景色、配饰色、点缀色优先参考色盘，可按镜头与剧情微调 |
| L3 例外机制 | 低 | 回忆/梦境/搞笑段落可临时突破局部色彩，但需保留整体暗调逻辑 |

| 序号 | 色名 | 色值 | 用途 |
|---|---|---|---|
| C1 | 黄皮肤 | `#E8C4A0` | 角色肤色基准（偏黄） |
| C2 | 苍白肤 | `#D8C8B8` | 鬼怪/僵尸/特殊角色肤色 |
| C3 | 暗红 | `#8B0000` | 血液、警示、惊悚强调色 |
| C4 | 墨蓝 | `#1A2A3A` | 暗部、夜景、阴影、惊悚氛围 |
| C5 | 惨绿 | `#4A7C59` | 灵异、鬼怪、毒雾、诡异光 |
| C6 | 土黄 | `#C9A96E` | 老旧建筑、纸张、复古、怀旧 |
| C7 | 冷灰 | `#6B7280` | 现代建筑、金属、阴天、压抑 |
| C8 | 惨白 | `#F0EDE8` | 高光、月光、幽灵、恐怖光源 |
| C9 | 墨黑 | `#0A0A0A` | 轮廓线、暗部、阴影、鬼怪服装 |
| C10 | 中性灰 | `#808080` | 设定图背景、过渡色 |

### 硬约束色（默认锁定）

| 色项 | 对应色 | 规则 |
|---|---|---|
| 角色肤色基准 | C1 黄皮肤 | 默认优先，允许不同种族有差异化肤色 |
| 轮廓线基准 | C9 墨黑 | 默认优先，细腻墨线为风格核心识别点 |
| 主服色基准 | 角色指定色 | 每个角色有固定主服色，跨镜头不得漂移 |

### 软约束色（推荐优先）

> C3/C4/C5/C6/C7/C8 为推荐惊悚色域，用于血液、暗部、灵异、老旧建筑、现代建筑、高光等。可根据镜头氛围做同色相邻近调整。暗色调是本风格核心——暗部占比大，高对比局部点亮。

### 情绪色盘（导演对齐版）

| 情绪场景 | 主色 | 辅色 | 光效与对比建议 | 画面关键词 |
|---|---|---|---|---|
| 日常都市（平静） | C1 黄皮肤 | C7 冷灰 + C6 土黄 | 平涂为主，少量阴影，色彩自然 | 日常、都市、平静 |
| 惊悚悬疑（紧张） | C4 墨蓝 | C9 墨黑 + C8 惨白 | 低调光影，暗部占比大，冷色调，局部高对比 | 紧张、压迫、未知、阴影 |
| 鬼怪灵异（诡异） | C5 惨绿 | C4 墨蓝 + C8 惨白 | 低光环境，惨绿/惨白光，高对比，诡异光晕 | 诡异、灵异、鬼怪、冷光 |
| 搞笑反差（荒诞） | C6 土黄 | C1 黄皮肤 + C7 冷灰 | 平涂为主，表情夸张，色彩自然但表情变形 | 搞笑、荒诞、反差、夸张 |
| 战斗冲突（激烈） | C3 暗红 | C9 墨黑 + C8 惨白 | 速度线、冲击特效、高对比、动态 | 战斗、冲击、爆发、速度 |
| 回忆/怀旧（温暖） | C6 土黄 | C1 黄皮肤 + C8 惨白 | 暖色调，柔光，低对比，怀旧滤镜 | 回忆、怀旧、温暖、旧时光 |
| 废弃/恐怖（压抑） | C4 墨蓝 | C9 墨黑 + C5 惨绿 | 暗部占比极大，仅局部光源，灰尘/蛛网/破败 | 废弃、恐怖、压抑、破败 |

### 情绪色盘使用规则

| 编号 | 规则 |
|---|---|
| E1 | 每条提示词至少指定 1 个「情绪场景」并绑定主色+辅色组合 |
| E2 | 单镜头主色不超过 2 个，避免颜色叙事失焦 |
| E3 | 情绪切换时优先调整光比与色温，再调整饱和度 |
| E4 | 惊悚搞笑向默认遵循「暗调基底+局部高对比」：暗色铺底，亮色落在角色/光源/惊悚焦点 |
| E5 | 搞笑段落可临时提高饱和度和表情夸张度，但场景仍保持暗调基底 |
| E6 | 若与剧情冲突，以情绪色盘优先于通用推荐色，但不得突破严禁项 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 偏冷 6000-7000K（推荐） | 惊悚主基调 |
| 搞笑/日常色温 | 中性 5500-6000K | 日常/搞笑段落 |
| 回忆/怀旧色温 | 偏暖 4500-5500K | 回忆/怀旧段落 |
| 对比度 | 高（建议保持） | 明暗反差鲜明，细腻墨线强化轮廓 |
| 饱和度 | 中低 40-60%（惊悚段落）/ 中高 60-75%（搞笑段落） | 暗色调是风格核心 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|
| 色相偏移 | ±12° |
| 饱和度偏移 | ±15% |
| 明度偏移 | ±15% |

> 例外场景：回忆、梦境、搞笑高潮镜头可使用更暖或更高饱和的局部色块；但禁止高饱和荧光色与本风格核心冲突。

## 三、全局约束规则

### 必守规则（所有技能继承）

| 编号 | 规则 |
|---|---|
| R1 | 必须包含「国产恐怖搞笑条漫风格」风格锚定词 |
| R2 | 必须声明「细腻墨线 + 写实与夸张结合 + 暗色调」 |
| R3 | 面部必须使用「写实细腻 + 表情夸张（惊恐/搞笑时变形）」 |
| R4 | 发丝必须使用「线条细腻 + 写实发质」 |
| R5 | 纹理必须声明「纹理细节细腻 + 手绘质感」 |
| R6 | 必须声明「暗色调 + 条漫分镜感 + 惊悚氛围」 |
| R7 | 角色核心外观（发型、服装主色、标志性特征）必须在每条提示词中重复锚定 |
| R8 | 惊悚段落暗部占比必须大于50%，搞笑段落可适当提高亮度 |

### 严禁项（所有技能继承）

| 编号 | 严禁内容 |
|---|---|
| X1 | 严禁「真人写实/摄影/3D渲染/CGI」 |
| X2 | 严禁「低幼Q版/萌系/日系纯爱」 |
| X3 | 严禁「唯美古风/仙侠/奇幻精灵」（回忆段落除外） |
| X4 | 严禁「面部变形/多指/肢体异常」倾向词（搞笑夸张表情除外） |
| X5 | 严禁「裸体/暴露/透视/暗示性描述」 |
| X6 | 严禁在提示词中直接使用受版权保护的特定漫画角色名 |
| X7 | 严禁「过度血腥/恐怖/低俗内容」（惊悚氛围可以，不能过度血腥） |
| X8 | 严禁「高饱和荧光色/霓虹色」（灵异发光除外） |
