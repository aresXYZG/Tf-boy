# 国产恐怖搞笑条漫场景图生成 · 约束手册

---

## 一、场景美学原则

1. **空间叙事** — 场景承载情绪与叙事功能，不是纯背景板，可加入惊悚/搞笑元素
2. **层次纵深** — 所有场景必须具备前/中/后景，杜绝扁平
3. **质感细腻** — 材质纹理必须清晰（金属/玻璃/木材/布料/墙面/混凝土/老旧物品），细腻手绘质感
4. **细腻墨线为锚** — 所有画面以国产恐怖搞笑条漫风格为标准，强调细腻墨线与暗色调
5. **暗色调惊悚氛围** — 光影服务于情绪，保持暗色调基调，明暗反差强烈，局部高对比
6. **现代中国都市+灵异混搭** — 本风格场景常出现现代中国都市场景与灵异元素的混搭，制造惊悚搞笑反差

## 五、主视图规范

### 视图定义

> 单画面主视图，从场景中最具代表性的角度拍摄，承载空间叙事与构图重心。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 自然观察视角或夸张透视，构图最能体现场景主体与纵深 | `hero shot`、`representative angle`、夸张透视 |
| 视点高度 | 默认人眼平视高度，惊悚场景常用低角度/高角度，灵异场景可用Dutch角 | `eye level`（默认）/ `low angle` / `high angle` / `dutch angle` |
| 构图 | 主体居中或符合三分法，前/中/后景层次清晰，可加入惊悚/灵异元素 | `balanced composition`、夸张构图 |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 风格/材质/色调/光线统一 |
| 光线 | 单一光源逻辑或多光源混合（灵异/惊悚场景），光影方向一致 |
| 画面比例 | 默认 16:9 横屏或 9:16 竖屏（条漫推荐竖屏） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次」 |
| R2 | 室外必须包含「空气透视」 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能代表场景主体并展示前/中/后景层次 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含「国产恐怖搞笑条漫风格」+「细腻墨线」+「暗色调」+「条漫分镜感」关键词 |
| R7 | 材质必须带有使用痕迹/老旧/灰尘，禁止全新无瑕的"3D渲染感" |
| R8 | 惊悚/灵异场景必须有至少一个非日常元素（诡异光/灵异物品/非现实布局/血迹（克制）） |
| R9 | 暗部占比必须大于50%（惊悚段落），搞笑段落可适当提高亮度 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑/无场景 |
| X2 | 极端天候（暴风雨/雷电/暴雪，除非剧情需要） |
| X3 | 场景无纵深/无层次 |
| X4 | 植被/天候与季节/场景矛盾 |
| X5 | 出现任何人物、人影、人体剪影或人体轮廓 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 3D渲染/CG动画/游戏引擎质感 |
| X8 | 材质过于干净完美、无任何使用痕迹与岁月感 |
| X9 | 光照过于均匀平坦、无景深虚化、无镜头光学特征 |
| X10 | 低幼Q版/萌系/日系纯爱风格 |
| X11 | 过度血腥/恐怖/低俗内容（血迹必须克制） |
