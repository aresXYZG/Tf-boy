# 国产恐怖搞笑条漫道具衍生状态生成 · 约束手册

## 一、衍生原则

### 文书/告示/纸条类道具文字排版规则（必守）
若道具为文书、告示、纸条、清单、便签、规章制度、卡片等包含明确文字内容的道具：
1. **双引号逐字精准输出**：在提示词中必须使用双引号将文字标题与核心条款逐字精准标出（例如：包含清晰可见的书法/印刷文字标题 "【顾客须知】" 以及逐条清晰排版的规则内容 "1. 禁止投喂" "2. 违者后果自负"）。
2. **文字排版与可读性**：必须明确描述文字的字迹风格（如：深黑墨迹手写体 / 醒目印刷体 / 红色印章）、纸张折痕与排版布局（居中大标题、分行条例清晰、段落整齐），确保生图模型精准逐字渲染，严禁模糊乱码或乱画无意义字符。


1. **造型锚定** — 道具核心造型/轮廓在所有状态中可识别
2. **状态可读** — 状态差异必须一目了然，观众能立即区分
3. **叙事服务** — 每种状态变体服务于特定剧情节点
4. **渐进退化** — 损伤/老化状态应有合理的物理逻辑，可夸张表现
5. **纯道具独立展示** — 画面中只能出现道具本身，严禁出现任何人物、手部、肢体

## 二、状态类型

### 2.1 使用状态

| 状态 | 描述 | 适用道具 | 提示词 |
|---|---|---|---|
| 崭新 | 完好无损、光泽如新、标签未撕 | 所有道具 | 崭新、完好无损、光泽如新 |
| 日常使用 | 微磨损、自然包浆、贴纸/刮痕 | 手机/电脑/个人物品/生活器物 | 日常使用痕迹、自然磨损、刮痕 |
| 陈旧 | 明显年代感、色泽暗淡、灰尘/蛛网 | 老旧物品/灵异物品/古董 | 古旧斑驳、年代感、色泽暗沉、灰尘蛛网 |
| 激活/发光 | 符咒发光/装置启动/能量聚集/灵异反应 | 灵异道具/科技装置/武器 | 激活状态、发光、能量聚集、灵异反应 |

### 2.2 损伤状态

| 状态 | 描述 | 适用道具 | 提示词 |
|---|---|---|---|
| 微损 | 小裂纹/小缺口/轻微磨损/按钮失灵 | 手机/玻璃器具/桃木剑/生活器物 | 细微裂纹、轻微缺口、按钮凹陷 |
| 破损 | 明显裂缝/断裂/破碎/屏幕碎裂/刀刃缺口 | 玻璃/陶瓷/塑料/电子设备/武器 | 裂缝明显、碎裂、断裂、屏幕碎裂 |
| 残片 | 仅剩部分/碎片/烧焦残骸/断裂残端 | 玻璃/陶瓷/桃木剑/符咒/科技装置 | 残片、碎片、仅存半块、烧焦残骸 |
| 燃烧 | 火焰/烟雾/烧焦/部分熔化 | 纸张/布料/塑料/符咒/木质 | 燃烧状态、火焰、烟雾、烧焦 |

### 2.3 特殊状态

| 状态 | 描述 | 适用道具 | 提示词 |
|---|---|---|---|
| 灵异激活 | 符咒发光/八卦镜反光/罗盘指针乱转/佛珠发光/铃铛自鸣 | 灵异/驱邪道具 | 灵异激活、符咒发光、八卦反光、指针乱转 |
| 诅咒/黑化 | 道具变黑/散发黑气/出现裂纹/血色蔓延/温度降低 | 灵异物品/诅咒道具 | 诅咒状态、黑化、黑气、血色蔓延 |
| 故障/短路 | 火花四溅/屏幕乱码/电线冒烟/电流乱窜/警告灯闪烁 | 电子设备/科技装置 | 故障状态、火花四溅、屏幕乱码、电线冒烟 |
| 冻结 | 冰霜覆盖/冰晶凝结/冷雾缭绕/表面结霜 | 任意道具 | 冻结状态、冰霜覆盖、冰晶凝结、冷雾 |
| 血迹/沾染 | 血迹附着/灰尘覆盖/液体残留/污渍（克制） | 任意道具（惊悚场景） | 血迹（克制）、灰尘覆盖、液体残留、污渍 |
| 泛黄/老化 | 纸张泛黄/布料褪色/金属氧化/木材干裂 | 老旧物品/古董/灵异物品 | 泛黄、老化、褪色、氧化、干裂 |

## 三、状态变体画面规范

### 单状态图

| 项目 | 约束 |
|---|---|
| 背景 | 纯净中性灰 `#808080`（与设定图一致） |
| 光线 | 均匀照明，自然阴影，灵异/发光状态可加诡异侧光 |
| 角度 | 与原设定图正面图一致 |
| 比例 | 道具占画面主体 70%+ |

### 状态对比图

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面并排展示 2-3 种状态 |
| 标注 | 每种状态下方标注状态名（如需要） |
| 一致性 | 角度/光线/背景完全一致，仅状态不同 |

## 四、材质状态变化规则

| 材质 | 崭新 → 日常 | 日常 → 陈旧 | 损伤表现 | 激活/发光表现 |
|---|---|---|---|---|
| 金属 | 亮光泽 → 微划痕 | 划痕 → 氧化/锈迹 | 缺口/卷边/断裂/凹陷/烧焦 | 能量纹路发光、高温红热、电流乱窜 |
| 玻璃 | 通透清晰 → 微划痕 | 划痕 → 裂纹/碎裂 | 裂纹/碎裂/缺口/碎片 | 内部发光、能量折射、八卦反光 |
| 木材 | 新木纹理 → 自然包浆 | 包浆 → 色泽暗沉/干裂 | 开裂/虫蛀/磨损/烧焦/断裂 | 符咒发光、桃木红光、能量流动 |
| 塑料 | 崭新平整 → 微划痕 | 划痕 → 老化变色 | 裂纹/变形/褪色/融化/烧焦 | 按钮发光、屏幕透光、警告灯闪烁 |
| 纸张 | 崭新平整 → 微折痕 | 折痕 → 发黄变脆 | 撕裂/焦损/污渍/血迹（克制） | 符咒发光、朱砂发亮、文字发光 |
| 布料 | 崭新平整 → 微褶皱 | 褶皱 → 褪色/磨损 | 撕裂/烧焦/污渍/血迹（克制） | 红绳发光、符咒布发光、能量流动 |
| 玉石 | 温润光泽 → 微磨损 | 磨损 → 色泽暗淡/裂纹 | 裂纹/碎裂/缺口 | 玉石发光、能量聚集、温润光晕 |
| 电子元件 | 崭新 → 微使用 | 使用 → 焊点老化/灰尘 | 短路/烧焦/电容爆裂/电线断裂 | 指示灯亮、屏幕显示、能量流动、电流乱窜 |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 道具核心造型/轮廓在所有状态中可识别 |
| R2 | 状态变化须符合物理逻辑，可夸张但不可荒谬 |
| R3 | 必须使用四宫格（2×2）布局 |
| R4 | 必须指定「纯净中性灰背景」，均匀柔光，自然阴影 |
| R5 | 必须包含「国产恐怖搞笑条漫风格」+「细腻墨线」+「暗色调」关键词 |
| R6 | 激活/发光/灵异状态必须有明确的发光效果描述 |
| R7 | 血迹/恐怖元素必须克制，不能过度血腥 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 状态变化后道具不可识别 |
| X2 | 违反物理逻辑的损伤 |
| X3 | 过度血腥/恐怖/低俗的损伤描绘 |
| X4 | 出现任何人物形象，包括全身、半身、局部（手、手指、手臂等肢体） |
| X5 | 道具处于被持有、握持、佩戴、使用中的状态 |
| X6 | 出现暗示人物存在的元素 |
| X7 | 使用真人写实/摄影/3D渲染相关词 |
| X8 | 低幼Q版/萌系风格 |
| X9 | 在提示词中直接使用受版权保护的特定道具/物品名 |
