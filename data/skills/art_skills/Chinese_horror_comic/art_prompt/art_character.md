# 国产恐怖搞笑条漫人物基础形象生成 · 约束手册

---

## 一、基础形象原则

1. **写实即基础** — 面容写实细腻是角色基础，精细度适配国产条漫风格
2. **夸张即笑点** — 惊恐/搞笑时五官可夸张变形，是条漫喜剧效果的核心
3. **角色为本** — 基础着装由角色描述（身份/职业/性别/场景）决定其常规着装；后续特定服化为叠加层
4. **四视图一致** — 面容/体型/发型/基础服装跨视图高度统一
5. **轮廓辨识度** — 每个角色必须有独特的剪影轮廓，即使去掉颜色也能区分
6. **现代中国都市** — 角色发型服饰必须符合现代中国都市审美，杜绝古风/奇幻元素

## 二、面容约束

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型，但必须写实细腻 |
| 风格底色 | 国产恐怖搞笑条漫风格、细腻墨线、写实与夸张结合、暗色调、条漫分镜感 |
| 气质 | 必须从角色描述提炼整体气质关键词（如普通/猥琐/阳光/阴狠/呆萌/美艳），并写入提示词 |
| 表情 | 中性微表情，符合角色气质，但保留夸张变形潜力 |
| 轮廓 | 脸型轮廓写实，避免过于圆润或过于尖锐 |

### 国产条漫特征（必含）

| 特征 | 描述 | 提示词 |
|---|---|---|
| 写实五官 | 五官比例接近真人，细腻渲染 | 写实五官、细腻面容 |
| 细腻墨线 | 面部轮廓用细腻墨线勾勒，线条有手绘感 | 细腻墨线、手绘轮廓 |
| 表情夸张潜力 | 惊恐时瞳孔放大、嘴巴大张；搞笑时五官变形、眉毛飞起 | 表情夸张、可变形 |
| 现代发型 | 符合现代中国都市审美，不染夸张颜色 | 现代发型、都市审美 |
| 肤色自然 | 黄皮肤为主，不同角色可有差异化 | 自然肤色、黄皮肤 |

### 表情类型（条漫核心）

| 表情 | 描述 | 适用场景 | 提示词 |
|---|---|---|---|
| 惊恐 | 瞳孔放大、眼睛瞪大、嘴巴大张、眉毛飞起、冷汗 | 惊悚/鬼怪出现 | 惊恐表情、瞳孔放大、冷汗 |

## 六、基础服装约束

> 基础服装由角色描述（身份/职业/性别/场景）决定其最自然的常规着装，作为该角色「日常默认态」；特殊衍生在服化衍生环节叠加。

### 着装选择原则

| 角色身份 | 默认着装方向 |
|---|---|
| 上班族 | 衬衫+西裤/西装/职业装/连衣裙 |
| 学生 | 校服/T恤+牛仔裤/休闲装 |
| 普通人/市民 | T恤+牛仔裤/卫衣/休闲装/连衣裙 |
| 道士/驱魔师 | 道袍/唐装/特色服装（现代改良） |
| 警察/军人 | 警服/军装/战术装备 |
| 鬼怪/僵尸 | 古装/破烂衣服/白色长袍/特色鬼怪服装 |
| 反派/坏人 | 黑色西装/皮夹克/怪异服装 |
| 角色描述未明确 | 现代都市休闲装，暗色调 |

### 着装统一规则

- 服装风格须与国产恐怖搞笑条漫美学一致（细腻墨线、写实与夸张结合、暗色调）
- 颜色以暗色调为主，每个角色有固定主服色
- 四视图服装款式完全一致
- 基础服装是「日常默认态」，焦点仍在面容与体型
- 服装可有现代中国都市特色（国产品牌风格、淘宝风、校服等）
- 鬼怪/僵尸服装可有破烂/血迹/古风元素，但不能过度血腥

## 七、四视图设定图规范（双参考垫图融合与无头素体防干扰版）

### 双真人参考图（垫图）特征融合机制（核心必守）
系统在生成四视图设定图时，支持从人脸参考资产库中匹配抽取 2 张真人人脸参考底图（图1与图2）进行解耦融合，生成全新原创角色：
1. **图 2（主要参考 70%）**：主导人物面部五官排布、眼型神韵、唇形特征与生活化/故事感神态，确立角色的核心面孔基底；
2. **图 1（辅助参考 30%）**：提供骨相立体度、下颌线轮廓骨感、鼻骨结构与皮肤通透细腻质感；
3. **画风媒介属性转化**：模型将提取的双真人参考特征自动转化为当前【国产民俗恐怖搞笑条漫】的专属艺术媒介（如墨线描边、赛璐璐平涂、PBR渲染、黏土塑形等），严禁生硬贴图；
4. **原创独立与人种/年龄参数化**：生成完全独立的全新原创角色，杜绝千篇一律的 AI 网红模板脸。根据剧本设定动态适配人种（东亚/欧美/混血/非裔等）与年龄段（少年/青年/中年/老年）。若参考底图与设定有年龄差异，由提示词动态注入年龄修饰词，模型自动渲染对应年龄段的面部特征与皮肤质感。

### 视图定义

| 位置 | 视图 | 角度 | 景别 | 要求 | 提示词 |
|---|---|---|---|---|---|
| 左一 | 人像超大特写 | 正面平视 | 头顶至锁骨 | 从头顶到锁骨完整展示不裁切，面部占60%+，锁定基于两张垫图融合出的高精五官细节、神态与媒介质感 | `portrait closeup`, `face detail`, `ultra detailed face` |
| 左二 | 正视图全身（无头素体） | 正面 0° | 颈部以下至脚底 | 面对镜头、双臂自然、从颈部以下到脚底完整展示，**颈部以上完全截断留空不画头部**，展示体型与服装全貌 | `front view`, `headless body`, `full body neck to toe` |
| 右二 | 侧视图全身（无头素体） | 右侧 90° | 颈部以下至脚底 | 纯侧面轮廓、从颈部以下到脚底完整展示，**颈部以上完全截断留空不画头部**，展示体态与侧缝细节 | `side view`, `headless body`, `profile neck to toe` |
| 右一 | 后视图全身（完整后背与后脑） | 后方 180° | 全身立像 | 后脑发型、发尾、背部服装版型与鞋底完整清晰展示 | `back view`, `rear view`, `full body head to toe` |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面从左至右横排四视图（3:1 或 4:1）：左一人像超大特写 + 左二正视图无头素体 + 右二侧视图无头素体 + 右一后视图全身立像 |
| 背景 | 纯净中性灰 `#808080`（或画风适配纯色中灰背景纸） |
| 站姿 | 自然站立、双脚平行微分、双臂自然下垂或微展 |
| **无头防干扰机制** | **左二与右二必须为无头素体（颈部以上留空截断）**，迫使生图模型将面部注意力与像素算力100%集中在左一超大特写上，彻底根除全身小脸五官变形与多头特征冲突 |
| 特写展示 | 人像特写必须从头顶到锁骨完整入画，严禁裁切头顶 |
| 光线 | 均匀柔光，前方主光 + 双侧补光，自然阴影 |
| 画面比例 | 建议 4:1 或 3:1 |
