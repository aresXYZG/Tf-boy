# 分镜表国产恐怖搞笑条漫约束 · 条漫风格 · 技法参考

---

## 一、分镜表定位

分镜表是导演将剧本转化为镜头语言的核心工具。以下仅提供国产恐怖搞笑条漫风格在分镜表层面的约束规范。

---

## 二、光影与氛围

- **同场戏光影统一** — 一场戏内不应出现两种以上光影方案，除非有明确的叙事转折（如室内灯光切换→窗外暮色渐深、门打开→诡异光涌入、灵异出现→惨绿光充满房间）
- **情绪色盘绑定** — 每场戏至少绑定 1 个情绪场景（日常都市/惊悚悬疑/鬼怪灵异/搞笑反差/战斗冲突/回忆怀旧/废弃恐怖），并在镜头组内保持主色+辅色连续性
- **光源角度规范** — 正给镜头光源默认低调冷光或局部光源，侧给镜头根据画面需要调整。描述光影时须区分自然光（窗光/阳光/月光）与人造光（灯光/屏幕光/路灯/诡异发光）的差异
- **冷暖色调与叙事阶段匹配** — 惊悚/灵异/压迫段落严格使用冷色光（墨蓝 C4 + 墨黑 C9 + 惨绿 C5），禁用土黄/暖橙等暖色调；暖色调（土黄 C6 + 黄皮肤 C1）仅在日常、搞笑、回忆段落使用
- **光影转场是高级手段** — 从窗外自然光渐变到室内暖灯光 = 日转夜的时间流逝；从明亮办公室到昏暗废弃建筑 = 情绪转折；从正常光到诡异惨绿光 = 灵异出现。在分镜表中标注光影变化点
- **发光元素是叙事工具** — 诡异光/门后光/镜子反光/屏幕发光/符咒发光的状态变化（亮→灭、正常→诡异、能量充能→释放）可作为叙事信号，在分镜表中标注发光状态变化点
- **暗部占比规范** — 惊悚段落暗部占比必须大于50%，搞笑段落可适当提高亮度至40-50%，日常段落30-40%

## 三、环境动态

- **环境动态增加画面呼吸感** — 灯光闪烁、灰尘飘落、蛛网颤动、雨滴滑过玻璃、门吱呀作响、窗帘轻摆、电线火花、雾气流动、影子异常移动。每 2-3 个镜头至少安排一个有环境动态的镜头，避免画面"死"掉
- **国产条漫环境元素优先** — 环境动态应选用国产恐怖搞笑条漫世界观内的元素：老旧灯泡闪烁、灰尘在光柱中飘落、蛛网颤动、门吱呀作响、窗帘轻摆、雾气流动、影子异常移动、镜子表面波纹、水龙头滴水、电梯灯闪烁、走廊尽头黑暗涌动，禁止出现古风/奇幻元素（灵异场景除外）
- **条漫动态表现** — 环境动态应符合国产条漫的表现方式：速度线的手绘质感、灰尘飘落的细腻线条、雾气流动的平涂渲染、诡异光的高饱和发光、影子异常的非现实形态
- **夸张环境动态是惊悚搞笑工具** — 国产条漫常用夸张环境动态强化效果：惊悚时灯光突然熄灭/影子异常拉长/门自动开合；搞笑时灰尘呛人/灯泡爆炸/蟑螂乱窜。在分镜表中标注此类夸张环境变化

## 四、国产条漫人物动作节奏

- **动作要符合情绪** — 惊悚时动作缓慢/僵硬/颤抖，搞笑时动作夸张/快速/变形，日常时动作自然/放松。关键动作（转身、抬手、奔跑、跌倒）标注情绪对应的速度和幅度
- **服饰动态** — 国产条漫服饰（外套下摆、围巾、道袍衣袖、鬼怪长袍）的动态是天然的画面资产，可在画面描述中加入衣物随风/随动作的飘动，增加画面的"活"感
- **仪态约束** — 国产条漫角色的举止应符合角色性格：普通人紧张蜷缩/道士沉稳挺拔/鬼怪僵硬不自然/搞笑角色夸张变形。不出现标准化的"优雅克制"仪态
- **表情优先于动作** — 以面部夸张表情（惊恐时瞳孔放大、搞笑时五官变形、阴狠时眯眼歪笑）传达情绪，表情幅度必须大。肢体动作为表情和情绪服务
- **预备-动作-反应三段式** — 国产条漫动作遵循经典三段式：预备（蓄力/表情变化/肌肉绷紧）→ 动作（执行/速度线/能量聚集）→ 反应（定格/夸张后果/表情变化）。在分镜表中拆解动作时遵循此节奏
- **慢动作的惊悚搞笑功能** — 升格在国产条漫中用于"关键瞬间"：鬼怪现身、jump scare、搞笑跌倒、符咒发光、门后异象——慢动作让观众有足够时间感受惊悚或搞笑，冲击力在慢动作中积蓄
- **惊恐反应库** — 经典惊恐反应：瞳孔放大→嘴巴大张→身体后仰→冷汗直流→头发竖起→僵住不动。搞笑惊恐可夸张变形：眼睛变成X→嘴巴巨大→流口水→身体夸张弯曲
- **搞笑动作库** — 经典搞笑动作：滑倒/撞墙/被吓跳起来/夸张逃跑/表情定格/慢动作跌倒/弹簧效果。搞笑动作要快节奏、夸张幅度、配合滑稽音效

## 五、运镜禁忌

- **运镜要服务于惊悚搞笑节奏** — 国产条漫运镜可以比其他风格更灵活，但必须服务于惊悚感和搞笑反差
- **缓慢推进 = 悬疑/惊悚 buildup** — 悬疑/惊悚段落常用缓慢推进，让观众逐渐靠近恐惧源，紧张感逐渐积累。这是国产条漫惊悚场景中最高频的运镜之一
- **固定 = 冷静旁观/日常/ jump scare 前的静默** — 日常场景、对话场景、jump scare 前的静默用固定机位，稳定感。固定后的突然变化 = 最大惊悚
- **急推 = 反应放大/情绪爆发/jump scare** — 某个角色看到/听到关键信息，快速推向其面部，放大"惊恐/震惊/愤怒"的反应。jump scare 时急推强化冲击力
- **甩镜 = 信息揭示/灵异出现/搞笑转折** — 从角色A迅速甩到角色B/灵异现象/搞笑元素，速度本身带有"等等！那是什么？！"的紧张感或搞笑感
- **跟随 = 追逐/逃跑/移动** — 追逐戏、逃跑、角色移动，用跟随运镜，保持角色在画面中心，背景流动
- **Dutch角 = 紧张/不安/诡异/怪诞** — 倾斜构图用于紧张场景、不安情绪、灵异空间、精神异常。国产条漫常用Dutch角强化惊悚和怪诞感
- **低角度仰拍 = 压迫/高大/英雄登场/鬼怪现身** — 高大建筑/反派/鬼怪/英雄登场，用低角度仰拍强化压迫感和力量感
- **高角度俯拍 = 渺小/迷失/战场全貌/废弃** — 废弃场景、迷失感、角色渺小感、战场全貌，用高角度俯拍。展示全局混乱和孤独感
- **运镜即节奏** — 缓慢推进 = 悬疑 buildup；固定 = 冷静/日常/静默；急推 = 反应放大/jump scare；甩镜 = 信息揭示/转折；跟随 = 追逐/移动；Dutch角 = 紧张/诡异；低角度 = 压迫/高大；高角度 = 渺小/全貌
- **不要过度运镜** — 惊悚和日常段落保持稳定，jump scare 和搞笑转折可以灵活运镜。运镜过多会分散对角色和情绪的注意力

## 六、转场设计

- **硬切为主** — 国产条漫场景内剪辑节奏偏快，硬切为主，不拖泥带水
- **惊悚转场** — 从日常场景硬切到惊悚场景，反差本身就是惊悚效果。常用：门打开→诡异光涌入、镜子反射→异象、电梯门开合→灵异出现、灯光熄灭→黑暗中出现眼睛
- **搞笑反差转场** — 从惊悚静默突然硬切到搞笑夸张，反差本身就是笑点。常用：惊悚定格→搞笑滑倒、恐怖音效→滑稽boing、鬼怪现身→搞笑表情
- **光影转场** — 用光影变化做转场：灯光熄灭→全黑→亮起新场景、门后光涌入→过曝→新场景、诡异光扩散→充满画面→新场景
- **匹配剪辑** — 用形状/动作/颜色匹配做转场：门→棺材、眼睛→月亮、红色→血液、奔跑→追逐
- **假正经转场** — 用正式/庄重的转场方式（淡入淡出、字幕卡"Meanwhile"、光圈转场）来过渡惊悚/搞笑内容，反差出戏剧感
- **条漫格子转场** — 模拟条漫格子切换效果，一格一格出现/消失，强化条漫感
- **打破第四面墙** — 角色突然看向镜头/对观众说话的瞬间用正面近景+突然静止，制造"你看到了吧？"的共谋感或搞笑感

## 七、文字画面处理

- **带文字画面必须关键帧先行** — 标题、对话气泡、旁白框、拟声词、符咒文字、标语、招牌、屏幕显示等带文字画面，必须先生成关键帧图片确认文字准确，再用图生视频
- **关键帧作为参考图** — 生成的关键帧图片作为图生视频的参考图传入，文字准确性由关键帧保障
- **视频prompt仍需描述文字** — 视频prompt中仍需描述文字内容和位置，但不依赖视频模型直接生成文字
- **符咒/符文是核心元素** — 道教符咒、符文、八卦图案是国产灵异条漫的标志性元素，符咒文字必须清晰可辨，建议先生成关键帧确认文字
- **拟声词是条漫核心** — 惊悚用"咯噔""嘶——""咚""哐当"，搞笑用"噗""boing""啊——"，拟声词必须先生成关键帧确认文字准确
- **对话气泡/旁白框** — 条漫的对话气泡和旁白框是核心叙事元素，文字必须清晰，建议先生成关键帧
- **品牌元素后期合成** — Logo/徽标/官方标语等品牌元素建议在视频中预留空位，后期合成（AI直接画品牌物易乱码）
- **画内文字 vs 画外文字** — 故事世界内的道具文字（符咒、招牌、屏幕、海报、对话气泡、旁白框、拟声词）属于画内文字，应如实描写；字幕、水印、标题卡、旁白叠字属于画外文字，严禁出现
