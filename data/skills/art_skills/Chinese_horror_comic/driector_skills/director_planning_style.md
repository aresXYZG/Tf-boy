# 国产恐怖搞笑条漫约束 · 条漫风格 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以墨蓝（C4）、墨黑（C9）、冷灰（C7）为基底色，整体色温偏冷（6000-7000K），饱和度中低（40-60%惊悚段落），呈现暗色调惊悚的国产条漫基调
- **撞色叙事对比** — 惨绿（C5）、暗红（C3）、惨白（C8）作为叙事转折的视觉信号，用于灵异出现、情绪爆发与场景切换。撞色对比应与故事弧线同步，而非随意混用
- **冷暖分配策略** — 惊悚/灵异/压迫段落严格维持冷色调基底（墨蓝 C4 + 墨黑 C9 + 惨绿 C5），禁用暖黄、爆炸橙等暖色调；暖色仅在搞笑反差、日常段落、回忆段落释放，用冷暖对比做叙事转折
- **色盘先行原则** — 段落规划需先绑定情绪场景（日常都市/惊悚悬疑/鬼怪灵异/搞笑反差/战斗冲突/回忆怀旧/废弃恐怖），再确定主色+辅色与光影方案
- **禁用色域** — 高饱和荧光色、霓虹色、日系清新淡色、莫兰迪色均与本风格不兼容（灵异发光除外）

---

## 二、光影方案体系

- **光影即叙事** — 7 套光影方案对应不同情绪段落，导演规划阶段应在段落层面确定光影基调方向
- **国产条漫光影特征** — 细腻的明暗分界线、戏剧性光影、暗部占比大为核心手段；光影必须服务于情绪叙事，保持国产恐怖搞笑条漫的惊悚氛围

| 光影方案 | 方案名 | 色调倾向 | 适用情绪 |
|---|---|---|---|
| A | 日常平光 | 冷灰 C7 + 黄皮肤 C1 平涂 | 日常都市、搞笑反差、平静铺垫 |
| B | 硬侧高反差 | 墨黑 C9 + 暗红 C3 硬光分割 | 对峙压迫、愤怒冷峻、紧张对抗 |
| C | 低调冷光 | 墨蓝 C4 + 墨黑 C9 低调打光 | 悬疑紧张、废弃恐怖、孤独寂寥 |
| D | 灵异荧光 | 惨绿 C5 + 惨白 C8 发光 | 鬼怪灵异、异星场景、科技装置、被附身 |
| E | 暖光日常 | 土黄 C6 + 黄皮肤 C1 侧光 | 室内日间、日常起居、回忆怀旧 |
| F | 夜景灯火 | 土黄 C6 点缀 + 墨黑 C9 暗部 + 墨蓝 C4 | 夜生活、城市夜景、深夜街道 |
| G | 惊悚高光 | 惨白 C8 + 墨黑 C9 强光 | 鬼怪现身、惊悚瞬间、 jump scare |

- **冷暖光分配** — 暖色光（土黄 C6）适用于日常、搞笑、回忆段落；冷色光（墨蓝 C4 + 墨黑 C9 + 惨绿 C5）适用于惊悚、灵异、压迫段落。导演可根据叙事需要调整冷暖切换点
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述光影方案（A-G）的某一方向，确保视觉一致性

## 三、质感方向

- **细腻墨线为锚** — 国产恐怖搞笑条漫的核心：细腻墨线、写实与夸张结合、暗色调、惊悚氛围、条漫分镜感，呈现强烈的条漫手绘画面
- **面容与表情** — 面容写实细腻、表情夸张（惊恐时瞳孔放大、搞笑时五官变形）。表情是惊悚搞笑反差的核心载体
- **体型与比例** — 写实比例为主，搞笑角色可夸张变形。普通角色保持写实，鬼怪/灵异角色可非写实
- **服饰材质** — 衣物布料质感细腻、纹理细节清晰、布料折痕自然、衣物随动态飘逸。现代中国都市服饰（衬衫/西装/T恤/道袍/鬼怪服装）的面料质感须可信
- **场景材质** — 场景材质纹理细腻、空气透视、使用痕迹、老旧灰尘、乱中有序。混凝土/砖墙/木材/玻璃/金属质感均需在条漫风格下清晰呈现
- **条漫不等于扁平** — 国产恐怖搞笑条漫强调在平涂基础上叠加戏剧性光影与条漫分镜感，通过夸张构图与表情设计放大感染力

## 四、国产条漫场景空间元素

国产恐怖搞笑条漫世界观特有的场景元素及其视觉叙事功能：

- **老旧小区/胡同/城中村** — 惊悚感的天然载体，墙皮脱落、杂物堆积、昏暗路灯、狭窄空间。老旧与生活气息的结合 = 熟悉中的陌生感
- **废弃建筑/工地/地下室** — 恐怖感的天然舞台，倒塌墙壁、灰尘蛛网、黑暗角落、诡异回声。废弃 = 未知与恐惧
- **电梯/走廊/楼梯间** — 封闭空间惊悚的经典场景，电梯门开合、走廊尽头黑暗、楼梯间回声。封闭 = 压迫与无路可逃
- **镜子/倒影/水面** — 灵异元素的天然载体，镜中异象、倒影异常、水面浮现。镜像 = 另一个世界/自我
- **现代都市/写字楼/便利店** — 日常感的天然载体，繁华街景、明亮灯光、人来人往。日常 = 反差搞笑的基底
- **天台/屋顶/城市景观** — 英雄登场/沉思/对决的经典场景，城市景观为背景，栏杆/水塔/天线。天台 = 开阔与孤独
- **段落间用场景空镜过渡** — 本风格有丰富的场景资产（不同时段/天候变体），段落衔接建议用场景空镜做情绪缓冲，不要硬切。老旧小区走廊、废弃建筑全景、深夜街道均可作为过渡空镜
- **转折点用视觉而非台词** — 优先使用画面手段（光影突变、景别跳切、空镜隐喻、表情定格、灵异元素出现）而非依赖对白解释

## 五、国产条漫配乐与环境音

国产恐怖搞笑条漫世界观下的声音元素约束：

### 配乐乐器选择

- **钢琴** — 核心乐器，适用范围最广：惊悚段落的不和谐音程、搞笑段落的轻快旋律、情感段落的抒情旋律
- **弦乐（小提琴/大提琴/弦乐组）** — 情感铺底与升华，大提琴低沉适合压抑/惊悚，小提琴高音适合紧张/灵异，弦乐组适合情绪高潮
- **电子合成器** — 科幻/灵异场景的氛围铺底，低频电子pad用于太空/异星/灵异空间，不和谐电子音用于惊悚
- **打击乐** — 节奏核心，定音鼓/军鼓用于紧张和战斗，木鱼/铃铛用于灵异/道教元素，紧凑鼓点用于追逐/搞笑
- **笛子/箫/二胡** — 中国风乐器，用于古风/灵异/回忆段落，营造神秘和怀旧氛围
- **环境音/音效** — 灵异音效（鬼魂低语/诡异回声/心跳声）、搞笑音效（弹簧声/滑音/卡通音效）、日常环境音

### 配乐组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 日常/铺垫 | 轻钢琴 + 弦乐 或 吉他 + 轻打击乐 |
| 悬疑/紧张 | 不和谐钢琴 + 低频弦乐 + 电子氛围音 |
| 惊悚/灵异 | 不和谐弦乐 + 电子合成器 + 灵异音效 + 心跳声 |
| 搞笑/反差 | 轻快钢琴 + 滑稽打击乐 + 弹簧/滑音音效 |
| 战斗/爆发 | 弦乐全奏 + 打击乐全奏 + 铜管 |
| 回忆/怀旧 | 钢琴独奏 + 二胡/笛子 + 轻弦乐 |
| 都市夜景 | 电子氛围音 + 轻钢琴 + 轻打击乐 |
|  jump scare | 突然静默 + 刺耳音效 + 重击 |

### 国产条漫环境音

- **典型环境音层次** — 城市车流远声 / 老旧小区嘈杂声 / 电梯叮咚声 / 走廊脚步声 / 心跳声 / 呼吸声 / 鬼魂低语 / 诡异回声 / 玻璃碎裂声 / 门吱呀声 / 风声 / 电流滋滋声 / 木鱼声 / 铃铛声
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越丰富，国产条漫场景越有沉浸感
- **静默是惊悚核心** — 惊悚段落常用突然静默，只保留心跳声/呼吸声/脚步声，静默中的异响 = 最大惊悚
- **反差音效是搞笑核心** — 惊悚场景突然插入滑稽音效（弹簧声/卡通boing），反差本身就是笑点

## 六、视频生成工作流约束

- **关键帧先行** — 带文字画面（标题、对话气泡、旁白框、拟声词）必须先生成关键帧图片确认文字准确，再用图生视频
- **角色一致性锚定** — 每段视频prompt必须重复角色核心外观锚点（发型、服装主色、标志性特征）
- **分段生成** — 单段不超过15秒，长视频按叙事段落拆分
- **后期合成** — Logo/徽标/标语等品牌元素预留空位后期合成
- **惊悚搞笑反差** — 惊悚段落用暗色调+慢节奏+静默，搞笑段落用表情夸张+快节奏+滑稽音效，反差转场是核心
