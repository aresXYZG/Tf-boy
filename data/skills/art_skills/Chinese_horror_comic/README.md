# 国产恐怖搞笑条漫风格说明（中国惊奇先生画风版）

本风格专为**国产恐怖搞笑条漫风格**题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **国产条漫/漫画风格**：所有角色、场景、道具均以国产条漫为标准，强调细腻线条、写实与夸张结合、竖屏条漫构图、分镜格子布局。
- **都市恐怖+搞笑叙事背景**：涵盖现代都市灵异、僵尸鬼怪、惊悚悬疑、搞笑反差等，杜绝唯美古风/纯写实/低幼卡通元素。
- **条漫分镜感**：画面构图强调条漫分镜感，竖屏格子布局、对话气泡、旁白框、拟声词等元素可入画。
- **暗色调+惊悚氛围**：整体色调偏暗，冷暖对比强烈，突出惊悚与搞笑并存的氛围。

## 适用范围

- 国产恐怖搞笑条漫题材的AI美术生成（角色、场景、道具、分镜等）
- 都市灵异/僵尸鬼怪/惊悚悬疑动画风格的视觉创作
- 需要细腻线条、暗色调、惊悚氛围的视觉创作
- 品牌IP动画、科普宣传、灵异短剧等需要强风格感的项目

## 严禁内容

- 真人写实/摄影/3D渲染风格
- 低幼Q版/萌系/日系纯爱风格
- 唯美古风/仙侠/奇幻精灵风格（除非剧情需要的回忆段落）
- 直接使用受版权保护的特定漫画角色名或形象
- 过度血腥/恐怖/低俗/不适宜内容（惊悚氛围可以，但不能过度血腥）
- 暗示性、暴露、低俗等不适宜内容

## 风格体验

在本风格下，您将体验到：

- 角色面容写实细腻、表情夸张（惊恐时瞳孔放大、搞笑时五官变形），发型服饰符合现代中国都市
- 场景空间层次丰富，老旧小区/城中村/写字楼/胡同/废弃建筑，材质纹理细腻，氛围惊悚且富有生活气息
- 道具、装饰、灵异物品等均为国产条漫造型，工艺细腻，质感手绘感强
- 分镜与视频均以国产条漫为基础，强调叙事节奏与惊悚搞笑反差

## 视频生成工作流（关键帧+图生视频）

本风格推荐使用"关键帧先行"工作流，特别适用于带文字画面和角色一致性要求高的项目：

1. **关键帧生成**：对每段中带文字的关键画面（标题、对话气泡、旁白框、拟声词、标语等），先用文生图生成静态关键帧，确认文字准确无误
2. **图生视频**：将关键帧作为参考图传入视频生成工具，配合时间轴分镜prompt生成动态视频
3. **角色一致性锚定**：每段prompt中重复角色核心外观锚点（发型、服装主色、标志性特征），防止跨段角色漂移
4. **分段生成**：单段不超过15秒，长视频按叙事段落拆分后拼接
5. **后期合成**：Logo/徽标/标语等品牌元素在视频中预留空位，后期合成
