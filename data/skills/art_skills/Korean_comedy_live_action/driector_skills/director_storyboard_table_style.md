# 分镜表搞笑韩剧真人版约束 · 真人韩剧风格 · 技法参考

---

## 一、分镜表定位

分镜表是导演将剧本转化为镜头语言的核心工具。以下仅提供搞笑韩剧真人版风格在分镜表层面的约束规范。

---

## 二、光影与氛围

- **同场戏光影统一** — 一场戏内不应出现两种以上光影方案，除非有明确的叙事转折（如室内灯光切换→窗外暮色渐深、门打开→暖光涌入、初雪飘落→浪漫光）
- **情绪色盘绑定** — 每场戏至少绑定 1 个情绪场景（搞笑反应/浪漫约会/日常都市/职场喜剧/家庭温馨/街头偶遇/害羞心动/幻想梦境），并在镜头组内保持主色+辅色连续性
- **光源角度规范** — 正给镜头光源默认柔和韩剧布光或暖光，侧给镜头根据画面需要调整。描述光影时须区分自然光（窗光/阳光/月光）与人造光（灯光/屏幕光/路灯/暖光）的差异
- **冷暖色调与叙事阶段匹配** — 日常/搞笑/家庭/职场段落严格使用暖色调（柔和黄 C5 + 暖白肤 C1 + 温暖橙 C4），浪漫/心动/梦境段落增加浪漫粉 C3 + 温柔紫 C8；冷色仅在特定场景（雨夜/初雪/清晨）使用
- **光影转场是高级手段** — 从窗外自然光渐变到室内暖灯光 = 日转夜的时间流逝；从明亮办公室到温馨咖啡馆 = 情绪转折；从正常光到梦幻柔光 = 幻想开始。在分镜表中标注光影变化点
- **发光元素是叙事工具** — 屏幕/暖灯/咖啡杯热气/蜡烛/夕阳的状态变化（亮→灭、正常→浪漫、暖光→梦幻）可作为叙事信号，在分镜表中标注发光状态变化点
- **柔和暖调是核心** — 明暗反差必须适中，暗部占比根据情绪调整（日常30-40%、浪漫40-50%、夜景50-60%、搞笑20-30%）

## 三、环境动态

- **环境动态增加画面呼吸感** — 灯光闪烁、灰尘飘落、咖啡杯热气、窗帘轻摆、樱花飘落、初雪簌簌、雨丝、风铃、头发飘动。每 2-3 个镜头至少安排一个有环境动态的镜头，避免画面"死"掉
- **韩剧环境元素优先** — 环境动态应选用搞笑韩剧真人版世界观内的元素：咖啡杯热气、樱花飘落、初雪簌簌、雨丝、窗帘轻摆、风铃、头发飘动、韩文招牌闪烁、汉江波浪、树叶沙沙、筷子碰撞声，禁止出现古风/奇幻/暗黑元素
- **韩剧级动态表现** — 环境动态应符合韩剧的表现方式：樱花飘落的慢动作、初雪的柔和感、咖啡杯热气的朦胧感、雨丝的反光、头发飘动的自然感
- **夸张环境动态是搞笑工具** — 韩剧常用夸张环境动态强化效果：搞笑时背景静止/人物夸张、浪漫时樱花/初雪突然飘落、心动时周围虚化/光晕。在分镜表中标注此类夸张环境变化

---

## 四、韩剧人物动作节奏

- **动作要符合情绪** — 搞笑时动作夸张/快速/变形，浪漫时动作缓慢/温柔/细腻，日常时动作自然/放松。关键动作（转身、抬手、奔跑、跌倒、害羞）标注情绪对应的速度和幅度
- **服饰动态** — 韩剧服饰（外套下摆、围巾、连衣裙、头发）的动态是天然的画面资产，可在画面描述中加入衣物随风/随动作的飘动，增加画面的"活"感。头发飘动是韩剧浪漫场景的标志性元素
- **仪态约束** — 韩剧角色的举止应符合角色性格：阳光角色挺胸/高冷角色含胸/呆萌角色放松/搞笑角色夸张。不出现标准化的"优雅克制"仪态
- **表情优先于动作** — 以面部夸张搞笑表情（震惊时眼睛瞪大、搞笑时五官变形、害羞时脸红）传达情绪，表情幅度必须大但真实。肢体动作为表情和情绪服务
- **预备-动作-反应三段式** — 韩剧动作遵循经典三段式：预备（蓄力/表情变化/肌肉绷紧）→ 动作（执行/夸张/速度）→ 反应（定格/夸张后果/表情变化）。在分镜表中拆解动作时遵循此节奏
- **慢动作的浪漫功能** — 升格在韩剧中用于"关键瞬间"：初雪飘落、樱花飞舞、雨中偶遇、害羞心动、浪漫对视、搞笑跌倒——慢动作让观众有足够时间感受浪漫或搞笑，冲击力在慢动作中积蓄
- **韩剧经典动作库** — 经典韩剧动作：害羞低头/眼神躲闪/手摸脸颊/心跳加速、浪漫对视/慢动作/头发飘动、搞笑跌倒/夸张反应/弹簧效果、偶遇定格/眼睛瞪大/手捂嘴巴、花痴爱心眼/双手合十/追星状
- **搞笑动作库** — 经典搞笑动作：滑倒/撞墙/被吓跳起来/夸张逃跑/表情定格/慢动作跌倒/弹簧效果/搞笑追逐。搞笑动作要快节奏、夸张幅度、配合滑稽音效

## 五、运镜禁忌

- **运镜要服务于韩剧节奏** — 韩剧运镜可以比其他风格更灵活，但必须服务于温馨感和搞笑节奏
- **固定 = 日常/冷静/搞笑反应** — 日常场景、对话场景、搞笑反应用固定机位，稳定感。固定后的突然变化 = 最大搞笑或心动
- **缓慢推进 = 浪漫/心动 buildup** — 浪漫/心动段落常用缓慢推进，让观众逐渐靠近浪漫源，温馨感逐渐积累。这是韩剧浪漫场景中最高频的运镜之一
- **急推 = 反应放大/情绪爆发/关键瞬间** — 某个角色看到/听到关键信息，快速推向其面部，放大"震惊/害羞/搞笑"的反应。关键瞬间时急推强化冲击力
- **甩镜 = 信息揭示/偶遇转折/搞笑** — 从角色A迅速甩到角色B/偶遇对象/搞笑元素，速度本身带有"等等！那是谁？！"的紧张感或搞笑感
- **跟随 = 追逐/移动/日常** — 追逐戏、角色移动、日常行走，用跟随运镜，保持角色在画面中心，背景流动
- **过肩 = 对话/浪漫/对视** — 韩剧对话/浪漫场景常用过肩镜头，增加代入感和亲密感
- **框架构图 = 韩剧经典/浪漫/沉思** — 韩剧常用框架构图（窗户/门框/镜子），增加画面层次和浪漫感
- **Dutch角 = 搞笑/紧张/怪诞** — 倾斜构图用于搞笑场景、紧张情绪、怪诞感。韩剧常用Dutch角强化搞笑和怪诞感
- **运镜即节奏** — 固定 = 日常/冷静；缓慢推进 = 浪漫 buildup；急推 = 反应放大；甩镜 = 信息揭示；跟随 = 追逐/移动；过肩 = 对话/浪漫；框架构图 = 韩剧经典；Dutch角 = 搞笑/怪诞
- **不要过度运镜** — 日常和浪漫段落保持稳定，搞笑和关键瞬间可以灵活运镜。运镜过多会分散对角色和情绪的注意力

## 六、转场设计

- **硬切为主** — 韩剧场景内剪辑节奏偏快，硬切为主，不拖泥带水
- **浪漫转场** — 从日常场景硬切到浪漫场景，反差本身就是浪漫效果。常用：初雪突然飘落、樱花飞舞、门打开→暖光涌入、对视→慢动作
- **搞笑转场** — 从日常/浪漫突然硬切到搞笑夸张，反差本身就是笑点。常用：表情定格→搞笑跌倒、浪漫音乐→滑稽boing、对视→搞笑喷嚏
- **光影转场** — 用光影变化做转场：灯光熄灭→全黑→亮起新场景、暖光涌入→过曝→新场景、梦幻柔光→充满画面→新场景
- **匹配剪辑** — 用形状/动作/颜色匹配做转场：咖啡杯→月亮、眼睛→爱心、粉色→樱花、奔跑→追逐
- **假正经转场** — 用正式/庄重的转场方式（淡入淡出、字幕卡"Meanwhile"、光圈转场）来过渡搞笑/浪漫内容，反差出戏剧感
- **慢动作转场** — 用慢动作做转场：初雪飘落慢动作→正常速度日常、浪漫对视慢动作→正常速度搞笑
- **韩剧经典转场** — 初雪/樱花/雨夜作为转场元素，从一个场景飘到另一个场景，增加韩剧感
- **打破第四面墙** — 角色突然看向镜头/对观众说话的瞬间用正面近景+突然静止，制造"你看到了吧？"的共谋感或搞笑感

## 七、文字画面处理

- **带文字画面必须关键帧先行** — 标题、拟声词、标语、招牌、韩文标识、屏幕显示等带文字画面，必须先生成关键帧图片确认文字准确，再用图生视频
- **关键帧作为参考图** — 生成的关键帧图片作为图生视频的参考图传入，文字准确性由关键帧保障
- **视频prompt仍需描述文字** — 视频prompt中仍需描述文字内容和位置，但不依赖视频模型直接生成文字
- **韩文标识/招牌是核心元素** — 韩剧场景的韩文标识、招牌是标志性元素，文字必须清晰可辨，建议先生成关键帧确认文字
- **拟声词是韩剧搞笑核心** — 搞笑用"哐当""噗""啊——""boing"，浪漫用心跳声"扑通"，拟声词必须先生成关键帧确认文字准确
- **品牌元素后期合成** — Logo/徽标/官方标语等品牌元素建议在视频中预留空位，后期合成（AI直接画品牌物易乱码）
- **画内文字 vs 画外文字** — 故事世界内的道具文字（韩文标识、招牌、屏幕显示、标语、海报）属于画内文字，应如实描写；字幕、水印、标题卡、旁白叠字属于画外文字，严禁出现
