# 搞笑韩剧真人版约束 · 真人韩剧风格 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以柔和黄（C5）、暖白肤（C1）、中性灰（C10）为基底色，整体色温偏暖（4500-5500K），饱和度中高（50-70%），呈现柔和暖调的韩剧基调
- **撞色叙事对比** — 浪漫粉（C3）、温暖橙（C4）、温柔紫（C8）作为叙事转折的视觉信号，用于浪漫约会、害羞心动、幻想梦境与搞笑反应。撞色对比应与故事弧线同步，而非随意混用
- **冷暖分配策略** — 日常/职场/街头段落维持暖色调基底（柔和黄 C5 + 暖白肤 C1 + 天空蓝 C7），浪漫/心动/梦境段落增加浪漫粉 C3 + 温柔紫 C8；冷色仅在特定场景（雨夜/初雪/清晨）使用，用冷暖对比做叙事转折
- **色盘先行原则** — 段落规划需先绑定情绪场景（搞笑反应/浪漫约会/日常都市/职场喜剧/家庭温馨/街头偶遇/害羞心动/幻想梦境），再确定主色+辅色与光影方案
- **禁用色域** — 高对比硬光、冷调暗黑、低饱和灰调、莫兰迪色、高饱和荧光色均与本风格不兼容

---

## 二、光影方案体系

- **光影即叙事** — 7 套光影方案对应不同情绪段落，导演规划阶段应在段落层面确定光影基调方向
- **韩剧光影特征** — 柔和光影、浅景深、暖色调、韩剧布光、温馨浪漫为核心手段；光影必须服务于情绪叙事，保持韩剧的温馨感

| 光影方案 | 方案名 | 色调倾向 | 适用情绪 |
|---|---|---|---|
| A | 日常柔光 | 柔和黄 C5 + 暖白肤 C1 平涂 | 日常都市、职场喜剧、平静铺垫 |
| B | 浪漫暖光 | 浪漫粉 C3 + 柔和黄 C5 暖光 | 浪漫约会、害羞心动、甜蜜、初雪/樱花 |
| C | 搞笑明亮 | 温暖橙 C4 + 柔和黄 C5 明亮 | 搞笑反应、夸张、喜剧、快节奏 |
| D | 温馨家庭 | 柔和黄 C5 + 温暖橙 C4 暖光 | 家庭温馨、温暖、日常、生活气息 |
| E | 街头自然光 | 天空蓝 C7 + 清新绿 C6 + 柔和黄 C5 | 街头偶遇、日常、都市、巧合 |
| F | 夜景暖光 | 柔和黄 C5 + 深棕 C9 + 浪漫粉 C3 | 夜生活、城市夜景、浪漫、温馨 |
| G | 梦幻柔光 | 温柔紫 C8 + 浪漫粉 C3 + 柔和黄 C5 | 幻想/梦境、花痴、迷恋、超现实 |

- **冷暖光分配** — 暖色光（柔和黄 C5 + 温暖橙 C4 + 浪漫粉 C3）适用于日常、搞笑、浪漫、家庭段落；冷色光（天空蓝 C7）仅在室外日常/特定场景使用。导演可根据叙事需要调整冷暖切换点
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述光影方案（A-G）的某一方向，确保视觉一致性

## 三、质感方向

- **韩剧真实为锚** — 搞笑韩剧真人版的核心：柔和光影、浅景深、暖色调、真实材质、皮肤质感细腻、韩剧级妆容，呈现强烈的韩剧画面
- **面容与表情** — 面容真实立体、表情夸张搞笑（震惊时眼睛瞪大、搞笑时五官变形、害羞时脸红），皮肤质感细腻，韩剧级妆容
- **体型与比例** — 写实比例为主，7-8头身，真实比例，韩剧审美。不胖不瘦或健美，避免过度夸张
- **服饰材质** — 衣物布料质感真实、纹理细节清晰、布料折痕自然、衣物随动态飘逸。韩剧时尚（oversize外套/阔腿裤/卫衣/连衣裙/风衣/针织衫）的面料质感须可信
- **场景材质** — 场景材质纹理真实、空气透视、使用痕迹、生活气息、乱中有序。木材/玻璃/金属/布料质感均需在韩剧级光影下清晰呈现
- **韩剧不等于纪录片** — 搞笑韩剧真人版强调在真实基础上叠加柔和光影与韩剧级构图，通过暖色调与浅景深放大温馨浪漫感

## 四、韩剧场景空间元素

搞笑韩剧真人版世界观特有的场景元素及其视觉叙事功能：

- **温馨公寓/家庭** — 温馨感的天然载体，暖光/可爱装饰/个人物品/生活气息。温馨公寓 = 日常与浪漫的舞台
- **咖啡馆/餐厅** — 浪漫感的天然载体，暖光/浅景深/咖啡杯/食物/温馨氛围。咖啡馆 = 约会与偶遇的舞台
- **韩国城市街道/明洞** — 日常感的天然载体，韩文标识/商店/招牌/人群/垃圾。城市街道 = 日常与搞笑的舞台
- **汉江边/公园** — 浪漫感的天然载体，汉江/栏杆/步道/夕阳/夜景/初雪。汉江边 = 浪漫与沉思的舞台
- **初雪/樱花/雨夜** — 韩剧经典场景，初雪/樱花飘落/雨丝/路灯/雨伞/浪漫氛围。经典场景 = 浪漫与心动的标志
- **职场办公室** — 喜剧感的天然载体，办公桌/电脑/文件/落地窗/城市景观。办公室 = 职场喜剧与日常的舞台
- **屋顶/天台** — 浪漫/沉思的经典场景，城市景观/夕阳/夜景/栏杆。天台 = 浪漫与沉思的舞台
- **段落间用场景空镜过渡** — 本风格有丰富的场景资产（不同时段/天候变体），段落衔接建议用场景空镜做情绪缓冲，不要硬切。温馨公寓、咖啡馆、汉江边均可作为过渡空镜
- **转折点用视觉而非台词** — 优先使用画面手段（光影突变、景别跳切、空镜隐喻、表情定格、初雪/樱花飘落）而非依赖对白解释

## 五、韩剧配乐与环境音

搞笑韩剧真人版世界观下的声音元素约束：

### 配乐乐器选择

- **钢琴** — 核心乐器，适用范围最广：搞笑段落的轻快旋律、浪漫段落的抒情旋律、日常段落的温馨旋律
- **弦乐（小提琴/大提琴/弦乐组）** — 情感铺底与升华，小提琴高音适合浪漫/心动，大提琴低沉适合温馨/日常，弦乐组适合情绪高潮
- **吉他（木吉他/电吉他）** — 日常/搞笑/青春场景的核心，木吉他适合日常/温馨，电吉他适合搞笑/夸张
- **合成器/电子** — 搞笑/幻想/梦境场景的氛围铺底，轻快电子音适合搞笑，梦幻合成器适合幻想/梦境
- **打击乐** — 节奏核心，轻快打击乐适合搞笑/日常，定音鼓适合情绪高潮
- **口哨/口琴** — 韩剧搞笑/日常常用，轻快口哨适合搞笑，口琴适合温馨/日常
- **环境音/音效** — 搞笑音效（弹簧声/滑音/卡通音效）、浪漫音效（心跳声/风铃/钢琴音）、日常环境音

### 配乐组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 搞笑反应/夸张 | 轻快钢琴 + 木吉他 + 搞笑打击乐 + 口哨/弹簧音效 |
| 浪漫约会/心动 | 钢琴抒情 + 弦乐 + 轻打击乐 + 心跳音效 |
| 日常都市/平静 | 轻钢琴 + 木吉他 + 轻弦乐 |
| 职场喜剧/轻松 | 轻快钢琴 + 木吉他 + 轻打击乐 + 搞笑音效 |
| 家庭温馨/温暖 | 钢琴 + 弦乐 + 口琴 + 轻打击乐 |
| 街头偶遇/巧合 | 木吉他 + 轻钢琴 + 轻打击乐 |
| 害羞心动/甜蜜 | 钢琴 + 小提琴 + 心跳音效 + 风铃 |
| 幻想/梦境/花痴 | 梦幻合成器 + 钢琴 + 弦乐 + 梦幻音效 |

### 韩剧环境音

- **典型环境音层次** — 城市车流远声 / 咖啡馆嘈杂声 / 韩语对话背景声 / 汉江风声 / 初雪簌簌声 / 樱花飘落声 / 雨丝声 / 心跳声 / 呼吸声 / 咖啡杯碰撞声 / 碗筷声 / 门铃叮咚声 / 手机震动声
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越丰富，韩剧场景越有沉浸感
- **静默是浪漫核心** — 浪漫/心动段落常用突然静默，只保留心跳声/呼吸声/风声，静默中的异响 = 最大心动
- **搞笑音效是喜剧核心** — 搞笑段落常用滑稽音效（弹簧声/滑音/卡通boing/夸张音效），音效本身就是笑点

## 六、视频生成工作流约束

- **关键帧先行** — 带文字画面（标题、拟声词、标语、招牌、韩文标识等）必须先生成关键帧图片确认文字准确，再用图生视频
- **角色一致性锚定** — 每段视频prompt必须重复角色核心外观锚点（发型、服装主色、标志性特征）
- **分段生成** — 单段不超过15秒，长视频按叙事段落拆分
- **后期合成** — Logo/徽标/标语等品牌元素预留空位后期合成
- **韩剧经典场景处理** — 初雪/樱花/雨夜/汉江边/咖啡馆等韩剧经典场景必须用柔光、浅景深、慢动作、暖色调处理
