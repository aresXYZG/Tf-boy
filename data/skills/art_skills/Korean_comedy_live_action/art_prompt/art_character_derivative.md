# 搞笑韩剧真人版人物衍生资产生成 · 约束手册

---

## 一、叠加原则

1. **面容不变** — 叠加后五官必须与底模完全一致，禁止面容偏移
2. **姿态不变** — 保持底模自然站立姿态，禁止任何姿态/动作/体态变化
3. **逐层可控** — 每层独立描述，便于按层替换（换装不换妆）
4. **风格统一** — 所有服化元素服从同一搞笑韩剧真人版美学体系
5. **质感不降** — 叠加后质感标准不低于底模
6. **纯服化范畴** — 仅叠加妆容/发型/服饰/配饰/鞋履，禁止引入道具、场景、环境、动作

---

## 二、叠加层级

| 层级 | 内容 | 说明 |
|---|---|---|
| L0 | 底模 | 基础形象底模，不修改 |
| L1 | 表情/妆容（决策层） | 先分析用户线索，再决策表情强度与妆容风格 |
| L2 | 发型造型 | 发型变化/发饰/帽子/头饰 |
| L3 | 内搭 | 替换基础内搭 |
| L4 | 外衣/主服 | 差异化服装（西装/休闲/连衣裙/风衣/针织衫等） |
| L5 | 配饰 | 眼镜/手表/项链/背包/耳环/围巾等 |
| L6 | 鞋履 | 运动鞋/皮鞋/高跟鞋/靴子等，与整体服装完整配套 |

> **范畴边界**：人物衍生资产仅包含 L0–L6 层级（服化妆造），不包含手持道具（手机/咖啡杯/雨伞/包包等属于道具资产）、场景环境、姿态动作。

### 差异化着装原则

| 项目 | 约束 | 说明 |
|---|---|---|
| 角色区分 | 根据年龄、职业、性格、经济条件决定穿搭风格与配色 | 禁止所有角色同款同色同搭配 |
| 同风格差异 | 即使同为日常装，也要区分款式/颜色/配饰 | 保持统一审美，不做制服化处理 |
| 场景适配 | 通勤/约会/居家/正式/校园分别切换服装方案 | 服装应随情境变化而变化 |
| 主服色固定 | 每个角色有1-2个固定主服色，跨场景保持识别 | 主服色是角色识别核心 |
