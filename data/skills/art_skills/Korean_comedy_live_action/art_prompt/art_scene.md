# 搞笑韩剧真人版场景图生成 · 约束手册

---

## 一、场景美学原则

1. **空间叙事** — 场景承载情绪与叙事功能，不是纯背景板，可加入温馨/搞笑/浪漫元素
2. **层次纵深** — 所有场景必须具备前/中/后景，杜绝扁平
3. **质感真实** — 材质纹理必须清晰（金属/玻璃/木材/布料/墙面/混凝土），韩剧级真实质感
4. **柔和光影为锚** — 所有画面以搞笑韩剧真人版风格为标准，强调柔和光影、浅景深、暖色调、真实材质
5. **柔和暖调光影** — 光影服务于情绪，保持柔和暖调基调，明暗反差适中，温馨浪漫氛围
6. **现代韩国都市+温馨混搭** — 本风格场景常出现现代韩国都市场景与温馨元素的混搭，制造韩剧感与浪漫氛围

## 五、主视图规范

### 视图定义

> 单画面主视图，从场景中最具代表性的角度拍摄，承载空间叙事与构图重心。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 自然观察视角或韩剧经典角度，构图最能体现场景主体与纵深 | `hero shot`、`representative angle`、韩剧经典角度 |
| 视点高度 | 默认人眼平视高度，浪漫场景常用略低角度，搞笑场景可用夸张角度 | `eye level`（默认）/ `slightly low angle` / `exaggerated angle` |
| 构图 | 主体居中或符合三分法，前/中/后景层次清晰，可加入温馨/浪漫/搞笑元素 | `balanced composition`、韩剧级构图 |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 风格/材质/色调/光线统一 |
| 光线 | 单一光源逻辑或多光源混合（温馨/浪漫场景），光影方向一致 |
| 画面比例 | 默认 16:9 横屏或 9:16 竖屏（韩剧推荐竖屏） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次」 |
| R2 | 室外必须包含「空气透视」 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能代表场景主体并展示前/中/后景层次 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含「搞笑韩剧真人版风格」+「柔和光影」+「浅景深」+「暖色调」+「真实材质」+「韩剧大片质感」关键词 |
| R7 | 材质必须带有使用痕迹/生活气息，禁止全新无瑕的"3D渲染感" |
| R8 | 温馨/浪漫/搞笑场景必须有至少一个非日常元素（暖光/可爱装饰/浪漫氛围/搞笑构图） |
| R9 | 柔和暖调是核心——明暗反差必须适中，温馨浪漫氛围 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑/无场景 |
| X2 | 极端天候（暴风雨/雷电/暴雪，除非剧情需要） |
| X3 | 场景无纵深/无层次 |
| X4 | 植被/天候与季节/场景矛盾 |
| X5 | 出现任何人物、人影、人体剪影或人体轮廓 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 卡通/动画/漫画/手绘风格（除非明确要求风格化） |
| X8 | 材质过于干净完美、无任何使用痕迹与岁月感 |
| X9 | 光照过于均匀平坦、无景深虚化、无镜头光学特征 |
| X10 | 低幼Q版/萌系/日系纯爱风格 |
| X11 | 高对比硬光/冷调暗黑/低饱和灰调 |
| X12 | 暗黑/恐怖/血腥/暴力/沉重压抑内容 |
