# 搞笑韩剧真人版场景衍生资产生成 · 约束手册

---

## 一、衍生原则

1. **空间一致** — 建筑结构/布局/材质在所有变体中保持一致
2. **景别驱动** — 同一场景通过不同景别展示不同叙事功能
3. **时段切换** — 同一空间在不同时间段呈现不同光影氛围
4. **天候变化** — 同一空间在不同天气下呈现不同情绪
5. **风格统一** — 所有变体必须保持搞笑韩剧真人版风格，柔和光影、浅景深、暖色调、真实材质

---

## 二、景别变体

### 景别定义

| 景别 | 范围 | 叙事功能 | 提示词 |
|---|---|---|---|
| 大全景 | 场景全貌 + 周围环境 | 建立空间感、定位、展示城市/街区规模 | `extreme wide shot`、大全景 |
| 全景 | 场景完整呈现 | 展示空间结构、角色活动范围 | `wide shot`、全景 |
| 中景 | 场景局部区域 | 聚焦功能区、互动区域 | `medium shot`、中景 |
| 近景 | 场景细部 | 材质/氛围道具/可爱装饰特写 | `close shot`、近景 |
| 特写 | 极局部细节 | 材质纹理/关键道具/可爱装饰/发光元件 | `extreme closeup`、特写 |

### 景别衍生规范

| 从基准图衍生 | 保持不变 | 允许变化 |
|---|---|---|
| 大全景 → 全景 | 建筑外观、整体布局 | 视角收窄、前景增加 |
| 全景 → 中景 | 材质、色调、光线 | 裁切聚焦、景深变化 |
| 中景 → 近景 | 材质、色调 | 景深浅、背景虚化 |
| 近景 → 特写 | 材质纹理 | 极浅景深、微距感 |

## 三、时段变体

### 时段定义

| 时段 | 视觉特征 | 提示词 |
|---|---|---|
| 清晨/黎明 | 暖白光调、薄雾感、城市苏醒、金色曙光 | 晨光微熹、清晨薄雾、暖光、金色曙光 |
| 正午 | 明亮、阴影短、色彩自然、暖色调 | 正午阳光、光线明亮、暖色调 |
| 黄昏/傍晚 | 温暖橙色调、长影、天空渐变温暖橙/柔和黄、金色余晖 | 暮色温暖、golden hour、长影柔和、金色余晖 |
| 夜间（月光） | 暖黄色调、幽静温馨、星星可见、月光柔和 | 月光清辉、moonlight、暖黄夜色 |
| 夜间（灯火） | 暖黄/路灯点缀、明暗对比、城市灯光、温馨、浪漫 | 灯火阑珊、路灯光、灯光氛围、温馨、浪漫 |
| 凌晨 | 暖灰调、雾气柔和、最暗时刻、城市苏醒前 | 凌晨暖光、雾气柔和、最暗时刻 |
| 室内（温馨） | 暖光环境、装置发光、柔和光影、韩剧布光、暖调 | 温馨室内、暖光环境、柔和光影、韩剧布光 |
| 搞笑/夸张 | 明亮暖光、夸张构图、高饱和、快节奏、韩剧搞笑 | 搞笑氛围、明亮暖光、夸张构图、韩剧搞笑 |

### 时段衍生规范

| 从基准时段衍生 | 保持不变 | 变化项 |
|---|---|---|
| 日间 → 黄昏 | 建筑/布局/材质 | 天空色调温暖化、影子拉长、暗部柔和、金色余晖 |
| 日间 → 夜间 | 建筑/布局/材质 | 整体变暗、增加路灯/月色/暖光/温馨氛围 |
| 室内日间 → 室内夜间 | 空间结构、家具 | 整体色调暖化、增加室内灯光/暖光/局部光源 |
| 正常 → 搞笑 | 建筑/布局 | 增加明亮暖光、夸张构图、高饱和、搞笑元素 |

## 五、角度变体

### 角度定义

| 角度 | 描述 | 提示词 |
|---|---|---|
| 正面/前视 | 与参考图相比，视线朝向场景正面 | `front view`、`eye level` |
| 侧面（左/右） | 朝场景左/右侧 90° 平视 | `left side view` / `right side view` |
| 背面/后视 | 朝场景背面 180° | `back view` |
| 俯视 | 高位俯瞰，呈现整体布局/城市全貌/街区 | `high angle`、`bird's eye view` |
| 仰视 | 低位仰望，强调高大主体/建筑/浪漫氛围 | `low angle`、`worm's eye view` |
| Dutch角 | 倾斜构图，制造搞笑/紧张/怪诞感 | `dutch angle`、倾斜构图 |
| 鱼眼 | 极端广角，边缘扭曲，制造搞笑/超现实感 | `fisheye`、鱼眼透视 |
| 近景推进 | 同方向但镜头推进，聚焦局部 | `push-in`、`closer angle` |
| 韩剧经典角度 | 略低角度/过肩/框架构图，韩剧常用 | `Korean drama angle`、韩剧经典角度 |
| 自由角度 | 调用方自定义的任意角度描述 | 按 `{目标角度}` 注入 |

### 角度衍生规范

| 项目 | 约束 |
|---|---|
| 参考一致性 | 建筑结构/布局/材质/色调/光线/季节/天候必须与参考图一致 |
| 视点 | 同一场景中心点，仅角度切换；视线高度可随角度调整 |
| 光照逻辑 | 参考图光源方向不变，角度切换后光影投射方向需同步重算 |
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 画面比例 | 默认 16:9 横屏或 9:16 竖屏（韩剧推荐竖屏） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景空间结构在所有变体中保持一致 |
| R2 | 时段变体必须调整天空色调与氛围 |
| R3 | 天候变体必须适配植被/材质表面 |
| R4 | 衍生图必须为「单画面」，不得拼接多视图/网格/分屏 |
| R5 | 衍生图必须与参考图保持建筑结构/材质/色调/光线一致，仅按指定角度切换视点 |
| R6 | 场景图中**严禁出现任何人物** |
| R7 | 根据用户提供的信息自行判断变化维度，未提及维度留空省略 |
| R8 | 必须包含「搞笑韩剧真人版风格」+「柔和光影」+「浅景深」+「暖色调」+「真实材质」+「韩剧大片质感」关键词 |
| R9 | 材质必须带有使用痕迹/生活气息，禁止全新无瑕的"3D渲染感" |
| R10 | 温馨/浪漫/搞笑变体必须有至少一个非日常元素 |
| R11 | 柔和暖调是核心——明暗反差必须适中，温馨浪漫氛围 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 变体间建筑结构/布局不一致 |
| X2 | 天候与季节矛盾（夏天飞雪等，韩剧经典场景除外） |
| X3 | 变体间材质/风格突变 |
| X4 | 出现任何人物、人影、人体剪影或人体轮廓 |
| X5 | 画面被拼接成多视图/网格/分屏布局 |
| X6 | 卡通/动画/漫画/手绘风格（除非明确要求风格化） |
| X7 | 材质过于干净完美、无任何使用痕迹与岁月感 |
| X8 | 光照过于均匀平坦、无景深虚化、无镜头光学特征 |
| X9 | 低幼Q版/萌系/日系纯爱风格 |
| X10 | 高对比硬光/冷调暗黑/低饱和灰调 |
| X11 | 暗黑/恐怖/血腥/暴力/沉重压抑内容 |
