# 搞笑韩剧真人版道具衍生状态生成 · 约束手册

---

## 一、衍生原则

### 文书/告示/纸条类道具文字排版规则（必守）
若道具为文书、告示、纸条、清单、便签、规章制度、卡片等包含明确文字内容的道具：
1. **双引号逐字精准输出**：在提示词中必须使用双引号将文字标题与核心条款逐字精准标出（例如：包含清晰可见的书法/印刷文字标题 "【顾客须知】" 以及逐条清晰排版的规则内容 "1. 禁止投喂" "2. 违者后果自负"）。
2. **文字排版与可读性**：必须明确描述文字的字迹风格（如：深黑墨迹手写体 / 醒目印刷体 / 红色印章）、纸张折痕与排版布局（居中大标题、分行条例清晰、段落整齐），确保生图模型精准逐字渲染，严禁模糊乱码或乱画无意义字符。


1. **造型锚定** — 道具核心造型/轮廓在所有状态中可识别
2. **状态可读** — 状态差异必须一目了然，观众能立即区分
3. **叙事服务** — 每种状态变体服务于特定剧情节点
4. **渐进退化** — 损伤/老化状态应有合理的物理逻辑，可夸张表现
5. **纯道具独立展示** — 画面中只能出现道具本身，严禁出现任何人物、手部、肢体

## 二、状态类型

### 2.1 使用状态

| 状态 | 描述 | 适用道具 | 提示词 |
|---|---|---|---|
| 崭新 | 完好无损、光泽如新、标签未撕 | 所有道具 | 崭新、完好无损、光泽如新 |
| 日常使用 | 微磨损、自然包浆、贴纸/刮痕 | 手机/电脑/个人物品/生活器物 | 日常使用痕迹、自然磨损、刮痕 |
| 陈旧 | 明显年代感、色泽暗淡、灰尘/蛛网 | 老旧物品/古董/废弃物品 | 古旧斑驳、年代感、色泽暗沉、灰尘 |
| 可爱装饰 | 加入可爱装饰/贴纸/挂件/韩剧时尚 | 手机/电脑/个人物品/时尚配饰 | 可爱装饰、贴纸、挂件、韩剧时尚 |

| 状态 | 描述 | 适用道具 | 提示词 |
|---|---|---|---|

| 破损 | 明显裂缝/断裂/破碎/屏幕碎裂/凹陷 | 玻璃/陶瓷/塑料/电子设备 | 裂缝明显、碎裂、断裂、屏幕碎裂、凹陷 |
| 残片 | 仅剩部分/碎片/烧焦残骸/断裂残端 | 玻璃/陶瓷/电子设备/木质 | 残片、碎片、仅存半块、烧焦残骸 |
| 搞笑破损 | 夸张破损/变形/搞笑痕迹/韩剧搞笑风格 | 搞笑道具/日常道具 | 搞笑破损、夸张变形、搞笑痕迹、韩剧搞笑 |

## 三、状态变体画面规范

### 单状态图

| 项目 | 约束 |
|---|---|
| 背景 | 纯净中性灰 `#C0C0C0` 或摄影棚渐变背景（与设定图一致） |
| 光线 | 柔和韩剧布光，前方主光 + 侧逆光 + 轮廓光，浅景深，暖色调，自然阴影 |
| 角度 | 与原设定图正面图一致 |
| 比例 | 道具占画面主体 70%+ |

### 状态对比图

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面并排展示 2-3 种状态 |
| 标注 | 每种状态下方标注状态名（如需要） |
| 一致性 | 角度/光线/背景完全一致，仅状态不同 |

## 四、材质状态变化规则

| 材质 | 崭新 → 日常 | 日常 → 陈旧 | 损伤表现 | 激活/发光表现 |
|---|---|---|---|---|
| 金属 | 亮光泽 → 微划痕 | 划痕 → 氧化/锈迹 | 缺口/卷边/断裂/凹陷/烧焦 | 高温红热、电流乱窜、反光增强 |
| 玻璃 | 通透清晰 → 微划痕 | 划痕 → 裂纹/碎裂 | 裂纹/碎裂/缺口/碎片 | 内部发光、屏幕亮起、反光增强 |
| 木材 | 新木纹理 → 自然包浆 | 包浆 → 色泽暗沉/干裂 | 开裂/虫蛀/磨损/烧焦/断裂 | 温度升高、光泽变化 |
| 塑料 | 崭新平整 → 微划痕 | 划痕 → 老化变色 | 裂纹/变形/褪色/融化/烧焦 | 按钮发光、屏幕透光、警告灯闪烁 |
| 布料 | 崭新平整 → 微褶皱 | 褶皱 → 褪色/磨损 | 撕裂/烧焦/污渍/食物残留 | 温度升高、光泽变化 |
| 皮革 | 崭新 → 微磨损 | 磨损 → 色泽暗淡/裂纹 | 撕裂/烧焦/磨损/污渍 | 光泽变化、温度升高 |
| 陶瓷 | 崭新 → 微使用 | 使用 → 色泽暗淡/裂纹 | 裂纹/碎裂/缺口/碎片 | 光泽变化、温度变化 |
| 食物 | 完整 → 半吃 | 半吃 → 吃完/残留 | 变形/洒落/搞笑残留 | 热气/光泽/诱人 |
| 电子元件 | 崭新 → 微使用 | 使用 → 焊点老化/灰尘 | 短路/烧焦/电容爆裂/电线断裂 | 指示灯亮、屏幕显示、电流乱窜 |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 道具核心造型/轮廓在所有状态中可识别 |
| R2 | 状态变化须符合物理逻辑，可夸张但不可荒谬 |
| R3 | 必须使用四宫格（2×2）布局 |
| R4 | 必须指定「纯净中性灰背景」或摄影棚背景，柔和韩剧布光，浅景深，暖色调 |
| R5 | 必须包含「搞笑韩剧真人版风格」+「柔和光影」+「浅景深」+「暖色调」+「真实材质」关键词 |
| R6 | 激活/发光/屏幕状态必须有明确的发光效果描述 |
| R7 | 食物/饮品类道具状态必须真实诱人，韩剧美食风格 |
| R8 | 搞笑/可爱状态必须保持真实材质，不能卡通化 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 状态变化后道具不可识别 |
| X2 | 违反物理逻辑的损伤 |
| X3 | 暗黑/恐怖/血腥/暴力/沉重压抑的损伤描绘 |
| X4 | 出现任何人物形象，包括全身、半身、局部（手、手指、手臂等肢体） |
| X5 | 道具处于被持有、握持、佩戴、使用中的状态 |
| X6 | 出现暗示人物存在的元素 |
| X7 | 卡通/动画/漫画/手绘风格（除非明确要求风格化） |
| X8 | 低幼Q版/萌系/日系纯爱风格 |
| X9 | 塑料感材质/不真实的质感 |
| X10 | 在提示词中直接使用受版权保护的特定道具/物品名/品牌名 |
