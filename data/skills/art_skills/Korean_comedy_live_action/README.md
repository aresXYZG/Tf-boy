# 搞笑韩剧真人版风格说明

本风格专为**搞笑韩剧真人版风格**题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **真人韩剧摄影风格**：所有角色、场景、道具均以真人韩剧摄影为标准，强调柔和光影、浅景深、暖色调、真实材质、韩剧大片质感。
- **搞笑浪漫叙事背景**：涵盖都市日常、搞笑反应、浪漫约会、职场喜剧、家庭温馨、街头偶遇等，杜绝低幼卡通/纯写实纪录片/暗黑恐怖元素。
- **韩剧级构图**：画面构图强调韩剧感，景深虚化、镜头光学特征、空气透视、暖色调滤镜。
- **柔和暖调光影**：整体色调偏暖柔和，明暗反差适中，突出温馨感与浪漫氛围，韩剧/网剧质感。

## 适用范围

- 搞笑韩剧真人版题材的AI美术生成（角色、场景、道具、分镜等）
- 搞笑/浪漫/日常叙事/都市喜剧风格的视觉创作
- 需要柔和光影、浅景深、暖色调、真实材质的视觉创作
- 品牌IP短剧、科普宣传、搞笑短片等需要温馨搞笑风格的项目

## 严禁内容

- 卡通/动画/漫画/手绘风格（除非明确要求风格化）
- 低幼Q版/萌系/日系纯爱风格
- 暗黑/恐怖/血腥/暴力元素
- 直接使用受版权保护的特定韩剧角色名或演员名
- 暗示性、暴露、低俗等不适宜内容
- 过度悲伤/沉重/压抑内容（搞笑浪漫为主）

## 风格体验

在本风格下，您将体验到：

- 角色面容真实立体、表情夸张搞笑（震惊时眼睛瞪大、搞笑时五官变形、害羞时脸红），皮肤质感真实，韩剧级妆容
- 场景空间温馨，韩国都市街道/咖啡馆/公寓/职场，材质纹理真实，暖色调，氛围温馨且富有韩剧感
- 道具、装备、科技装置等均为韩剧级造型，真实材质，时尚设计
- 分镜与视频均以真人韩剧为基础，强调镜头语言与搞笑节奏，韩剧/网剧质感

## 视频生成工作流（关键帧+图生视频）

本风格推荐使用"关键帧先行"工作流，特别适用于带文字画面和角色一致性要求高的项目：

1. **关键帧生成**：对每段中带文字的关键画面（标题、拟声词、标语、招牌等），先用文生图生成静态关键帧，确认文字准确无误
2. **图生视频**：将关键帧作为参考图传入视频生成工具，配合时间轴分镜prompt生成动态视频
3. **角色一致性锚定**：每段prompt中重复角色核心外观锚点（发型、服装主色、标志性特征），防止跨段角色漂移
4. **分段生成**：单段不超过15秒，长视频按叙事段落拆分后拼接
5. **后期合成**：Logo/徽标/标语等品牌元素在视频中预留空位，后期合成

本风格仅适用于"搞笑韩剧真人版风格"相关项目。如需其他风格（如卡通动画、日系动画、美式成人动画等），请勿使用本套提示词。
