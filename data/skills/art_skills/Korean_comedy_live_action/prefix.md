## 二、全局色彩盘（风格基线，不是硬锁）

> 目标：统一审美而非限制创作。除「硬约束色」外，其余颜色默认优先使用，可在合理范围内偏移。

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 仅锁定角色识别核心：肤色、发色、主服底色的审美方向 |
| L2 软约束 | 中 | 场景色、装备色、点缀色优先参考色盘，可按镜头与剧情微调 |
| L3 例外机制 | 低 | 回忆/梦境/幻想可临时突破局部色彩，但需保留整体柔和逻辑 |

|---|---|---|---|

### 硬约束色（默认锁定）

| 色项 | 对应色 | 规则 |
|---|---|---|
| 角色肤色基准 | C1 暖白肤 | 默认优先，允许不同角色有差异化肤色，皮肤质感细腻 |
| 暗部基准 | C9 深棕 | 默认优先，暖调暗部，保留细节不死黑 |
| 主服色基准 | 角色指定色 | 每个角色有固定主服色，跨镜头不得漂移 |

### 软约束色（推荐优先）

> C3/C4/C5/C6/C7/C8 为推荐韩剧色域，用于服装、暖光、自然、浪漫氛围等。可根据镜头氛围做同色相邻近调整。柔和暖调是本风格核心——温暖色彩铺底，温馨感为焦点。

### 情绪色盘使用规则

| 编号 | 规则 |
|---|---|
| E1 | 每条提示词至少指定 1 个「情绪场景」并绑定主色+辅色组合 |
| E2 | 单镜头主色不超过 2 个，避免颜色叙事失焦 |
| E3 | 情绪切换时优先调整光比与色温，再调整饱和度 |
| E4 | 搞笑浪漫向默认遵循「柔和暖调色」：温暖色彩铺底，温馨感为焦点 |
| E5 | 若与剧情冲突，以情绪色盘优先于通用推荐色，但不得突破严禁项 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 偏暖 4500-5500K（推荐） | 韩剧暖调主基调 |
| 室内/温馨色温 | 偏暖 4000-5000K | 家庭/约会/温馨场景 |
| 室外/日常色温 | 中性 5000-6000K | 日常/都市/街头场景 |
| 对比度 | 中低（建议保持） | 明暗反差适中，柔和韩剧感 |
| 饱和度 | 中高 50-70%（建议区间） | 柔和暖调是风格核心，但不过度 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|
| 色相偏移 | ±10° |
| 饱和度偏移 | ±12% |
| 明度偏移 | ±12% |

> 例外场景：回忆、梦境、幻想镜头可使用更夸张的色彩偏移；但禁止暗黑/冷调/高对比与本风格核心冲突。
