# 美式成人动画人物衍生资产生成 · 约束手册

---

## 一、叠加原则

1. **面容不变** — 叠加后五官必须与底模完全一致，禁止面容偏移
2. **姿态不变** — 保持底模自然站立姿态，禁止任何姿态/动作/体态变化
3. **逐层可控** — 每层独立描述，便于按层替换（换装不换妆）
4. **风格统一** — 所有服化元素服从同一美式成人动画美学体系
5. **质感不降** — 叠加后质感标准不低于底模
6. **纯服化范畴** — 仅叠加妆容/发型/服饰/配饰/鞋履，禁止引入道具、场景、环境、动作

---

## 二、叠加层级

| 层级 | 内容 | 说明 |
|---|---|---|
| L0 | 底模 | 基础形象底模，不修改 |
| L1 | 表情/妆容（决策层） | 先分析用户线索，再决策表情强度与妆容风格 |
| L2 | 发型造型 | 发髻/束发/编发 + 发饰/帽子/头饰 |
| L3 | 中衣/内搭 | 替换基础内搭 |
| L4 | 外衣/主服 | 美式动画差异化服装（实验服/西装/战斗服/异星服等） |
| L5 | 配饰 | 眼镜/手表/腰带/背包/科技装置等 |
| L6 | 鞋履 | 运动鞋/皮鞋/靴子/异形鞋等，与整体服装完整配套 |

> **范畴边界**：人物衍生资产仅包含 L0–L6 层级（服化妆造），不包含道具（手机/书本/武器/科技装置等手持物）、场景环境（室内/室外/天气等）、姿态动作（行走/回眸/举手等）。这些属于其他资产类型的范畴。

## 三、表情与妆容约束（L1）

### 表情决策（美式动画核心）

> 美式成人动画的表情是喜剧效果的核心。衍生资产应根据场景/情绪选择夸张表情，而非保持中性。

| 情绪 | 表情描述 | 提示词 |
|---|---|---|
| 得意/张扬 | 咧嘴大笑，眼睛眯起，眉毛上扬，一只手可能比手势 | 得意大笑、咧嘴笑、张扬表情 |
| 震惊/石化 | 眼睛瞪大，瞳孔缩小，嘴巴张成O型，眉毛飞起，面部去饱和 | 震惊表情、石化脸、瞪大眼 |
| 愤怒/暴怒 | 眉毛下压，眼睛怒视，嘴巴咬紧或大喊，青筋暴起 | 愤怒表情、暴怒、青筋暴起 |
| 猥琐/阴险 | 眼睛眯成缝，嘴角歪笑，眉毛一高一低，身体微缩 | 猥琐笑、阴险表情、贼眉鼠眼 |
| 呆萌/困惑 | 眼睛无神，嘴巴微张，眉毛微皱，头微歪 | 呆萌表情、困惑脸、无神眼 |
| 恐惧/害怕 | 眼睛瞪大，瞳孔缩小，嘴巴颤抖，冷汗直流，头发竖起 | 恐惧表情、害怕、冷汗直流 |
| 厌恶/嫌弃 | 鼻子皱起，嘴巴撇向一侧，眼睛半闭，眉毛下压 | 厌恶表情、嫌弃脸、皱眉 |
| 自信/从容 | 微笑，眼神坚定，眉毛平稳，身体挺直 | 自信微笑、从容表情 |
| 悲伤/难过 | 眉毛下垂，眼睛含泪，嘴角下撇，肩膀微缩 | 悲伤表情、含泪眼、嘴角下垂 |

### 妆容风格

| 风格 | 适用场景 | 核心提示词 |
|---|---|---|
| 日常淡妆 | 日常、普通场景 | 自然妆容、淡妆 |
| 夸张舞台妆 | 表演、派对、特殊场合 | 夸张妆容、舞台妆 |
| 伤痕妆 | 战斗后、受伤场景 | 伤痕妆、淤青、擦伤 |
| 科技妆 | 赛博改造、外星人 | 科技妆容、机械纹理、异星纹理 |
| 伪装妆 | 卧底、伪装场景 | 伪装妆容、假胡须、眼镜伪装 |

### 差异化着装原则

| 项目 | 约束 | 说明 |
|---|---|---|
| 角色区分 | 根据年龄、职业、性格、经济条件决定穿搭风格与配色 | 禁止所有角色同款同色同搭配 |
| 同风格差异 | 即使同为休闲装，也要区分款式/颜色/配饰 | 保持统一审美，不做制服化处理 |
| 场景适配 | 通勤、战斗、居家、宴会分别切换服装方案 | 服装应随情境变化而变化 |
| 主服色固定 | 每个角色有1-2个固定主服色，跨场景保持识别 | 主服色是角色识别核心 |

## 九、四视图设定图规范（无头素体防干扰版）

> 衍生服化叠加后仍需输出四视图设定图，确保服化妆造在各角度的高度一致性。

### 视图定义

| 位置 | 视图 | 角度 | 景别 | 要求 | 提示词 |
|---|---|---|---|---|---|
| 左一 | 人像超大特写 | 正面平视 | 头顶至锁骨 | 从头顶到锁骨完整展示不裁切，面部占比70%+，锁定高精五官细节、L1表情与妆容 | `portrait closeup`, `face detail`, `ultra detailed face` |
| 左二 | 正视图全身（无头素体） | 正面 0° | 颈部以下至脚底 | 面对镜头、双臂自然、从颈部以下到脚底完整展示，**颈部以上完全留空不画头部**，展示体型与L3/L4服装全貌 | `front view`, `headless body`, `full body neck to toe` |
| 右二 | 侧视图全身（无头素体） | 右侧 90° | 颈部以下至脚底 | 纯侧面轮廓、从颈部以下到脚底完整展示，**颈部以上完全留空不画头部**，展示体态与侧面层次 | `side view`, `headless body`, `profile neck to toe` |
| 右一 | 后视图全身（完整后背与后脑） | 后方 180° | 全身立像 | 后脑发型、发尾、背部服装版型与鞋底完整清晰展示 | `back view`, `rear view`, `full body head to toe` |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面从左至右并排四视图（左一人像特写 + 左二正视图无头素体 + 右二侧视图无头素体 + 右一后视图全身） |
| 背景 | 纯净白色背景（clean white background），与基础设定图一致 |
| 站姿 | 自然站立、双脚平行微分、双臂自然下垂或微展（**禁止任何姿态变化**） |
| 素体约束 | 左二与右二必须为无头素体（颈部以上截断留空），强制AI在特征提取时仅锁定左一人像特写，杜绝全身小脸畸变与特征冲突 |
| 特写展示 | 人像特写必须从头顶到锁骨完整入画，严禁裁切头顶 |
| 一致性 | 四视图的面容/妆容/发型/服饰/配饰/鞋履完全一致 |
| 光线 | 均匀柔光，自然阴影 |
| 画面比例 | 16:9 横版（与生图管线参数一致） |

## 十一、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 叠加后面容必须与底模一致 |
| R2 | 服饰必须用「衣服质感清晰 + 纹理清晰」 |
| R3 | 表情必须根据场景选择美式动画夸张表情，不保持中性 |
| R4 | 妆容/发型/服饰/配饰/鞋履风格统一 |
| R5 | 必须输出四视图设定图 |
| R6 | 必须指定「纯净中性灰背景」 |
| R7 | 必须指定「四视图一致性」 |
| R8 | **仅输出提示词**——禁止输出速查表/分层方案/视觉约束/禁止事项等任何非提示词内容 |
| R9 | **禁止包含场景描述** |
| R10 | **禁止道具交互** |
| R11 | **姿态保持不变**——必须保持底模自然站立姿态 |
| R12 | 每个角色必须有固定主服色，跨衍生保持识别 |

| R14 | **服装必须差异化**——禁止所有角色套用同一套衣服模板 |
