# 美式成人动画场景衍生资产生成 · 约束手册

---

## 一、衍生原则

1. **空间一致** — 建筑结构/布局/材质在所有变体中保持一致
2. **景别驱动** — 同一场景通过不同景别展示不同叙事功能
3. **时段切换** — 同一空间在不同时间段呈现不同光影氛围
4. **天候变化** — 同一空间在不同天气下呈现不同情绪
5. **风格统一** — 所有变体必须保持美式成人动画风格，粗墨线描边，高饱和撞色

---

## 二、景别变体

### 景别定义

| 景别 | 范围 | 叙事功能 | 提示词 |
|---|---|---|---|
| 大全景 | 场景全貌 + 周围环境 | 建立空间感、定位、展示异星/城市规模 | `extreme wide shot`、大全景 |
| 全景 | 场景完整呈现 | 展示空间结构、角色活动范围 | `wide shot`、全景 |
| 中景 | 场景局部区域 | 聚焦功能区、互动区域 | `medium shot`、中景 |
| 近景 | 场景细部 | 材质/氛围道具/科技装置特写 | `close shot`、近景 |
| 特写 | 极局部细节 | 材质纹理/关键道具/发光元件/按钮 | `extreme closeup`、特写 |

### 景别衍生规范

| 从基准图衍生 | 保持不变 | 允许变化 |
|---|---|---|
| 大全景 → 全景 | 建筑外观、整体布局 | 视角收窄、前景增加 |
| 全景 → 中景 | 材质、色调、光线 | 裁切聚焦、景深变化 |
| 中景 → 近景 | 材质、色调 | 景深浅、背景虚化 |
| 近景 → 特写 | 材质纹理 | 极浅景深、微距感 |

---

## 三、时段变体

### 时段定义

| 时段 | 视觉特征 | 提示词 |
|---|---|---|
| 清晨 | 冷白光调、薄雾感、城市苏醒 | 晨光微熹、清晨薄雾 |
| 正午 | 明亮、阴影短、色彩鲜明、高饱和 | 正午阳光、光线明亮、高饱和 |
| 黄昏 | 金橙色调、长影、天空渐变紫橙 | 暮色金辉、golden hour、长影拉伸 |
| 夜间（月光） | 冷蓝色调、幽静清冷、星星可见 | 月光清辉、moonlight、冷蓝夜色 |
| 夜间（灯火） | 暖黄/霓虹点缀、明暗对比、城市灯光 | 灯火阑珊、霓虹灯光、灯光氛围 |
| 夜间（科幻） | 荧光绿/紫色发光、科技装置亮、高对比 | 科幻夜光、装置发光、荧光点缀 |

### 时段衍生规范

| 从基准时段衍生 | 保持不变 | 变化项 |
|---|---|---|
| 日间 → 黄昏 | 建筑/布局/材质 | 天空色调暖化、影子拉长、撞色橙红 |
| 日间 → 夜间 | 建筑/布局/材质 | 整体变暗、增加灯火/月色/霓虹氛围 |
| 室内日间 → 室内夜间 | 空间结构、家具 | 整体色调暖化/冷化、增加室内灯光/科技发光 |

## 四、天候变体

### 天候定义

| 天候 | 视觉特征 | 提示词 |
|---|---|---|
| 晴天 | 明亮、阴影清晰、高饱和 | 晴空万里、阳光明媚 |
| 阴天 | 光线均匀、无硬影、色调偏灰 | 阴天柔光、overcast |
| 薄雾 | 能见度降低、空气朦胧、远景模糊 | 薄雾弥漫、雾气缭绕 |
| 细雨 | 水珠、湿润反光、雨丝、地面反光 | 细雨如丝、雨幕轻纱、地面湿润 |
| 飞雪 | 白色覆盖、雪花飘落、冷色调 | 飞雪纷纷、银装素裹 |
| 异星天气 | 紫色雨/双月/极光/彩色云/能量风暴 | 异星天气、{描述} |

### 天候衍生规范

| 从基准天候衍生 | 保持不变 | 变化项 |
|---|---|---|
| 晴 → 薄雾 | 建筑/布局 | 增加雾气层、远景模糊、饱和度降低 |
| 晴 → 细雨 | 建筑/布局 | 增加雨丝、地面反光、色调偏冷、湿润质感 |
| 晴 → 飞雪 | 建筑/布局 | 增加积雪、雪花、色调偏白冷 |
| 植被需随天候逻辑适配 | — | 雨中花瓣湿润、雪中枯枝挂霜、异星植物发光 |

## 五、角度变体

### 角度定义

| 角度 | 描述 | 提示词 |
|---|---|---|
| 正面/前视 | 与参考图相比，视线朝向场景正面 | `front view`、`eye level` |
| 侧面（左/右） | 朝场景左/右侧 90° 平视 | `left side view` / `right side view` |
| 背面/后视 | 朝场景背面 180° | `back view` |
| 俯视 | 高位俯瞰，呈现整体布局 | `high angle`、`bird's eye view` |
| 仰视 | 低位仰望，强调高大主体/建筑压迫感 | `low angle`、`worm's eye view` |
|  Dutch角 | 倾斜构图，制造不安/怪诞感 | `dutch angle`、倾斜构图 |
| 近景推进 | 同方向但镜头推进，聚焦局部 | `push-in`、`closer angle` |
| 自由角度 | 调用方自定义的任意角度描述 | 按 `{目标角度}` 注入 |

### 角度衍生规范

| 项目 | 约束 |
|---|---|
| 参考一致性 | 建筑结构/布局/材质/色调/光线/季节/天候必须与参考图一致 |
| 视点 | 同一场景中心点，仅角度切换；视线高度可随角度调整 |
| 光照逻辑 | 参考图光源方向不变，角度切换后光影投射方向需同步重算 |
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景空间结构在所有变体中保持一致 |
| R2 | 时段变体必须调整天空色调与氛围 |
| R3 | 天候变体必须适配植被/材质表面 |
| R4 | 衍生图必须为「单画面」，不得拼接多视图/网格/分屏 |
| R5 | 衍生图必须与参考图保持建筑结构/材质/色调/光线一致，仅按指定角度切换视点 |
| R6 | 场景图中**严禁出现任何人物** |
| R7 | 根据用户提供的信息自行判断变化维度，未提及维度留空省略 |
| R8 | 必须包含「美式成人动画手绘风格」+「粗墨线描边」+「高饱和撞色」关键词 |
| R9 | 材质必须带有使用痕迹/生活气息，禁止全新无瑕的"3D渲染感" |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 变体间建筑结构/布局不一致 |
| X2 | 天候与季节矛盾（夏天飞雪等，异星场景除外） |
| X3 | 变体间材质/风格突变 |
| X4 | 出现任何人物、人影、人体剪影或人体轮廓 |
| X5 | 画面被拼接成多视图/网格/分屏布局 |
| X6 | 3D渲染/CG动画/游戏引擎质感 |
| X7 | 材质过于干净完美、无任何使用痕迹与岁月感 |
| X8 | 光照过于均匀平坦、无景深虚化、无镜头光学特征 |
| X9 | 低幼Q版/萌系/日系纯爱风格 |
