# 美式成人动画道具衍生状态生成 · 约束手册

---

## 一、衍生原则

### 文书/告示/纸条类道具文字排版规则（必守）
若道具为文书、告示、纸条、清单、便签、规章制度、卡片等包含明确文字内容的道具：
1. **双引号逐字精准输出**：在提示词中必须使用双引号将文字标题与核心条款逐字精准标出（例如：包含清晰可见的书法/印刷文字标题 "【顾客须知】" 以及逐条清晰排版的规则内容 "1. 禁止投喂" "2. 违者后果自负"）。
2. **文字排版与可读性**：必须明确描述文字的字迹风格（如：深黑墨迹手写体 / 醒目印刷体 / 红色印章）、纸张折痕与排版布局（居中大标题、分行条例清晰、段落整齐），确保生图模型精准逐字渲染，严禁模糊乱码或乱画无意义字符。


1. **造型锚定** — 道具核心造型/轮廓在所有状态中可识别
2. **状态可读** — 状态差异必须一目了然，观众能立即区分
3. **叙事服务** — 每种状态变体服务于特定剧情节点
4. **渐进退化** — 损伤/老化状态应有合理的物理逻辑，可夸张表现
5. **纯道具独立展示** — 画面中只能出现道具本身，严禁出现任何人物、手部、肢体

## 二、状态类型

### 2.1 使用状态

| 状态 | 描述 | 适用道具 | 提示词 |
|---|---|---|---|
| 崭新 | 完好无损、光泽如新、标签未撕 | 所有道具 | 崭新、完好无损、光泽如新 |
| 日常使用 | 微磨损、自然包浆、贴纸/涂鸦 | 科技装置/器具/个人物品 | 日常使用痕迹、自然磨损、贴纸涂鸦 |
| 陈旧 | 明显年代感、色泽暗淡、锈迹 | 生活器物/机械装置 | 古旧斑驳、年代感、色泽暗沉、锈迹 |
| 改装 | 额外零件/电线/胶带固定/功能增强 | 科技装置/武器 | 改装状态、外露电线、胶带固定、额外零件 |

### 2.2 损伤状态

| 状态 | 描述 | 适用道具 | 提示词 |
|---|---|---|---|
| 微损 | 小裂纹/小缺口/轻微磨损/按钮失灵 | 科技装置/玻璃器具/手机 | 细微裂纹、轻微缺口、按钮凹陷 |
| 破损 | 明显裂缝/断裂/破碎/屏幕碎裂 | 玻璃/陶瓷/塑料/电子设备 | 裂缝明显、碎裂、断裂、屏幕碎裂 |
| 残片 | 仅剩部分/碎片/烧焦残骸 | 玻璃/陶瓷/科技装置/武器 | 残片、碎片、仅存半块、烧焦残骸 |
| 爆炸 | 爆炸瞬间/碎片飞散/烟雾弥漫 | 科技装置/武器/机械 | 爆炸状态、碎片飞散、烟雾弥漫 |

### 2.3 特殊状态

| 状态 | 描述 | 适用道具 | 提示词 |
|---|---|---|---|
| 激活/发光 | 元件发光/屏幕亮起/能量充能 | 科技装置/武器/电子设备 | 激活状态、元件发光、屏幕亮起、能量充能 |
| 故障/短路 | 火花四溅/屏幕乱码/电线冒烟 | 电子设备/科技装置 | 故障状态、火花四溅、屏幕乱码、电线冒烟 |
| 污渍 | 污渍附着/液体残留/食物残渣 | 杯子/衣物/纸张/道具 | 污渍残留、液体痕迹、食物残渣 |
| 冻结 | 冰霜覆盖/冰晶凝结/冷雾缭绕 | 任意道具 | 冻结状态、冰霜覆盖、冰晶凝结 |
| 融化 | 融化变形/液体滴落/形态扭曲 | 食物/塑料/蜡质道具 | 融化状态、液体滴落、形态扭曲 |

## 三、状态变体画面规范

### 单状态图

| 项目 | 约束 |
|---|---|
| 背景 | 纯净中性灰 `#A8A8A8`（与设定图一致） |
| 光线 | 均匀照明，平涂阴影，发光状态可加光晕 |
| 角度 | 与原设定图正面图一致 |
| 比例 | 道具占画面主体 70%+ |

### 状态对比图

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面并排展示 2-3 种状态 |
| 标注 | 每种状态下方标注状态名（如需要） |
| 一致性 | 角度/光线/背景完全一致，仅状态不同 |

## 四、材质状态变化规则

| 材质 | 崭新 → 日常 | 日常 → 陈旧 | 损伤表现 | 激活/发光表现 |
|---|---|---|---|---|
| 金属 | 亮光泽 → 微划痕 | 划痕 → 氧化/锈迹 | 缺口/卷边/断裂/凹陷 | 能量纹路发光、高温红热 |
| 玻璃 | 通透清晰 → 微划痕 | 划痕 → 裂纹/碎裂 | 裂纹/碎裂/缺口/碎片 | 内部发光、能量折射 |
| 塑料 | 崭新平整 → 微划痕 | 划痕 → 老化变色 | 裂纹/变形/褪色/融化 | 按钮发光、屏幕透光 |
| 电子元件 | 崭新 → 微使用 | 使用 → 焊点老化 | 短路/烧焦/电容爆裂 | 指示灯亮、屏幕显示、能量流动 |
| 木材 | 新木纹理 → 自然包浆 | 包浆 → 色泽暗沉 | 开裂/虫蛀/磨损/烧焦 | 无（木材不发光） |
| 布料 | 崭新平整 → 微褶皱 | 褶皱 → 褪色/磨损 | 撕裂/烧焦/污渍 | 无（布料不发光） |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 道具核心造型/轮廓在所有状态中可识别 |
| R2 | 状态变化须符合物理逻辑，可夸张但不可荒谬 |
| R3 | 必须使用四宫格（2×2）布局 |
| R4 | 必须指定「纯净中性灰背景」，均匀柔光，平涂阴影 |
| R5 | 必须包含「美式成人动画手绘风格」+「粗墨线描边」关键词 |
| R6 | 激活/发光状态必须有明确的发光效果描述 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 状态变化后道具不可识别 |
| X2 | 违反物理逻辑的损伤（如金属融化成水等不符合材质的变化） |
| X3 | 过度血腥/恐怖的损伤描绘 |
| X4 | 出现任何人物形象，包括全身、半身、局部（手、手指、手臂等肢体） |
| X5 | 道具处于被持有、握持、佩戴、使用中的状态 |
| X6 | 出现暗示人物存在的元素 |
| X7 | 使用真人写实/摄影/3D渲染相关词 |
| X8 | 低幼Q版/萌系风格 |
