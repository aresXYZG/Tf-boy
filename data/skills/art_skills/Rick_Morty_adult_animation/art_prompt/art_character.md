# 美式成人动画人物基础形象生成 · 约束手册

---

## 一、基础形象原则

1. **表情即灵魂** — 夸张五官与表情是角色唯一锚点，精细度适配美式成人动画风格
2. **角色为本** — 基础着装由角色描述（身份/职业/性别/场景）决定其常规着装；后续特定服化为叠加层
3. **四视图一致** — 面容/体型/发型/基础服装跨视图高度统一
4. **轮廓辨识度** — 每个角色必须有独特的剪影轮廓，即使去掉颜色也能区分
5. **夸张比例** — 头身比、五官位置、肢体比例可适度夸张，符合美式动画审美

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/气质）驱动 AI 自由生成五官，保证人物间外观差异化。但必须保持美式成人动画的夸张特征。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型，但必须夸张 |
| 风格底色 | 美式成人动画手绘风格、粗墨线描边、高饱和撞色、平涂加少量阴影 |
| 气质 | 必须从角色描述提炼整体气质关键词（如猥琐/自信/呆萌/阴险/张扬），并写入提示词 |
| 表情 | 中性微表情，符合角色气质，但保留夸张潜力 |
| 轮廓 | 脸型轮廓必须独特且可识别，避免千人一面 |

### 美式动画夸张特征（必含）

| 特征 | 描述 | 提示词 |
|---|---|---|
| 大眼睛 | 眼睛占面部比例大，眼白多，瞳孔可夸张 | 大眼睛、夸张眼型 |
| 大嘴巴 | 嘴巴可张合幅度大，表情时牙齿/舌头可见 | 大嘴、夸张嘴型 |
| 夸张眉毛 | 眉毛位置和形状随表情大幅变化（惊讶时飞起、愤怒时下压） | 夸张眉毛、表情丰富 |
| 粗轮廓线 | 面部轮廓用粗墨线勾勒，线条有手绘感 | 粗墨线描边、手绘轮廓 |
| 不规则脸型 | 脸型不完全对称，有独特棱角或弧度 | 独特脸型、不规则轮廓 |

## 三、肤感约束

### 通用

| 项目 | 约束 | 提示词 |
|---|---|---|
| 肤色 | 暖黄肤为主，不同角色/物种可有差异化 | 暖黄肤色、肤色统一 |
| 光泽 | 平涂为主，少量阴影，无油光 | 平涂上色、少量阴影 |
| 质感 | 手绘质感，线条清晰，赛璐璐式平涂 | 手绘质感、平涂质感 |
| 阴影 | 阴影边缘清晰，用深色块表现，不做渐变 | 清晰阴影、色块阴影 |

### 特殊物种肤色

| 物种类型 | 肤色方向 | 提示词 |
|---|---|---|
| 人类 | 暖黄/冷白/棕褐等人类肤色 | 正常人类肤色 |
| 外星人 | 绿色/蓝色/紫色/灰色等非人类肤色 | 异星肤色、非人类肤色 |
| 怪物/变异体 | 任意高饱和非人类肤色，可带斑点/纹理 | 怪物肤色、变异肤色 |

## 四、体型约束

### 通用

| 项目 | 约束 | 提示词 |
|---|---|---|
| 身高 | 由角色设定指定，通过头身比换算体现 | `{身高}cm tall`、`{身高描述}` |
| 头身比 | 美式动画夸张比例，5-7头身为主，特殊角色可更夸张 | `5-7 heads tall proportion`、夸张比例 |
| 体型 | 必须有独特体型（瘦高/矮胖/肌肉/佝偻等），避免标准体型 | 独特体型、{体型描述} |
| 手部 | 手指可夸张（4指/大手掌/长手指），美式动画常见4指 | 夸张手部、卡通手指 |
| 体态 | 符合角色性格的自然体态（自信挺胸/猥琐驼背/呆萌歪头） | 体态自然、{体态描述} |

### 体型类型速查

| 体型 | 描述 | 适用角色 | 提示词 |
|---|---|---|---|
| 瘦高型 | 身高腿长，肩窄，四肢细长 | 科学家、书呆子、反派 | tall slender、lanky |
| 矮胖型 | 身高矮，体型圆滚，肚子突出 | 喜剧角色、老板、吃货 | short chubby、round body |
| 肌肉型 | 肩宽胸厚，四肢粗壮 | 英雄、打手、运动员 | muscular、broad shoulders |
| 佝偻型 | 驼背，颈部前伸，四肢偏长 | 反派、科学家、怪人 | hunched、stooped posture |
| 标准型 | 比例匀称，无极端特征 | 主角、普通人 | average build、proportionate |
| 超夸张型 | 头大身小或头小身大，比例极端 | 喜剧角色、儿童、怪物 | exaggerated proportions、cartoonish build |

## 五、基础发型约束

> 仅定义自然散发/简单束发，发饰在服化衍生环节叠加。

### 通用

| 项目 | 约束 | 提示词 |
|---|---|---|
| 发色 | 任意高饱和色，人类角色以棕/黑/金为主，特殊角色可夸张 | {发色}头发 |
| 发长 | 短发/中发/长发/光头均可 | {发长} |
| 发质 | 线条清晰，手绘质感，发束块面化 | 发丝线条清晰、手绘发质 |
| 造型 | 必须有独特发型轮廓，避免普通 | 独特发型、{发型描述} |

### 美式动画典型发型

| 发型 | 描述 | 提示词 |
|---|---|---|

| 光头 | 完全光头或少量头发 | bald、光头 |
| 侧分油头 | 头发侧分，油亮整齐 | slicked hair、侧分油头 |
| 乱发 | 头发凌乱，有几缕翘起 | messy hair、乱发 |
| 莫西干 | 两侧剃光，中间竖起 | mohawk、莫西干头 |
| 长发飘逸 | 长发及腰或更长，飘逸 | long flowing hair、长发飘逸 |

## 六、基础服装约束

> 基础服装由角色描述（身份/职业/性别/场景）决定其最自然的常规着装，作为该角色「日常默认态」；正式服饰/特殊衍生在服化衍生环节叠加。

### 着装选择原则

| 角色身份 | 默认着装方向 |
|---|---|
| 科学家/发明家 | 白大褂/实验服 + 内搭 |
| 上班族 | 衬衫+西裤/西装/职业装 |
| 学生 | T恤+牛仔裤/校服/休闲装 |
| 英雄/守护者 | 特色制服/战斗服/标志性外套 |
| 反派/骗子 | 黑色夜行衣/西装/怪异服装 |
| 外星人 | 异星风格服装/裸体（非人类） |
| 角色描述未明确 | 美式休闲服，高饱和撞色 |

### 着装统一规则

- 服装风格须与美式成人动画美学一致（粗墨线、平涂、高饱和）
- 颜色高饱和，撞色搭配，每个角色有固定主服色
- 四视图服装款式完全一致
- 基础服装是「日常默认态」，焦点仍在面容与体型
- 服装可有夸张设计（大翻领、宽腰带、夸张口袋等）

## 七、四视图设定图规范（双参考垫图融合与无头素体防干扰版）

### 双真人参考图（垫图）特征融合机制（核心必守）
系统在生成四视图设定图时，支持从人脸参考资产库中匹配抽取 2 张真人人脸参考底图（图1与图2）进行解耦融合，生成全新原创角色：
1. **图 2（主要参考 70%）**：主导人物面部五官排布、眼型神韵、唇形特征与生活化/故事感神态，确立角色的核心面孔基底；
2. **图 1（辅助参考 30%）**：提供骨相立体度、下颌线轮廓骨感、鼻骨结构与皮肤通透细腻质感；
3. **画风媒介属性转化**：模型将提取的双真人参考特征自动转化为当前【美式成人荒诞动画】的专属艺术媒介（如墨线描边、赛璐璐平涂、PBR渲染、黏土塑形等），严禁生硬贴图；
4. **原创独立与人种/年龄参数化**：生成完全独立的全新原创角色，杜绝千篇一律的 AI 网红模板脸。根据剧本设定动态适配人种（东亚/欧美/混血/非裔等）与年龄段（少年/青年/中年/老年）。若参考底图与设定有年龄差异，由提示词动态注入年龄修饰词，模型自动渲染对应年龄段的面部特征与皮肤质感。

### 视图定义

| 位置 | 视图 | 角度 | 景别 | 要求 | 提示词 |
|---|---|---|---|---|---|
| 左一 | 人像超大特写 | 正面平视 | 头顶至锁骨 | 从头顶到锁骨完整展示不裁切，面部占比70%+，锁定基于两张垫图融合出的高精五官细节、神态与媒介质感 | `portrait closeup`, `face detail`, `ultra detailed face` |
| 左二 | 正视图全身（无头素体） | 正面 0° | 颈部以下至脚底 | 面对镜头、双臂自然、从颈部以下到脚底完整展示，**颈部以上完全截断留空不画头部**，展示体型与服装全貌 | `front view`, `headless body`, `full body neck to toe` |
| 右二 | 侧视图全身（无头素体） | 右侧 90° | 颈部以下至脚底 | 纯侧面轮廓、从颈部以下到脚底完整展示，**颈部以上完全截断留空不画头部**，展示体态与侧缝细节 | `side view`, `headless body`, `profile neck to toe` |
| 右一 | 后视图全身（完整后背与后脑） | 后方 180° | 全身立像 | 后脑发型、发尾、背部服装版型与鞋底完整清晰展示 | `back view`, `rear view`, `full body head to toe` |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面从左至右横排四视图（16:9 横版）：左一人像超大特写 + 左二正视图无头素体 + 右二侧视图无头素体 + 右一后视图全身立像 |
| 背景 | 纯净白色背景（clean white background） |
| 站姿 | 自然站立、双脚平行微分、双臂自然下垂或微展 |
| **无头防干扰机制** | **左二与右二必须为无头素体（颈部以上留空截断）**，迫使生图模型将面部注意力与像素算力100%集中在左一超大特写上，彻底根除全身小脸五官变形与多头特征冲突 |
| 特写展示 | 人像特写必须从头顶到锁骨完整入画，严禁裁切头顶 |
| 光线 | 均匀柔光，前方主光 + 双侧补光，自然阴影 |
| 画面比例 | 16:9 横版（与生图管线参数一致） |

## 九、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须包含「美式成人动画手绘风格」+「粗墨线描边」+「夸张五官与表情」 |
| R2 | 必须根据角色描述声明合适的常规着装作为基础服装；禁止内衣打底 |
| R3 | 必须声明角色有独特发型和独特体型轮廓 |
| R4 | 必须指定「纯净中性灰背景」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头顶到脚底完整展示，严禁裁切 |
| R7 | 必须声明角色身高并通过头身比换算约束全身比例 |
| R8 | 人像特写必须从头顶到锁骨完整展示，严禁裁切头顶 |
| R9 | 每个角色必须有固定主服色，跨镜头不得漂移 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 真人写实/摄影/3D渲染风格 |
| X2 | 低幼Q版/萌系/日系纯爱风格 |
| X3 | 正顶硬光/正底光/彩色光 |
| X4 | 复杂场景背景（必须纯灰底） |
| X5 | 全身立像裁切头顶或脚底 |
| X6 | 人像特写裁切头顶 |
| X7 | 忽略身高和头身比约束 |
| X8 | 在提示词中直接使用受版权保护的特定动画角色名 |
