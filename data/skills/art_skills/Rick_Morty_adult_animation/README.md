# 美式成人动画风格说明（瑞克和莫提画风版）

本风格专为**美式成人动画手绘风格**题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **美式成人动画风格**：所有角色、场景、道具均以美式成人动画为标准，强调粗墨线描边、夸张五官与表情、高饱和撞色、平涂加少量阴影、略带手绘凌乱质感。
- **怪诞科幻叙事背景**：涵盖科幻实验室、现代都市、异星场景、荒诞空间等，杜绝唯美古风/纯写实/低幼卡通元素。
- **漫画分镜感**：画面构图强调漫画分镜感，速度线、冲击特效、对话气泡、拟声词等元素可入画。
- **高饱和撞色调**：整体色调偏鲜艳撞色，冷暖对比强烈，突出怪诞与幽默并存的氛围。

## 适用范围

- 美式成人动画题材的AI美术生成（角色、场景、道具、分镜等）
- 科幻喜剧/黑色幽默/荒诞叙事动画风格的视觉创作
- 需要粗墨线、夸张表情、高饱和撞色的视觉创作
- 网络安全宣传、科普动画、品牌IP动画等需要强辨识度风格的项目

## 严禁内容

- 真人写实/摄影/3D渲染风格
- 低幼Q版/萌系/日系赛璐璐纯爱风格
- 唯美古风/仙侠/奇幻精灵风格
- 直接使用受版权保护的特定动画角色名或形象（提示词中使用风格描述，不出现具体角色名）
- 暗示性、暴露、低俗等不适宜内容

## 风格体验

在本风格下，您将体验到：

- 角色面容夸张独特、五官比例戏剧化，表情幅度大（惊讶时眉毛飞起、愤怒时青筋暴起、得意时咧嘴大笑）
- 场景空间层次丰富，科幻装置与日常场景混搭，材质纹理清晰，氛围怪诞且富有幽默感
- 道具、装饰、科技装置等均为美式动画造型，工艺夸张，质感手绘感强
- 分镜与视频均以美式成人动画为基础，强调叙事节奏与表情喜剧效果

## 视频生成工作流（关键帧+图生视频）

本风格推荐使用"关键帧先行"工作流，特别适用于带文字画面和角色一致性要求高的项目：

1. **关键帧生成**：对每段中带文字的关键画面（标题、弹窗、口诀、标语等），先用文生图生成静态关键帧，确认文字准确无误
2. **图生视频**：将关键帧作为参考图传入视频生成工具，配合时间轴分镜prompt生成动态视频
3. **角色一致性锚定**：每段prompt中重复角色核心外观锚点（发型、服装主色、标志性配饰），防止跨段角色漂移
4. **分段生成**：单段不超过15秒，长视频按叙事段落拆分后拼接

---

本风格仅适用于"美式成人动画手绘风格"相关项目。如需其他风格（如真人写实、日系动画、超级英雄漫画等），请勿使用本套提示词。
