# 全局美学基础 · 美式成人动画手绘风格

---

必须严格、完整遵循下方全部风格约束与全局规则，并严格按提示词模板格式生成提示词；仅输出提示词正文，不得附加任何解释、说明、注释、标题或其他额外文本。

## 一、风格基因

| 维度 | 定义 |
|---|---|
| **一级风格** | 美式成人动画手绘风格（American Adult Animation） |
| **二级风格** | 粗墨线描边 · 夸张表情 · 高饱和撞色 · 手绘凌乱质感 |
| **情感基调** | 怪诞幽默向 — 荒诞中见真实、夸张中藏讽刺 |
| **质感锚词** | 粗墨线描边、平涂加少量阴影、夸张五官与表情、高饱和撞色、略带手绘凌乱质感 |

## 二、全局色彩盘（风格基线，不是硬锁）

> 目标：统一审美而非限制创作。除「硬约束色」外，其余颜色默认优先使用，可在合理范围内偏移。

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 仅锁定角色识别核心：肤色、发色、主服底色的审美方向 |
| L2 软约束 | 中 | 场景色、配饰色、点缀色优先参考色盘，可按镜头与剧情微调 |
| L3 例外机制 | 低 | 回忆/梦境/高潮戏可临时突破局部色彩，但需保留整体撞色逻辑 |

| 序号 | 色名 | 色值 | 用途 |
|---|---|---|---|
| C1 | 暖黄肤 | `#F5D5A8` | 角色肤色基准（偏暖黄） |
| C2 | 冷白肤 | `#E8E0D0` | 次要角色/外星人肤色 |
| C3 | 荧光绿 | `#7FFF00` | 科幻装置、毒液、异星植物 |
| C4 | 墨黑 | `#1A1A1A` | 描边线、发色、暗部 |
| C5 | 撞色红 | `#E63946` | 警示、血液、披风、强调色 |
| C6 | 撞色蓝 | `#457B9D` | 科技感、制服、天空 |
| C7 | 撞色紫 | `#9B5DE5` | 科幻、神秘、异星 |
| C8 | 撞色橙 | `#F77F00` | 爆炸、能量、暖光 |
| C9 | 中性灰 | `#A8A8A8` | 设定图背景、金属材质 |
| C10 | 脏黄 | `#D4A574` | 旧化场景、磨损道具、沙漠 |

### 硬约束色（默认锁定）

| 色项 | 对应色 | 规则 |
|---|---|---|
| 角色肤色基准 | C1 暖黄肤 | 默认优先，允许不同种族/物种有差异化肤色 |
| 描边线基准 | C4 墨黑 | 默认优先，粗墨线为风格核心识别点 |
| 主服色基准 | 角色指定色 | 每个角色有固定主服色，跨镜头不得漂移 |

### 软约束色（推荐优先）

> C3/C5/C6/C7/C8/C10 为推荐撞色域，用于科幻装置、警示标识、能量特效、异星场景等。可根据镜头氛围做同色相邻近调整。撞色对比是本风格核心——冷暖并置、互补色相邻。

### 情绪色盘（导演对齐版）

| 情绪场景 | 主色 | 辅色 | 光效与对比建议 | 画面关键词 |
|---|---|---|---|---|
| 日常荒诞（幽默） | C1 暖黄肤 | C6 撞色蓝 + C8 撞色橙 | 平涂为主，少量阴影，色彩鲜艳 | 怪诞、日常、反差 |
| 科幻实验（神秘） | C7 撞色紫 | C3 荧光绿 + C4 墨黑 | 低光环境，荧光色发光，高对比 | 科技、诡异、实验 |
| 战斗冲突（激烈） | C5 撞色红 | C8 撞色橙 + C4 墨黑 | 速度线、爆炸特效、强对比 | 冲击、激烈、爆发 |
| 悬疑紧张（压迫） | C4 墨黑 | C6 撞色蓝 + C9 中性灰 | 低调光影，暗部占比大，冷色调 | 紧张、压迫、未知 |
| 得意胜利（张扬） | C8 撞色橙 | C5 撞色红 + C1 暖黄肤 | 暖光为主，角色占画面中心，放射状背景 | 得意、张扬、胜利 |
| 震惊石化（喜剧） | C9 中性灰 | C4 墨黑 + 白色 | 去饱和处理，角色表情夸张定格 | 石化、震惊、无语 |
| 异星奇幻（迷幻） | C7 撞色紫 | C3 荧光绿 + C6 撞色蓝 | 高饱和迷幻配色，发光元素多 | 迷幻、异星、超现实 |

### 情绪色盘使用规则

| 编号 | 规则 |
|---|---|
| E1 | 每条提示词至少指定 1 个「情绪场景」并绑定主色+辅色组合 |
| E2 | 单镜头主色不超过 2 个，避免颜色叙事失焦 |
| E3 | 情绪切换时优先调整光比与色温，再调整饱和度 |
| E4 | 怪诞幽默向默认遵循「高饱和撞色」：鲜艳色彩铺底，夸张表情为焦点 |
| E5 | 若与剧情冲突，以情绪色盘优先于通用推荐色，但不得突破严禁项 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 中性偏暖 5500-6500K（推荐） | 美式动画主基调 |
| 科幻场景色温 | 偏冷 6500-7500K | 实验室/异星场景 |
| 对比度 | 强（建议保持） | 明暗反差鲜明，粗墨线强化轮廓 |
| 饱和度 | 中高 60-80%（建议区间） | 高饱和撞色是风格核心 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|
| 色相偏移 | ±15° |
| 饱和度偏移 | ±15% |
| 明度偏移 | ±15% |

> 例外场景：回忆、梦境、情绪高潮镜头可使用更夸张的色彩偏移；但禁止低饱和灰调与本风格核心冲突。

## 三、全局约束规则

### 必守规则（所有技能继承）

| 编号 | 规则 |
|---|---|
| R1 | 必须包含「美式成人动画手绘风格」风格锚定词 |
| R2 | 必须声明「粗墨线描边 + 平涂加少量阴影」 |
| R3 | 面部必须使用「夸张五官与表情 + 表情幅度大」 |
| R4 | 发丝必须使用「线条清晰 + 手绘质感」 |
| R5 | 纹理必须声明「纹理细节清晰 + 手绘凌乱质感」 |

| R7 | 角色核心外观（发型/服装主色/标志性配饰）必须在每条提示词中重复锚定 |
