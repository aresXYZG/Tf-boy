# 美式成人动画约束 · 手绘风格 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以暖黄肤（C1）、撞色蓝（C6）、撞色红（C5）为基底色，整体色温中性偏暖（5500-6500K），饱和度中高（60-80%），呈现高饱和撞色的美式动画基调
- **撞色叙事对比** — 互补色（红/绿、蓝/橙、紫/黄）作为叙事转折的视觉信号，用于情绪爆发与场景切换。撞色对比应与故事弧线同步，而非随意混用
- **冷暖分配策略** — 悬疑/压迫/冷漠段落严格维持冷色调基底（撞色蓝 C6 + 墨黑 C4），禁用撞色橙、撞色红等暖色调；暖色仅在情绪回暖、得意胜利、日常荒诞段落释放，用冷暖对比做叙事转折
- **色盘先行原则** — 段落规划需先绑定情绪场景（日常荒诞/科幻实验/战斗冲突/悬疑紧张/得意胜利/震惊石化/异星奇幻），再确定主色+辅色与光影方案，避免"剧情对了但情绪不对色"
- **禁用色域** — 低饱和灰调、莫兰迪色、日系清新淡色均与本风格不兼容

---

## 二、光影方案体系

- **光影即叙事** — 7 套光影方案对应不同情绪段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **美式动画光影特征** — 清晰的明暗分界线、平涂加少量阴影、粗墨线强化轮廓为核心手段；光影必须服务于情绪叙事，保持美式成人动画的手绘质感

| 光影方案 | 方案名 | 色调倾向 | 适用情绪 |
|---|---|---|---|
| A | 平涂柔光 | 暖黄底 + 局部阴影 | 日常荒诞、温馨幽默、角色互动 |
| B | 硬侧高反差 | 墨黑 C4 + 撞色红 C5 硬光分割 | 对峙压迫、愤怒冷峻、紧张对抗 |
| C | 低调冷光 | 撞色蓝 C6 + 墨黑 C4 低调打光 | 悬疑紧张、分离误会、孤独寂寥 |
| D | 科幻荧光 | 撞色紫 C7 + 荧光绿 C3 发光 | 科幻实验、异星场景、科技装置 |
| E | 暖光日常 | 撞色橙 C8 + 暖黄肤 C1 侧光 | 室内日间、日常起居、都市生活 |
| F | 夜景霓虹 | 撞色橙 C8 点缀 + 墨黑 C4 暗部 + 撞色紫 C7 | 夜生活、城市夜景、酒吧餐厅 |
| G | 爆炸高光 | 撞色橙 C8 + 撞色红 C5 强光 | 战斗爆发、爆炸特效、胜利时刻 |

- **冷暖光分配** — 暖色光（撞色橙 C8）适用于日常、得意、胜利段落；冷色光（撞色蓝 C6 + 墨黑 C4）适用于悬疑、压迫、冷漠段落。导演可根据叙事需要调整冷暖切换点
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述光影方案（A-G）的某一方向，确保视觉一致性

## 三、质感方向

- **粗墨线为锚** — 美式成人动画的核心：粗墨线描边、平涂加少量阴影、夸张五官与表情、高饱和撞色、略带手绘凌乱质感，呈现强烈的手绘动画画面
- **面容与表情** — 面容夸张独特、五官比例戏剧化、表情幅度大（惊讶时眉毛飞起、愤怒时青筋暴起、得意时咧嘴大笑）。表情是喜剧效果的核心载体
- **服饰材质** — 衣物布料质感清晰、纹理细节清晰、布料折痕夸张、衣物随动态飘逸。美式动画服饰（实验服/西装/战斗服/异星服）的面料质感须可信
- **场景材质** — 场景材质纹理清晰、空气透视、使用痕迹、生活气息、乱中有序。玻璃反光、金属光泽、木质纹理、科技装置发光均需在美式动画风格下清晰呈现
- **手绘不等于扁平** — 美式成人动画强调在平涂基础上叠加戏剧化光影与漫画分镜感，通过夸张构图与表情设计放大感染力，而非依赖写实堆砌

## 四、美式动画场景空间元素

美式成人动画世界观特有的场景元素及其视觉叙事功能：

- **科幻装置/实验室** — 天然的怪诞感来源，外露电线、发光仪器、复杂按钮、黑板公式。装置的荒谬程度与角色的认真态度形成反差喜剧
- **都市街道/建筑** — 夸张透视的天然载体，景即情：繁华街景 = 孤独中的喧嚣、雨中街道 = 落寞、涂鸦小巷 = 反叛
- **霓虹/屏幕光/装置发光** — 美式动画的光源载体，室内暖灯 = 日常/私密、城市霓虹 = 冷暖交织、科幻装置发光 = 神秘/实验
- **段落间用场景空镜过渡** — 本风格有丰富的场景资产（不同时段/天候变体），段落衔接建议用场景空镜做情绪缓冲，不要硬切。城市天际线、实验室全景、异星地貌均可作为过渡空镜
- **转折点用视觉而非台词** — 优先使用画面手段（光影突变、景别跳切、空镜隐喻、表情定格）而非依赖对白解释

## 五、美式动画配乐与环境音

美式成人动画世界观下的声音元素约束：

### 配乐乐器选择

- **电子合成器** — 核心乐器，适用范围最广：科幻场景/异星/实验段落的氛围铺底，轻快合成器用于日常/幽默段落
- **电吉他** — 情感铺底与升华，失真吉他适合战斗/爆发段落，清音吉他适合都市夜景/微醺氛围
- **鼓组** — 节奏核心，紧凑鼓点用于追逐/战斗，松散鼓点用于日常/休闲
- **贝斯** — 低频支撑，放克贝斯用于幽默/怪诞段落，沉稳贝斯用于悬疑/压迫
- **钢琴** — 点缀乐器，用于真情流露/回忆段落，不做主导
- **管弦乐（夸张使用）** — 用于高潮/胜利/史诗段落，故意夸张使用制造反差喜剧

### 配乐组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 日常/开场/收尾 | 电子合成器 + 轻鼓组 或 电吉他清音 + 贝斯 |
| 幽默/荒诞 | 放克贝斯 + 电子合成器 + 紧凑鼓点 |
| 科幻/实验/异星 | 电子合成器铺底 + 氛围音效 + 低频贝斯 |
| 悬疑/紧张/压迫 | 低频贝斯 + 不和谐合成器 + 稀疏鼓点 |
| 战斗/爆发/胜利 | 失真电吉他 + 鼓组全奏 + 贝斯 + 夸张管弦乐 |
| 都市夜景/微醺 | 电吉他清音 + 电子氛围音 + 轻鼓组 |
| 真情流露/回忆 | 钢琴独奏 或 钢琴 + 轻弦乐 |

### 美式动画环境音

- **典型环境音层次** — 城市车流远声 / 实验室仪器嗡嗡声 / 电子装置哔哔声 / 咖啡机制动声 / 键盘敲击声 / 夸张脚步声 / 玻璃碎裂声 / 爆炸轰鸣声 / 远处汽车鸣笛 / 酒吧嘈杂声 / 异星环境音
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越丰富，美式动画场景越有沉浸感
- **夸张音效是喜剧核心** — 美式动画依赖夸张音效（弹簧声、滑音、爆炸、撞击）强化喜剧效果，不要用写实音效替代

## 六、视频生成工作流约束

- **关键帧先行** — 带文字画面必须先生成关键帧图片确认文字准确，再用图生视频
- **角色一致性锚定** — 每段视频prompt必须重复角色核心外观锚点（发型、服装主色、标志性配饰）
- **分段生成** — 单段不超过15秒，长视频按叙事段落拆分
- **后期合成** — Logo/徽标/标语等品牌元素预留空位后期合成
