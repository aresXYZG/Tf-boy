# 全局美学基础 · 王家卫电影风格

---

必须严格、完整遵循下方全部风格约束与全局规则，并严格按提示词模板格式生成提示词；仅输出提示词正文，不得附加任何解释、说明、注释、标题或其他额外文本。

## 一、风格基因

| 维度 | 定义 |
|---|---|
| **一级风格** | 王家卫电影风格（Wong Kar-wai Film Style） |
| **二级风格** | 电影级摄影 · 强烈色彩 · 霓虹灯 · 雨夜 · 烟雾 · 浅景深 · 朦胧感 |
| **情感基调** | 都市孤独浪漫向 — 暧昧中见孤独、错过中藏深情 |
| **质感锚词** | 强烈色彩、霓虹灯、雨夜反光、烟雾朦胧、浅景深、虚化、电影颗粒感、手持摄影、慢动作、抽帧 |

## 二、全局色彩盘（风格基线，不是硬锁）

> 目标：统一审美而非限制创作。除「硬约束色」外，其余颜色默认优先使用，可在合理范围内偏移。

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 仅锁定角色识别核心：肤色、发色、主服底色的审美方向 |
| L2 软约束 | 中 | 场景色、装备色、点缀色优先参考色盘，可按镜头与剧情微调 |
| L3 例外机制 | 低 | 回忆/梦境/幻想可临时突破局部色彩，但需保留整体朦胧逻辑 |

| 序号 | 色名 | 色值 | 用途 |
|---|---|---|---|
| C1 | 暧昧肤 | `#D4A574` | 角色肤色基准（偏暖黄，霓虹灯照射下） |
| C2 | 苍白肤 | `#C8B8A8` | 特定角色/冷光下肤色 |
| C3 | 霓虹绿 | `#00FF7F` | 霓虹灯、雨夜、强调色、暧昧氛围 |
| C4 | 霓虹红 | `#FF1744` | 霓虹灯、口红、强调色、暧昧氛围 |
| C5 | 暖黄 | `#FFB300` | 暖光、室内、怀旧、烟雾 |
| C6 | 深蓝 | `#0D47A1` | 夜空、雨夜、冷光、孤独 |
| C7 | 深紫 | `#4A148C` | 霓虹、暧昧、神秘、夜生活 |

### 硬约束色（默认锁定）

| 色项 | 对应色 | 规则 |
|---|---|---|
| 角色肤色基准 | C1 暧昧肤 | 默认优先，霓虹灯照射下偏暖黄，允许不同角色有差异化肤色 |
| 暗部基准 | C9 墨黑 | 默认优先，电影级暗部，保留细节不死黑，烟雾朦胧 |
| 主服色基准 | 角色指定色 | 每个角色有固定主服色，跨镜头不得漂移 |

### 软约束色（推荐优先）

> C3/C4/C5/C6/C7/C8 为推荐王家卫色域，用于霓虹灯、暖光、雨夜、暧昧氛围等。可根据镜头氛围做同色相邻近调整。红绿对比是本风格核心——霓虹绿与霓虹红并置，暧昧与孤独交织。

### 情绪色盘（导演对齐版）

| 情绪场景 | 主色 | 辅色 | 光效与对比建议 | 画面关键词 |

### 情绪色盘使用规则

| 编号 | 规则 |
|---|---|
| E1 | 每条提示词至少指定 1 个「情绪场景」并绑定主色+辅色组合 |
| E2 | 单镜头主色不超过 2 个，避免颜色叙事失焦 |
| E3 | 情绪切换时优先调整光比与色温，再调整饱和度 |
| E4 | 都市孤独浪漫向默认遵循「红绿对比色」：霓虹绿与霓虹红铺底，暧昧孤独为焦点 |
| E5 | 若与剧情冲突，以情绪色盘优先于通用推荐色，但不得突破严禁项 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 偏暖 4000-5000K（推荐） | 王家卫暖调主基调 |
| 霓虹灯/雨夜色温 | 混合 3000-7000K | 红绿霓虹混合，冷暖对比 |
| 室内/怀旧色温 | 偏暖 3500-4500K | 暖光、烟雾、怀旧 |
| 对比度 | 高（建议保持） | 明暗反差鲜明，红绿对比强烈 |
| 饱和度 | 中高 60-80%（建议区间） | 强烈色彩是风格核心，但不过度 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|
| 色相偏移 | ±15° |
| 饱和度偏移 | ±15% |
| 明度偏移 | ±15% |

> 例外场景：回忆、梦境、幻想镜头可使用更夸张的色彩偏移；但禁止明亮清新/高对比硬光/低饱和灰调与本风格核心冲突。

## 三、全局约束规则

### 必守规则（所有技能继承）

| 编号 | 规则 |
|---|---|
| R1 | 必须包含「王家卫电影风格」+「强烈色彩」+「霓虹灯」+「雨夜」+「烟雾」+「浅景深」风格锚定词 |
| R2 | 必须声明「真实材质」+「皮肤质感真实」+「电影级妆容」 |
| R3 | 面部必须使用「真实立体」+「表情暧昧含蓄」 |
| R4 | 身体必须使用「真实比例」+「自然体态」 |
| R5 | 纹理必须声明「材质纹理真实」+「细节丰富」+「电影颗粒感」 |
| R6 | 必须声明「红绿对比」+「电影级构图」+「浅景深」+「虚化朦胧」 |
| R7 | 角色核心外观（发型、服装主色、标志性特征）必须在每条提示词中重复锚定 |
| R8 | 必须声明「空气透视」+「烟雾朦胧」+「电影颗粒感」等电影级光学特征 |

### 严禁项（所有技能继承）

| 编号 | 严禁内容 |
|---|---|
| X1 | 严禁「卡通/动画/漫画/手绘风格」（除非明确要求风格化） |
| X2 | 严禁「低幼Q版/萌系/日系纯爱」 |
| X3 | 严禁「明亮清新/高对比硬光/低饱和灰调/莫兰迪色」 |
| X4 | 严禁「面部变形/多指/肢体异常」倾向词 |
| X5 | 严禁「裸体/暴露/透视/暗示性描述」 |
| X6 | 严禁在提示词中直接使用受版权保护的特定电影角色名或演员名 |
| X7 | 严禁「过度血腥/暴力/恐怖内容」 |
| X8 | 严禁「过度悲伤/沉重/压抑内容」（暧昧孤独可以，但不能过度） |
