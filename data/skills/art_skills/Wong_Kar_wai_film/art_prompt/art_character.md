# 王家卫电影风格人物基础形象生成 · 约束手册

---

## 一、基础形象原则

1. **真实即基础** — 面容真实立体是角色基础，皮肤质感真实，电影级妆容
2. **暧昧即灵魂** — 表情暧昧含蓄是角色核心，精细度适配王家卫电影风格
3. **角色为本** — 基础着装由角色描述（身份/职业/性别/性格）决定其常规着装；后续特定服化为叠加层
4. **四视图一致** — 面容/体型/发型/基础服装跨视图高度统一
5. **轮廓辨识度** — 每个角色必须有独特的剪影轮廓，即使去掉颜色也能区分
6. **电影级质感** — 皮肤、毛发、服装、装备均需达到电影级真实质感，烟雾朦胧

## 六、基础服装约束

> 基础服装由角色描述（身份/职业/性别/性格）决定其最自然的常规着装，作为该角色「日常默认态」；特殊衍生在服化衍生环节叠加。

### 着装选择原则

| 角色身份 | 默认着装方向 |
|---|---|
| 上班族/白领 | 衬衫+西裤/西装/职业装/连衣裙，60年代香港职场 |
| 学生 | 校服/运动服/学院装/休闲装，60年代校园 |
| 普通人/市民 | T恤+牛仔裤/衬衫/休闲装/连衣裙，60年代日常 |
| 医生/律师 | 白大褂/西装/职业装，60年代精英 |
| 警察/特工 | 警服/西装/黑色作战服，60年代动作 |
| 黑帮/混混 | 黑色西装/皮夹克/暗色服装，60年代黑帮 |
| 歌女/舞女 | 旗袍/礼服/连衣裙/性感服装，60年代夜生活 |
| 角色描述未明确 | 60年代香港都市休闲装，暖色调，怀旧 |

### 着装统一规则

- 服装风格须与王家卫电影风格美学一致（电影级质感、真实材质、60年代香港、怀旧、暧昧）
- 颜色以红绿对比为主，每个角色有固定主服色
- 四视图服装款式完全一致
- 基础服装是「日常默认态」，焦点仍在面容与体型
- 服装材质真实，布料/皮革/金属/丝绸质感可信，褶皱/缝线可见
- 服装可有60年代香港时尚设计，避免卡通化
- 旗袍/西装/风衣/针织衫是王家卫电影经典服装元素

## 七、四视图设定图规范（双参考垫图融合与无头素体防干扰版）

### 双真人参考图（垫图）特征融合机制（核心必守）
系统在生成四视图设定图时，支持从人脸参考资产库中匹配抽取 2 张真人人脸参考底图（图1与图2）进行解耦融合，生成全新原创角色：
1. **图 2（主要参考 70%）**：主导人物面部五官排布、眼型神韵、唇形特征与生活化/故事感神态，确立角色的核心面孔基底；
2. **图 1（辅助参考 30%）**：提供骨相立体度、下颌线轮廓骨感、鼻骨结构与皮肤通透细腻质感；
3. **画风媒介属性转化**：模型将提取的双真人参考特征自动转化为当前【王家卫港片胶片电影】的专属艺术媒介（如墨线描边、赛璐璐平涂、PBR渲染、黏土塑形等），严禁生硬贴图；
4. **原创独立与人种/年龄参数化**：生成完全独立的全新原创角色，杜绝千篇一律的 AI 网红模板脸。根据剧本设定动态适配人种（东亚/欧美/混血/非裔等）与年龄段（少年/青年/中年/老年）。若参考底图与设定有年龄差异，由提示词动态注入年龄修饰词，模型自动渲染对应年龄段的面部特征与皮肤质感。
