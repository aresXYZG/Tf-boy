# 王家卫电影风格场景图生成 · 约束手册

---

## 一、场景美学原则

1. **空间叙事** — 场景承载情绪与叙事功能，不是纯背景板，可加入暧昧/孤独/怀旧元素
2. **层次纵深** — 所有场景必须具备前/中/后景，杜绝扁平
3. **质感真实** — 材质纹理必须清晰（金属/玻璃/木材/布料/墙面/混凝土/霓虹灯），电影级真实质感
4. **强烈色彩为锚** — 所有画面以王家卫电影风格为标准，强调强烈色彩、霓虹灯、雨夜、烟雾、浅景深、朦胧感
5. **红绿对比光影** — 光影服务于情绪，保持红绿对比基调，明暗反差强烈，霓虹灯色彩，雨夜反光
6. **60年代香港+都市孤独混搭** — 本风格场景常出现60年代香港都市场景与都市孤独元素的混搭，制造暧昧感与怀旧氛围

## 五、主视图规范

### 视图定义

> 单画面主视图，从场景中最具代表性的角度拍摄，承载空间叙事与构图重心。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 自然观察视角或王家卫经典角度（框架构图/倾斜构图/低角度），构图最能体现场景主体与纵深 | `hero shot`、`representative angle`、王家卫经典角度 |
| 视点高度 | 默认人眼平视高度，暧昧场景常用略低角度，孤独场景可用高角度，王家卫常用框架构图 | `eye level`（默认）/ `slightly low angle` / `high angle` / `frame composition` |
| 构图 | 主体居中或符合三分法，前/中/后景层次清晰，可加入暧昧/孤独/怀旧元素 | `balanced composition`、电影级构图、框架构图 |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 风格/材质/色调/光线统一 |
| 光线 | 单一光源逻辑或多光源混合（霓虹灯/暧昧场景），光影方向一致 |
| 画面比例 | 默认 16:9 横屏或 2.35:1 宽银幕（王家卫推荐宽银幕） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次」 |
| R2 | 室外必须包含「空气透视」 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能代表场景主体并展示前/中/后景层次 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含「王家卫电影风格」+「强烈色彩」+「霓虹灯」+「雨夜」+「烟雾」+「浅景深」+「朦胧感」+「真实材质」+「电影级质感」关键词 |
| R7 | 材质必须带有使用痕迹/生活气息/烟雾，禁止全新无瑕的"3D渲染感" |
| R8 | 暧昧/孤独/怀旧场景必须有至少一个非日常元素（霓虹灯/烟雾/雨夜/暧昧光/60年代元素） |
| R9 | 红绿对比是核心——霓虹绿与霓虹红并置，明暗反差必须强烈 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑/无场景 |
| X2 | 极端天候（暴风雨/雷电/暴雪，除非剧情需要） |
| X3 | 场景无纵深/无层次 |
