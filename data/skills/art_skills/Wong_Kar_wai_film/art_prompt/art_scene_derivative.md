# 王家卫电影风格场景衍生资产生成 · 约束手册

---

## 一、衍生原则

1. **空间一致** — 建筑结构/布局/材质在所有变体中保持一致
2. **景别驱动** — 同一场景通过不同景别展示不同叙事功能
3. **时段切换** — 同一空间在不同时间段呈现不同光影氛围
4. **天候变化** — 同一空间在不同天气下呈现不同情绪
5. **风格统一** — 所有变体必须保持王家卫电影风格，强烈色彩、霓虹灯、雨夜、烟雾、浅景深、朦胧感

---

## 二、景别变体

### 景别定义

| 景别 | 范围 | 叙事功能 | 提示词 |
|---|---|---|---|
| 大全景 | 场景全貌 + 周围环境 | 建立空间感、定位、展示城市/街区规模 | `extreme wide shot`、大全景 |
| 全景 | 场景完整呈现 | 展示空间结构、角色活动范围 | `wide shot`、全景 |
| 中景 | 场景局部区域 | 聚焦功能区、互动区域 | `medium shot`、中景 |
| 近景 | 场景细部 | 材质/氛围道具/霓虹灯/烟雾特写 | `close shot`、近景 |
| 特写 | 极局部细节 | 材质纹理/关键道具/霓虹灯/烟雾/雨滴 | `extreme closeup`、特写 |

### 景别衍生规范

| 从基准图衍生 | 保持不变 | 允许变化 |
|---|---|---|
| 大全景 → 全景 | 建筑外观、整体布局 | 视角收窄、前景增加 |
| 全景 → 中景 | 材质、色调、光线 | 裁切聚焦、景深变化 |
| 中景 → 近景 | 材质、色调 | 景深浅、背景虚化 |
| 近景 → 特写 | 材质纹理 | 极浅景深、微距感 |

## 三、时段变体

### 时段定义

| 时段 | 视觉特征 | 提示词 |
|---|---|---|
| 清晨/黎明 | 暖白光调、薄雾感、城市苏醒、金色曙光 | 晨光微熹、清晨薄雾、暖光、金色曙光 |
| 正午 | 明亮、阴影短、色彩自然、暖色调 | 正午阳光、光线明亮、暖色调 |
| 黄昏/傍晚 | 温暖橙色调、长影、天空渐变温暖橙/暖黄、金色余晖 | 暮色温暖、golden hour、长影柔和、金色余晖 |
| 夜间（月光） | 暖黄色调、幽静暧昧、星星可见、月光柔和 | 月光清辉、moonlight、暖黄夜色 |
| 夜间（霓虹） | 霓虹灯/暖黄/路灯点缀、明暗对比、城市灯光、暧昧、雨夜 | 灯火阑珊、霓虹灯、灯光氛围、暧昧、雨夜 |
| 凌晨 | 暖灰调、雾气朦胧、最暗时刻、城市苏醒前 | 凌晨暖光、雾气朦胧、最暗时刻 |
| 室内（暧昧） | 暖光环境、霓虹灯、柔和光影、烟雾、浅景深、暧昧 | 暧昧室内、暖光环境、霓虹灯、柔和光影、烟雾 |
| 雨夜/街头 | 雨夜反光、霓虹灯、浅景深、虚化、朦胧感、红绿对比 | 雨夜反光、霓虹灯、浅景深、虚化、朦胧感、红绿对比 |

### 时段衍生规范

| 从基准时段衍生 | 保持不变 | 变化项 |
|---|---|---|
| 日间 → 黄昏 | 建筑/布局/材质 | 天空色调温暖化、影子拉长、暗部柔和、金色余晖 |
| 日间 → 夜间 | 建筑/布局/材质 | 整体变暗、增加路灯/月色/霓虹灯/暖光/暧昧氛围 |
| 室内日间 → 室内夜间 | 空间结构、家具 | 整体色调暖化、增加室内灯光/霓虹灯/暖光/局部光源 |
| 正常 → 雨夜 | 建筑/布局 | 增加雨丝、地面反光、霓虹灯倒影、色调偏暗、朦胧感 |

## 四、天候变体

### 天候定义

| 天候 | 视觉特征 | 提示词 |
|---|---|---|
| 晴天 | 明亮、阴影柔和、色彩自然、暖色调 | 晴空万里、阳光明媚、暖色调 |
| 阴天 | 光线均匀、无硬影、色调偏暖灰 | 阴天柔光、overcast、暖灰调 |
| 薄雾 | 能见度降低、空气朦胧、远景模糊、暧昧 | 薄雾弥漫、雾气缭绕、远景模糊、暧昧 |
| 细雨 | 水珠、湿润反光、雨丝、地面反光、浪漫 | 细雨如丝、雨幕轻纱、地面湿润、浪漫 |
| 雨夜 | 雨幕、积水、水花、霓虹灯倒影、暧昧、朦胧 | 雨夜、雨幕、水花、霓虹灯倒影、暧昧、朦胧 |
| 初雪/飞雪 | 白色覆盖、雪花飘落、冷色调、浪漫、60年代 | 初雪、飞雪纷纷、银装素裹、浪漫 |
| 大雾 | 能见度极低、浓雾弥漫、迷失感、神秘、暧昧 | 大雾弥漫、浓雾、能见度低、迷失、暧昧 |
| 烟雾/朦胧 | 烟雾笼罩、朦胧感、虚化、暖光、暧昧 | 烟雾笼罩、朦胧感、虚化、暖光、暧昧 |

### 天候衍生规范

| 从基准天候衍生 | 保持不变 | 变化项 |
|---|---|---|
| 晴 → 薄雾 | 建筑/布局 | 增加雾气层、远景模糊、饱和度降低、暧昧感 |
| 晴 → 细雨 | 建筑/布局 | 增加雨丝、地面反光、色调偏暖、湿润质感、浪漫 |
| 晴 → 雨夜 | 建筑/布局 | 增加雨幕、霓虹灯倒影、色调偏暗、朦胧感、暧昧 |
| 晴 → 初雪 | 建筑/布局 | 增加积雪、雪花、色调偏白暖、浪漫 |
| 晴 → 大雾 | 建筑/布局 | 增加浓雾、能见度降低、迷失感、暧昧 |
| 晴 → 烟雾 | 建筑/布局 | 增加烟雾、朦胧感、虚化、暖光、暧昧 |
| 植被需随天候逻辑适配 | — | 雨中花瓣湿润、雪中枯枝挂霜、雾中树木模糊、烟雾中朦胧 |

## 五、角度变体

### 角度定义

| 角度 | 描述 | 提示词 |
|---|---|---|
| 正面/前视 | 与参考图相比，视线朝向场景正面 | `front view`、`eye level` |
| 侧面（左/右） | 朝场景左/右侧 90° 平视 | `left side view` / `right side view` |
| 背面/后视 | 朝场景背面 180° | `back view` |
| 俯视 | 高位俯瞰，呈现整体布局/城市全貌/街区 | `high angle`、`bird's eye view` |
| 仰视 | 低位仰望，强调高大主体/建筑/霓虹灯/压迫感 | `low angle`、`worm's eye view` |
| Dutch角 | 倾斜构图，制造暧昧/紧张/怪诞/不安感 | `dutch angle`、倾斜构图 |
| 鱼眼 | 极端广角，边缘扭曲，制造超现实/暧昧/怪诞感 | `fisheye`、鱼眼透视 |
| 框架构图 | 通过门框/窗户/镜子框架场景，王家卫经典 | `frame composition`、框架构图、王家卫经典 |
| 近景推进 | 同方向但镜头推进，聚焦局部 | `push-in`、`closer angle` |
| 自由角度 | 调用方自定义的任意角度描述 | 按 `{目标角度}` 注入 |

### 角度衍生规范

| 项目 | 约束 |
|---|---|
| 参考一致性 | 建筑结构/布局/材质/色调/光线/季节/天候必须与参考图一致 |
| 视点 | 同一场景中心点，仅角度切换；视线高度可随角度调整 |
| 光照逻辑 | 参考图光源方向不变，角度切换后光影投射方向需同步重算 |
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 画面比例 | 默认 16:9 横屏或 2.35:1 宽银幕（王家卫推荐宽银幕） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景空间结构在所有变体中保持一致 |
| R2 | 时段变体必须调整天空色调与氛围 |
| R3 | 天候变体必须适配植被/材质表面 |
| R4 | 衍生图必须为「单画面」，不得拼接多视图/网格/分屏 |
| R5 | 衍生图必须与参考图保持建筑结构/材质/色调/光线一致，仅按指定角度切换视点 |
| R6 | 场景图中**严禁出现任何人物** |
| R7 | 根据用户提供的信息自行判断变化维度，未提及维度留空省略 |
| R8 | 必须包含「王家卫电影风格」+「强烈色彩」+「霓虹灯」+「雨夜」+「烟雾」+「浅景深」+「朦胧感」+「真实材质」+「电影级质感」关键词 |
| R9 | 材质必须带有使用痕迹/生活气息/烟雾，禁止全新无瑕的"3D渲染感" |
| R10 | 暧昧/孤独/怀旧变体必须有至少一个非日常元素 |
| R11 | 红绿对比是核心——霓虹绿与霓虹红并置，明暗反差必须强烈 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 变体间建筑结构/布局不一致 |
| X2 | 天候与季节矛盾（夏天飞雪等，60年代香港场景除外） |
| X3 | 变体间材质/风格突变 |
| X4 | 出现任何人物、人影、人体剪影或人体轮廓 |
| X5 | 画面被拼接成多视图/网格/分屏布局 |
| X6 | 卡通/动画/漫画/手绘风格（除非明确要求风格化） |
| X7 | 材质过于干净完美、无任何使用痕迹与岁月感 |
| X8 | 光照过于均匀平坦、无景深虚化、无镜头光学特征 |
| X9 | 低幼Q版/萌系/日系纯爱风格 |
| X10 | 明亮清新/高对比硬光/低饱和灰调/莫兰迪色 |
| X11 | 过度血腥/暴力/恐怖内容 |
