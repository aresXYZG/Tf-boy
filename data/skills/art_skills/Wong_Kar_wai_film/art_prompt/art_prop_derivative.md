# 王家卫电影风格道具衍生状态生成 · 约束手册

## 一、衍生原则

### 文书/告示/纸条类道具文字排版规则（必守）
若道具为文书、告示、纸条、清单、便签、规章制度、卡片等包含明确文字内容的道具：
1. **双引号逐字精准输出**：在提示词中必须使用双引号将文字标题与核心条款逐字精准标出（例如：包含清晰可见的书法/印刷文字标题 "【顾客须知】" 以及逐条清晰排版的规则内容 "1. 禁止投喂" "2. 违者后果自负"）。
2. **文字排版与可读性**：必须明确描述文字的字迹风格（如：深黑墨迹手写体 / 醒目印刷体 / 红色印章）、纸张折痕与排版布局（居中大标题、分行条例清晰、段落整齐），确保生图模型精准逐字渲染，严禁模糊乱码或乱画无意义字符。


1. **造型锚定** — 道具核心造型/轮廓在所有状态中可识别
2. **状态可读** — 状态差异必须一目了然，观众能立即区分
3. **叙事服务** — 每种状态变体服务于特定剧情节点
4. **渐进退化** — 损伤/老化状态应有合理的物理逻辑，可夸张表现
5. **纯道具独立展示** — 画面中只能出现道具本身，严禁出现任何人物、手部、肢体

## 二、状态类型

### 2.1 使用状态

| 状态 | 描述 | 适用道具 | 提示词 |
|---|---|---|---|
| 崭新 | 完好无损、光泽如新、标签未撕 | 所有道具 | 崭新、完好无损、光泽如新 |
| 日常使用 | 微磨损、自然包浆、贴纸/刮痕/使用痕迹 | 个人物品/生活器物/怀旧道具 | 日常使用痕迹、自然磨损、刮痕、使用痕迹 |
| 陈旧/怀旧 | 明显年代感、色泽暗淡、灰尘/泛黄/复古 | 怀旧道具/老式电器/旧信件/古董 | 古旧斑驳、年代感、色泽暗沉、灰尘、泛黄、复古 |
| 暧昧/霓虹 | 霓虹灯照射、红绿对比、烟雾朦胧、暧昧光 | 夜生活道具/酒杯/口红/香水 | 暧昧状态、霓虹灯照射、红绿对比、烟雾朦胧 |

### 2.2 损伤状态

| 状态 | 描述 | 适用道具 | 提示词 |
|---|---|---|---|
| 微损 | 小裂纹/小缺口/轻微磨损/按钮失灵/划痕 | 玻璃器具/生活器物/怀旧道具 | 细微裂纹、轻微缺口、按钮凹陷、划痕 |
| 破损 | 明显裂缝/断裂/破碎/屏幕碎裂/凹陷 | 玻璃/陶瓷/塑料/老式电器 | 裂缝明显、碎裂、断裂、凹陷 |
| 残片 | 仅剩部分/碎片/烧焦残骸/断裂残端 | 玻璃/陶瓷/木质/纸张 | 残片、碎片、仅存半块、烧焦残骸 |

## 三、状态变体画面规范

### 单状态图

| 项目 | 约束 |
|---|---|
| 背景 | 纯净中性灰 `#607D8B` 或摄影棚渐变背景（与设定图一致），烟雾朦胧 |
| 光线 | 暧昧电影布光，前方主光 + 侧逆光 + 轮廓光，浅景深，霓虹灯照射，红绿对比，自然阴影 |
| 角度 | 与原设定图正面图一致 |
| 比例 | 道具占画面主体 70%+ |

### 状态对比图

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面并排展示 2-3 种状态 |
| 标注 | 每种状态下方标注状态名（如需要） |
| 一致性 | 角度/光线/背景完全一致，仅状态不同 |

## 四、材质状态变化规则

| 材质 | 崭新 → 日常 | 日常 → 陈旧 | 损伤表现 | 激活/发光表现 |
|---|---|---|---|---|
| 金属 | 亮光泽 → 微划痕/氧化 | 划痕 → 氧化/锈迹/暗沉 | 缺口/卷边/断裂/凹陷/烧焦 | 高温红热、电流乱窜、反光增强、霓虹照射 |
| 玻璃 | 通透清晰 → 微划痕/水渍 | 划痕 → 裂纹/碎裂/暗沉 | 裂纹/碎裂/缺口/碎片/水渍 | 内部发光、屏幕亮起、反光增强、液体晃动 |
| 木材 | 新木纹理 → 自然包浆/使用痕迹 | 包浆 → 色泽暗沉/干裂/虫蛀 | 开裂/虫蛀/磨损/烧焦/断裂 | 温度升高、光泽变化、烟雾 |
| 塑料/胶木 | 崭新平整 → 微划痕/老化 | 划痕 → 老化变色/泛黄/脆化 | 裂纹/变形/褪色/融化/烧焦 | 按钮发光、屏幕透光、警告灯闪烁 |
| 布料 | 崭新平整 → 微褶皱/使用痕迹 | 褶皱 → 褪色/磨损/起球 | 撕裂/烧焦/污渍/食物残留/雨水 | 温度升高、光泽变化、烟雾、雨水湿润 |
| 皮革 | 崭新 → 微磨损/使用痕迹 | 磨损 → 色泽暗淡/裂纹/包浆 | 撕裂/烧焦/磨损/污渍/雨水 | 光泽变化、温度升高、霓虹照射 |
| 陶瓷 | 崭新 → 微使用/茶渍 | 使用 → 色泽暗淡/裂纹/茶渍 | 裂纹/碎裂/缺口/碎片/茶渍 | 光泽变化、温度变化、热气 |
| 丝绸 | 崭新 → 微褶皱/使用痕迹 | 褶皱 → 褪色/磨损/起丝 | 撕裂/烧焦/污渍/勾丝 | 光泽变化、温度升高、飘动 |

| 食物/液体 | 完整 → 半吃/晃动 | 半吃 → 吃完/残留/冷却 | 变形/洒落/残留/融化 | 热气/光泽/诱人/晃动/冰块 |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 道具核心造型/轮廓在所有状态中可识别 |
| R2 | 状态变化须符合物理逻辑，可夸张但不可荒谬 |
| R3 | 必须使用四宫格（2×2）布局 |
| R4 | 必须指定「纯净中性灰背景」或摄影棚背景，暧昧电影布光，浅景深，霓虹灯照射，烟雾朦胧 |
| R5 | 必须包含「王家卫电影风格」+「强烈色彩」+「霓虹灯」+「雨夜」+「烟雾」+「浅景深」+「朦胧感」+「真实材质」关键词 |
| R6 | 激活/发光/屏幕状态必须有明确的发光效果描述 |
| R7 | 食物/饮品类道具状态必须真实诱人，60年代香港风格 |
| R8 | 暧昧/霓虹状态必须有霓虹灯照射和红绿对比 |
| R9 | 60年代香港复古元素是核心，状态变化必须有时代感 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 状态变化后道具不可识别 |
| X2 | 违反物理逻辑的损伤 |
| X3 | 过度血腥/暴力/恐怖的损伤描绘 |
| X4 | 出现任何人物形象，包括全身、半身、局部（手、手指、手臂等肢体） |
| X5 | 道具处于被持有、握持、佩戴、使用中的状态 |
| X6 | 出现暗示人物存在的元素 |
| X7 | 卡通/动画/漫画/手绘风格（除非明确要求风格化） |
| X8 | 低幼Q版/萌系/日系纯爱风格 |
| X9 | 明亮清新/高对比硬光/低饱和灰调/莫兰迪色 |
| X10 | 塑料感材质/不真实的质感 |
| X11 | 在提示词中直接使用受版权保护的特定道具/物品名/品牌名 |
