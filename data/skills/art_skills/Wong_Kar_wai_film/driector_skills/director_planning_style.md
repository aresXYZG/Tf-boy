# 王家卫电影风格约束 · 电影风格 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以暖黄（C5）、暧昧肤（C1）、墨黑（C9）为基底色，整体色温偏暖（4000-5000K），饱和度中高（60-80%），呈现红绿对比的王家卫电影基调
- **撞色叙事对比** — 霓虹绿（C3）、霓虹红（C4）、深紫（C7）作为叙事转折的视觉信号，用于暧昧邂逅、雨夜孤独、幻想梦境与错过遗憾。撞色对比应与故事弧线同步，而非随意混用
- **冷暖分配策略** — 暧昧/夜生活/酒吧段落严格维持红绿对比（霓虹绿 C3 + 霓虹红 C4 + 深紫 C7），禁用明亮清新/高对比硬光；暖色（暖黄 C5 + 暧昧肤 C1 + 暖橙 C8）仅在日常、怀旧、回忆段落释放，用冷暖对比做叙事转折
- **色盘先行原则** — 段落规划需先绑定情绪场景（暧昧邂逅/雨夜孤独/怀旧回忆/错过遗憾/暧昧酒吧/街头擦肩/孤独公寓/幻想梦境），再确定主色+辅色与光影方案
- **禁用色域** — 明亮清新、高对比硬光、低饱和灰调、莫兰迪色、日系清新淡色、高饱和荧光色均与本风格不兼容（霓虹灯元素除外）

## 二、光影方案体系

- **光影即叙事** — 7 套光影方案对应不同情绪段落，导演规划阶段应在段落层面确定光影基调方向
- **王家卫光影特征** — 霓虹灯照射、红绿对比、浅景深、虚化、烟雾朦胧、暧昧光影为核心手段；光影必须服务于情绪叙事，保持王家卫电影的暧昧孤独感

| 光影方案 | 方案名 | 色调倾向 | 适用情绪 |
|---|---|---|---|
| A | 暧昧霓虹 | 霓虹绿 C3 + 霓虹红 C4 霓虹灯 | 暧昧邂逅、诱惑、夜生活、酒吧 |
| B | 雨夜孤独 | 深蓝 C6 + 墨黑 C9 + 霓虹绿 C3 | 雨夜孤独、寂寞、错过、街头 |
| C | 怀旧暖光 | 暖黄 C5 + 暖橙 C8 + 暧昧肤 C1 | 怀旧回忆、温暖、日常、60年代 |
| D | 低调沉重 | 墨黑 C9 + 深蓝 C6 + 朦胧灰 C10 | 错过遗憾、沉重、分别、孤独 |
| E | 梦幻柔光 | 深紫 C7 + 霓虹红 C4 + 暖黄 C5 | 幻想/梦境、花痴、迷恋、超现实 |
| F | 室内暧昧 | 暖黄 C5 + 霓虹红 C4 + 暧昧肤 C1 | 孤独公寓、私密、暧昧、室内 |
| G | 街头擦肩 | 霓虹绿 C3 + 深蓝 C6 + 暖黄 C5 | 街头偶遇、巧合、擦肩、日常 |

- **冷暖光分配** — 暖色光（暖黄 C5 + 暖橙 C8）适用于日常、怀旧、回忆、家庭段落；冷色光（深蓝 C6 + 墨黑 C9 + 霓虹绿 C3）适用于雨夜、孤独、错过、街头段落；红绿对比（霓虹绿 C3 + 霓虹红 C4）适用于暧昧、诱惑、夜生活、酒吧段落。导演可根据叙事需要调整冷暖切换点
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述光影方案（A-G）的某一方向，确保视觉一致性

## 三、质感方向

- **电影真实为锚** — 王家卫电影风格的核心：强烈色彩、霓虹灯、雨夜、烟雾、浅景深、朦胧感、真实材质、电影颗粒感，呈现强烈的王家卫电影画面
- **面容与表情** — 面容真实立体、表情暧昧含蓄（暧昧时眼神迷离、嘴角微扬、欲言又止；孤独时眼神空洞、肩膀下沉），皮肤质感真实，电影级妆容，烟雾朦胧
- **体型与比例** — 写实比例为主，7-8头身，真实比例，电影级审美。不胖不瘦或健美，避免过度夸张
- **服饰材质** — 衣物布料质感真实、纹理细节清晰、布料折痕自然、衣物随动态飘逸。60年代香港时尚（旗袍/西装/风衣/针织衫/连衣裙）的面料质感须可信，丝绸/皮革/布料质感真实
- **场景材质** — 场景材质纹理真实、空气透视、使用痕迹、生活气息、烟雾、乱中有序。木材/玻璃/金属/布料/霓虹灯质感均需在电影级光影下清晰呈现
- **王家卫不等于纪录片** — 王家卫电影风格强调在真实基础上叠加强烈色彩与霓虹灯，通过红绿对比与烟雾朦胧放大暧昧孤独感

## 四、王家卫场景空间元素

王家卫电影风格世界观特有的场景元素及其视觉叙事功能：

- **霓虹灯巷/夜生活** — 暧昧感的天然载体，霓虹灯招牌/狭窄巷道/烟雾/暧昧光/红绿对比。霓虹灯巷 = 暧昧与诱惑的舞台
- **雨夜街头/香港街道** — 孤独感的天然载体，雨/路灯/反光/雨伞/街道/霓虹灯倒影。雨夜 = 孤独与浪漫的舞台
- **60年代香港街景/唐楼** — 怀旧感的天然载体，唐楼/商店/招牌/行人/车辆/60年代。60年代街景 = 怀旧与日常的舞台
- **暧昧公寓/旅馆房间** — 私密感的天然载体，旧家具/电器/窗户/个人物品/烟雾/暖光。暧昧公寓 = 私密与孤独的舞台
- **酒吧/茶餐厅/餐厅** — 社交感的天然载体，吧台/桌椅/灯光/酒瓶/食物/烟雾/60年代。酒吧 = 暧昧与社交的舞台
- **天台/屋顶/维多利亚港** — 开阔感的天然载体，栏杆/城市景观/水塔/天线/夕阳/夜景/海。天台 = 孤独与沉思的舞台
- **段落间用场景空镜过渡** — 本风格有丰富的场景资产（不同时段/天候变体），段落衔接建议用场景空镜做情绪缓冲，不要硬切。霓虹灯巷、雨夜街头、60年代街景均可作为过渡空镜
- **转折点用视觉而非台词** — 优先使用画面手段（光影突变、景别跳切、空镜隐喻、表情定格、霓虹灯闪烁、烟雾弥漫）而非依赖对白解释

## 五、王家卫配乐与环境音

王家卫电影风格世界观下的声音元素约束：

### 配乐乐器选择

- **钢琴** — 核心乐器，适用范围最广：暧昧段落的抒情旋律、孤独段落的低沉旋律、怀旧段落的温暖旋律
- **弦乐（小提琴/大提琴/弦乐组）** — 情感铺底与升华，小提琴高音适合暧昧/心动，大提琴低沉适合孤独/怀旧，弦乐组适合情绪高潮
- **萨克斯/小号** — 爵士/夜生活/暧昧场景的核心，萨克斯适合暧昧/诱惑，小号适合怀旧/60年代
- **吉他（木吉他/电吉他）** — 日常/怀旧/60年代场景，木吉他适合日常/怀旧，电吉他适合暧昧/夜生活
- **合成器/电子** — 幻想/梦境/暧昧场景的氛围铺底，梦幻合成器适合幻想/梦境，低频电子适合暧昧/夜生活
- **打击乐** — 节奏核心，轻快打击乐适合日常/60年代，定音鼓适合情绪高潮
- **口琴/口哨** — 怀旧/60年代/日常常用，口琴适合怀旧/孤独，口哨适合日常/轻松
- **环境音/音效** — 暧昧音效（心跳声/呼吸声/风铃）、孤独音效（雨声/风声/脚步声）、怀旧音效（留声机/老式电话/60年代环境音）

### 配乐组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 暧昧邂逅/诱惑 | 钢琴抒情 + 萨克斯 + 弦乐 + 心跳音效 |
| 雨夜孤独/寂寞 | 钢琴低沉 + 大提琴 + 雨声/风声 |
| 怀旧回忆/温暖 | 钢琴 + 弦乐 + 口琴 + 留声机音效 |
| 错过遗憾/沉重 | 钢琴低沉 + 弦乐低沉 + 定音鼓 |
| 暧昧酒吧/夜生活 | 萨克斯 + 爵士钢琴 + 低音提琴 + 酒杯碰撞声 |
| 街头擦肩/巧合 | 木吉他 + 轻钢琴 + 城市环境音 |
| 孤独公寓/私密 | 钢琴独奏 + 弦乐低沉 + 呼吸声/时钟声 |
| 幻想/梦境/花痴 | 梦幻合成器 + 钢琴 + 弦乐 + 梦幻音效 |

### 王家卫环境音

- **典型环境音层次** — 城市车流远声 / 霓虹灯嗡嗡声 / 雨声 / 脚步声 / 心跳声 / 呼吸声 / 酒杯碰撞声 / 留声机沙沙声 / 老式电话铃声 / 时钟滴答声 / 风声 / 烟雾嘶嘶声 / 海浪声 / 粤语对话背景声
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越丰富，王家卫电影场景越有沉浸感
- **静默是暧昧核心** — 暧昧/心动段落常用突然静默，只保留心跳声/呼吸声/风声，静默中的异响 = 最大暧昧
- **爵士乐是夜生活核心** — 酒吧/夜生活段落常用萨克斯/爵士钢琴/低音提琴，爵士乐本身就是暧昧与诱惑的标志
- **留声机是怀旧核心** — 怀旧/60年代段落常用留声机沙沙声/老式音乐，留声机本身就是怀旧的标志

## 六、视频生成工作流约束

- **关键帧先行** — 带文字画面（标题、拟声词、标语、招牌、霓虹灯标识等）必须先生成关键帧图片确认文字准确，再用图生视频
- **角色一致性锚定** — 每段视频prompt必须重复角色核心外观锚点（发型、服装主色、标志性特征）
- **分段生成** — 单段不超过15秒，长视频按叙事段落拆分
- **后期合成** — Logo/徽标/标语等品牌元素预留空位后期合成
- **王家卫经典镜头语言** — 慢动作、抽帧、手持摄影、框架构图、倾斜构图、浅景深+虚化、特写、过肩镜头
- **红绿对比是核心** — 所有段落必须保持红绿对比基调，霓虹灯照射，烟雾朦胧
