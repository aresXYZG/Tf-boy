# 分镜表王家卫电影风格约束 · 电影风格 · 技法参考

---

## 一、分镜表定位

分镜表是导演将剧本转化为镜头语言的核心工具。以下仅提供王家卫电影风格在分镜表层面的约束规范。

---

## 二、光影与氛围

- **同场戏光影统一** — 一场戏内不应出现两种以上光影方案，除非有明确的叙事转折（如室内灯光切换→窗外暮色渐深、门打开→霓虹灯涌入、霓虹灯闪烁→暧昧光）
- **情绪色盘绑定** — 每场戏至少绑定 1 个情绪场景（暧昧邂逅/雨夜孤独/怀旧回忆/错过遗憾/暧昧酒吧/街头擦肩/孤独公寓/幻想梦境），并在镜头组内保持主色+辅色连续性
- **光源角度规范** — 正给镜头光源默认暧昧电影布光或霓虹灯，侧给镜头根据画面需要调整。描述光影时须区分自然光（窗光/阳光/月光）与人造光（灯光/屏幕光/路灯/霓虹灯/暖光）的差异
- **冷暖色调与叙事阶段匹配** — 暧昧/夜生活/酒吧段落严格使用红绿对比（霓虹绿 C3 + 霓虹红 C4 + 深紫 C7），禁用明亮清新/高对比硬光；暖色（暖黄 C5 + 暧昧肤 C1 + 暖橙 C8）仅在日常、怀旧、回忆、家庭段落使用；冷色（深蓝 C6 + 墨黑 C9）仅在雨夜、孤独、错过、街头段落使用
- **光影转场是高级手段** — 从窗外自然光渐变到室内暖灯光 = 日转夜的时间流逝；从明亮60年代街景到昏暗霓虹灯巷 = 情绪转折；从正常光到梦幻柔光 = 幻想开始。在分镜表中标注光影变化点
- **发光元素是叙事工具** — 霓虹灯/屏幕/暖灯/蜡烛/夕阳的状态变化（亮→灭、正常→暧昧、霓虹灯闪烁）可作为叙事信号，在分镜表中标注发光状态变化点
- **红绿对比是核心** — 明暗反差必须强烈，暗部占比根据情绪调整（暧昧30-40%、雨夜40-50%、怀旧30-40%、错过50-60%、酒吧40-50%）

## 三、环境动态

- **环境动态增加画面呼吸感** — 霓虹灯闪烁、烟雾弥漫、雨丝飘落、窗帘轻摆、头发飘动、酒杯晃动、留声机转动、时钟滴答、蒸汽升腾。每 2-3 个镜头至少安排一个有环境动态的镜头，避免画面"死"掉
- **王家卫环境元素优先** — 环境动态应选用王家卫电影世界观内的元素：霓虹灯闪烁、烟雾弥漫、雨丝飘落、窗帘轻摆、头发飘动、酒杯晃动、留声机转动、时钟滴答、蒸汽升腾、粤语对话背景声、海浪声、风声，禁止出现古风/奇幻/暗黑/科幻元素（特定场景除外）
- **电影级动态表现** — 环境动态应符合王家卫电影的表现方式：霓虹灯的闪烁、烟雾的流动、雨丝的反光、头发的自然飘动、酒杯的晃动、留声机的转动、蒸汽的升腾
- **夸张环境动态是暧昧工具** — 王家卫常用夸张环境动态强化效果：暧昧时烟雾突然弥漫/霓虹灯闪烁/头发飘动；孤独时雨丝突然变大/风突然吹起；怀旧时留声机突然转动/蒸汽升腾。在分镜表中标注此类夸张环境变化

## 四、王家卫人物动作节奏

- **动作要符合情绪** — 暧昧时动作缓慢/温柔/细腻，孤独时动作缓慢/沉重/僵硬，怀旧时动作缓慢/温柔/回忆，日常时动作自然/放松。关键动作（转身、抬手、擦肩而过、回头、吸烟）标注情绪对应的速度和幅度
- **服饰动态** — 王家卫服饰（旗袍下摆、风衣、围巾、连衣裙、头发）的动态是天然的画面资产，可在画面描述中加入衣物随风/随动作的飘动，增加画面的"活"感。头发飘动是王家卫暧昧场景的标志性元素
- **仪态约束** — 王家卫角色的举止应符合角色性格：暧昧角色放松/微倾/眼神迷离，孤独角色含胸/低头/肩膀下沉，高冷角色挺拔/后仰/面无表情，怀旧角色温柔/缓慢/回忆。不出现标准化的"优雅克制"仪态
- **表情优先于动作** — 以面部暧昧含蓄表情（暧昧时眼神迷离、嘴角微扬、欲言又止；孤独时眼神空洞、肩膀下沉）传达情绪，表情幅度必须小但含蓄。肢体动作为表情和情绪服务
- **预备-动作-反应三段式** — 王家卫动作遵循经典三段式：预备（蓄力/表情变化/肌肉绷紧）→ 动作（执行/缓慢/细腻）→ 反应（定格/慢动作/表情变化/回头凝望）。在分镜表中拆解动作时遵循此节奏
- **慢动作的暧昧功能** — 升格在王家卫电影中用于"关键瞬间"：暧昧对视、擦肩而过、回头凝望、初雪飘落、雨夜漫步、吸烟、酒杯晃动——慢动作让观众有足够时间感受暧昧或孤独，冲击力在慢动作中积蓄
- **抽帧的时间感** — 抽帧在王家卫电影中用于"时间流逝/奔跑/追逐/回忆"等场景，抽帧让动作有卡顿感和时间感，增加电影质感
- **王家卫经典动作库** — 经典王家卫动作：暧昧对视/眼神迷离/欲言又止、擦肩而过/回头凝望/慢动作、吸烟/烟雾缭绕/手指夹烟、喝酒/酒杯晃动/眼神放电、梳头/镜子/暧昧、奔跑/抽帧/时间流逝、等待/孤独/时钟滴答
- **手持摄影的不稳定感** — 暧昧/紧张/孤独段落常用手持摄影，增加不稳定感和代入感，让观众有"偷窥"的感觉

## 五、运镜禁忌

- **运镜要服务于暧昧节奏** — 王家卫运镜可以比其他风格更灵活，但必须服务于暧昧感和孤独节奏
- **固定 = 日常/冷静/暧昧前的静默** — 日常场景、对话场景、暧昧前的静默用固定机位，稳定感。固定后的突然变化 = 最大暧昧或孤独
- **缓慢推进 = 暧昧/心动 buildup** — 暧昧/心动段落常用缓慢推进，让观众逐渐靠近暧昧源，温馨感逐渐积累。这是王家卫浪漫场景中最高频的运镜之一
- **急推 = 反应放大/情绪爆发/关键瞬间** — 某个角色看到/听到关键信息，快速推向其面部，放大"暧昧/震惊/孤独"的反应。关键瞬间时急推强化冲击力
- **甩镜 = 信息揭示/偶遇转折/暧昧** — 从角色A迅速甩到角色B/偶遇对象/暧昧元素，速度本身带有"等等！那是谁？！"的紧张感或暧昧感
- **跟随 = 追逐/移动/日常/擦肩而过** — 追逐戏、角色移动、日常行走、擦肩而过，用跟随运镜，保持角色在画面中心，背景流动
- **过肩 = 对话/暧昧/对视** — 王家卫对话/暧昧场景常用过肩镜头，增加代入感和亲密感
- **框架构图 = 王家卫经典/暧昧/沉思** — 王家卫常用框架构图（窗户/门框/镜子），增加画面层次和暧昧感
- **Dutch角 = 暧昧/紧张/怪诞/不安** — 倾斜构图用于暧昧场景、紧张情绪、怪诞感、不安。王家卫常用Dutch角强化暧昧和怪诞感
- **低角度仰拍 = 压迫/高大/暧昧/神秘** — 高大建筑/反派/神秘角色/暧昧登场，用低角度仰拍强化压迫感和神秘感
- **高角度俯拍 = 渺小/迷失/孤独/全貌** — 孤独场景、迷失感、角色渺小感、城市全貌，用高角度俯拍。展示全局孤独和迷失感
- **运镜即节奏** — 固定 = 日常/冷静；缓慢推进 = 暧昧 buildup；急推 = 反应放大；甩镜 = 信息揭示；跟随 = 追逐/移动；过肩 = 对话/暧昧；框架构图 = 王家卫经典；Dutch角 = 暧昧/怪诞；低角度 = 压迫/神秘；高角度 = 渺小/孤独
- **不要过度运镜** — 日常和暧昧段落保持稳定，关键瞬间和转折可以灵活运镜。运镜过多会分散对角色和情绪的注意力

## 六、转场设计

- **硬切为主** — 王家卫场景内剪辑节奏偏快，硬切为主，不拖泥带水
- **暧昧转场** — 从日常场景硬切到暧昧场景，反差本身就是暧昧效果。常用：门打开→霓虹灯涌入、对视→慢动作、烟雾弥漫→过曝、擦肩而过→回头凝望
- **孤独转场** — 从暧昧/日常突然硬切到孤独场景，反差本身就是孤独效果。常用：霓虹灯熄灭→全黑、热闹酒吧→空荡街道、对视→独自离开
- **光影转场** — 用光影变化做转场：霓虹灯闪烁→全黑→亮起新场景、暖光涌入→过曝→新场景、烟雾弥漫→充满画面→新场景
- **匹配剪辑** — 用形状/动作/颜色匹配做转场：霓虹灯→月亮、眼睛→霓虹灯、红色→口红、烟雾→云、擦肩而过→追逐
- **假正经转场** — 用正式/庄重的转场方式（淡入淡出、字幕卡"Meanwhile"、光圈转场）来过渡暧昧/孤独内容，反差出戏剧感
- **慢动作转场** — 用慢动作做转场：暧昧对视慢动作→正常速度日常、擦肩而过慢动作→正常速度孤独
- **抽帧转场** — 用抽帧做转场：正常速度→抽帧→正常速度，增加时间感和电影质感
- **王家卫经典转场** — 霓虹灯/烟雾/雨夜作为转场元素，从一个场景飘到另一个场景，增加王家卫感
- **打破第四面墙** — 角色突然看向镜头/对观众说话的瞬间用正面近景+突然静止，制造"你看到了吧？"的共谋感或暧昧感

## 七、文字画面处理

- **带文字画面必须关键帧先行** — 标题、拟声词、标语、招牌、霓虹灯标识、屏幕显示等带文字画面，必须先生成关键帧图片确认文字准确，再用图生视频
- **关键帧作为参考图** — 生成的关键帧图片作为图生视频的参考图传入，文字准确性由关键帧保障
- **视频prompt仍需描述文字** — 视频prompt中仍需描述文字内容和位置，但不依赖视频模型直接生成文字
- **霓虹灯标识/招牌是核心元素** — 王家卫场景的霓虹灯标识、招牌是标志性元素，文字必须清晰可辨，建议先生成关键帧确认文字
- **拟声词** — 王家卫风格常用"咯噔""嘶——""咚""滴答"等拟声词，拟声词必须先生成关键帧确认文字准确
- **品牌元素后期合成** — Logo/徽标/官方标语等品牌元素建议在视频中预留空位，后期合成（AI直接画品牌物易乱码）
- **画内文字 vs 画外文字** — 故事世界内的道具文字（霓虹灯标识、招牌、屏幕显示、标语、海报）属于画内文字，应如实描写；字幕、水印、标题卡、旁白叠字属于画外文字，严禁出现
