# 王家卫电影风格说明

本风格专为**王家卫电影风格**题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **王家卫电影摄影风格**：所有角色、场景、道具均以王家卫电影摄影为标准，强调强烈色彩、霓虹灯、雨夜、烟雾、浅景深、朦胧感、手持摄影、慢动作、抽帧。
- **都市孤独浪漫叙事背景**：涵盖香港都市、60年代怀旧、雨夜街头、霓虹灯巷、暧昧酒吧、孤独公寓、擦肩而过、错过与重逢等，杜绝低幼卡通/纯写实纪录片/暗黑恐怖元素。
- **电影级构图**：画面构图强调王家卫式构图，框架构图、倾斜构图、浅景深、虚化、朦胧感、宽银幕比例。
- **强烈色彩对比**：整体色调偏暖（绿/黄/红），红绿对比强烈，霓虹灯色彩，雨夜反光，烟雾朦胧，电影级颗粒感。

## 适用范围

- 王家卫电影风格题材的AI美术生成（角色、场景、道具、分镜等）
- 都市孤独/浪漫/暧昧/怀旧叙事风格的视觉创作
- 需要强烈色彩、霓虹灯、雨夜、烟雾、浅景深、朦胧感的视觉创作
- 品牌IP短片、文艺宣传、怀旧短片等需要王家卫风格的项目

## 严禁内容

- 卡通/动画/漫画/手绘风格（除非明确要求风格化）
- 低幼Q版/萌系/日系纯爱风格
- 高饱和荧光色/霓虹色（除非是霓虹灯元素）
- 直接使用受版权保护的特定电影角色名或演员名
- 暗示性、暴露、低俗等不适宜内容
- 过度血腥/暴力/恐怖内容
- 明亮清新/高对比硬光/低饱和灰调

## 风格体验

在本风格下，您将体验到：

- 角色面容真实立体、表情暧昧含蓄（眼神迷离、嘴角微扬、欲言又止），皮肤质感真实，电影级妆容，烟雾朦胧
- 场景空间迷离，香港都市街道/霓虹灯巷/雨夜街头/暧昧酒吧/孤独公寓，材质纹理真实，红绿对比，霓虹灯色彩，氛围暧昧且富有电影感
- 道具、装备、科技装置等均为电影级造型，真实材质，怀旧设计，烟雾朦胧
- 分镜与视频均以王家卫电影为基础，强调镜头语言与暧昧节奏，慢动作、抽帧、手持摄影、宽银幕质感

## 视频生成工作流（关键帧+图生视频）

本风格推荐使用"关键帧先行"工作流，特别适用于带文字画面和角色一致性要求高的项目：

1. **关键帧生成**：对每段中带文字的关键画面（标题、拟声词、标语、招牌、霓虹灯标识等），先用文生图生成静态关键帧，确认文字准确无误
2. **图生视频**：将关键帧作为参考图传入视频生成工具，配合时间轴分镜prompt生成动态视频
3. **角色一致性锚定**：每段prompt中重复角色核心外观锚点（发型、服装主色、标志性特征），防止跨段角色漂移
4. **分段生成**：单段不超过15秒，长视频按叙事段落拆分后拼接
5. **后期合成**：Logo/徽标/标语等品牌元素在视频中预留空位，后期合成

---

本风格仅适用于"王家卫电影风格"相关项目。如需其他风格（如卡通动画、日系动画、美式成人动画等），请勿使用本套提示词。
