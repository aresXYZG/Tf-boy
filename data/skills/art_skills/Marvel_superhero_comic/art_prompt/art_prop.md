## 一、道具设计原则

### 文书/告示/纸条类道具文字排版规则（必守）
若道具为文书、告示、纸条、清单、便签、规章制度、卡片等包含明确文字内容的道具：
1. **双引号逐字精准输出**：在提示词中必须使用双引号将文字标题与核心条款逐字精准标出（例如：包含清晰可见的书法/印刷文字标题 "【顾客须知】" 以及逐条清晰排版的规则内容 "1. 禁止投喂" "2. 违者后果自负"）。
2. **文字排版与可读性**：必须明确描述文字的字迹风格（如：深黑墨迹手写体 / 醒目印刷体 / 红色印章）、纸张折痕与排版布局（居中大标题、分行条例清晰、段落整齐），确保生图模型精准逐字渲染，严禁模糊乱码或乱画无意义字符。


1. **功能可读** — 道具用途一目了然，造型服务于功能，可适度夸张
2. **质感硬朗** — 材质纹理必须清晰可辨（金属/塑料/木材/玻璃/布料/能量），金属质感强烈
3. **风格统一** — 所有道具必须符合美式超级英雄漫画世界观，硬朗墨线，戏剧性光影
4. **尺度明确** — 通过参照物或标注暗示道具真实尺寸，可夸张比例
5. **纯道具独立展示** — 画面中只能出现道具本身，严禁出现任何人物、手部、肢体，道具不可处于被持有/佩戴/握持状态，必须以静物陈列方式独立呈现

## 三、多角度设定图规范

### 视图定义

| 位置 | 视图 | 角度 | 要求 | 提示词 |
|---|---|---|---|---|
| 左上 | 正面图 | 正面 0° | 道具完整正面形态 | front view |
| 右上 | 侧面图 | 侧面 90° | 厚度/轮廓/结构清晰 | side view |
| 左下 | 背面图 | 背面 180° | 道具背部结构/装饰 | back view |
| 右下 | 细节特写 | 局部放大 | 材质纹理/工艺细节/按钮/发光元件 | detail closeup |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面四宫格（2×2），上下左右四视角 |
| 背景 | 纯净中性灰 `#808080` |
| 光线 | 戏剧性侧光，硬朗阴影，金属反光 |
| 比例 | 每格道具占格内主体 70%+ |
| 投影 | 允许自然地面微投影 |
| 画面比例 | 建议 1:1 |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须指定「纯净中性灰背景」 |
| R2 | 必须明确道具材质与工艺 |
| R3 | 道具造型必须符合美式超级英雄漫画世界观，可适度夸张 |
| R4 | 必须包含「美式超级英雄漫画风格」+「硬朗墨线」+「戏剧性光影」关键词 |
| R5 | 必须使用四宫格（2×2）布局 |
| R6 | 武器/科技装置/载具类必须有发光元件或夸张设计 |
| R7 | 金属材质必须有强烈反光和硬朗轮廓 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 复杂场景背景 |
| X2 | 道具与人物同画面 |
| X3 | 出现任何人物形象，包括全身、半身、局部（手、手指、手臂等肢体） |
| X4 | 道具处于被持有、握持、佩戴、使用中的状态 |
| X5 | 出现暗示人物存在的元素 |
| X6 | 使用真人写实/摄影/3D渲染相关词 |
| X7 | 低幼Q版/萌系风格 |
| X8 | 写实武器设计（必须保持漫画/科幻风格） |
| X9 | 在提示词中直接使用受版权保护的特定武器/装备名 |
