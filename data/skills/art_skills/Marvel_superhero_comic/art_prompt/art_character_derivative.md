# 美式超级英雄漫画人物衍生资产生成 · 约束手册

---

## 一、叠加原则

1. **面容不变** — 叠加后五官必须与底模完全一致，禁止面容偏移
2. **姿态不变** — 保持底模英雄站立姿态，禁止任何姿态/动作/体态变化
3. **逐层可控** — 每层独立描述，便于按层替换（换装不换妆）
4. **风格统一** — 所有服化元素服从同一美式超级英雄漫画美学体系
5. **质感不降** — 叠加后质感标准不低于底模
6. **纯服化范畴** — 仅叠加妆容/发型/服饰/配饰/装备/鞋履，禁止引入道具、场景、环境、动作

---

## 二、叠加层级

| 层级 | 内容 | 说明 |
|---|---|---|
| L0 | 底模 | 基础形象底模，不修改 |
| L1 | 表情/妆容（决策层） | 先分析用户线索，再决策表情强度与妆容风格 |
| L2 | 发型/头盔造型 | 发型变化/头盔/面罩/头饰 |
| L3 | 内搭/紧身衣 | 替换基础内搭或紧身战斗服 |
| L4 | 外衣/装甲/披风 | 美式英雄差异化服装（战斗服/装甲/风衣/披风等） |
| L5 | 配饰/装备 | 徽章/腰带/手套/护腕/科技装置等 |
| L6 | 鞋履 | 战靴/运动鞋/皮鞋/异形鞋等，与整体服装完整配套 |

> **范畴边界**：人物衍生资产仅包含 L0–L6 层级（服化妆造装备），不包含手持武器/道具（盾牌/锤子/弓等属于道具资产）、场景环境、姿态动作。

### 差异化着装原则

| 项目 | 约束 | 说明 |
|---|---|---|
| 角色区分 | 根据角色身份、能力、性格决定战斗服风格与配色 | 禁止所有英雄同款同色同搭配 |
| 同风格差异 | 即使同为紧身战斗服，也要区分标志/披风/配色/细节 | 保持统一审美，不做制服化处理 |
| 场景适配 | 战斗/日常/正式/太空分别切换服装方案 | 服装应随情境变化而变化 |
| 主服色固定 | 每个角色有1-2个固定主服色，跨场景保持识别 | 主服色是角色识别核心 |

## 九、四视图设定图规范（无头素体防干扰版）

> 衍生服化叠加后仍需输出四视图设定图，确保服化妆造在各角度的高度一致性。

### 视图定义

| 位置 | 视图 | 角度 | 景别 | 要求 | 提示词 |
|---|---|---|---|---|---|
| 左一 | 人像超大特写 | 正面平视 | 头顶至锁骨 | 从头顶到锁骨完整展示不裁切，面部占60%+，锁定高精五官细节、L1表情与妆容 | `portrait closeup`, `face detail`, `ultra detailed face` |
| 左二 | 正视图全身（无头素体） | 正面 0° | 颈部以下至脚底 | 面对镜头、双臂自然、从颈部以下到脚底完整展示，**颈部以上完全留空不画头部**，展示体型与L3/L4服装全貌 | `front view`, `headless body`, `full body neck to toe` |
| 右二 | 侧视图全身（无头素体） | 右侧 90° | 颈部以下至脚底 | 纯侧面轮廓、从颈部以下到脚底完整展示，**颈部以上完全留空不画头部**，展示体态与侧面层次 | `side view`, `headless body`, `profile neck to toe` |
| 右一 | 后视图全身（完整后背与后脑） | 后方 180° | 全身立像 | 后脑发型、发尾、背部服装版型与鞋底完整清晰展示 | `back view`, `rear view`, `full body head to toe` |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面从左至右并排四视图（左一人像特写 + 左二正视图无头素体 + 右二侧视图无头素体 + 右一后视图全身） |
| 背景 | 纯净中性灰 `#808080` |
| 站姿 | 自然站立、双脚平行微分、双臂自然下垂或微展（**禁止任何姿态变化**） |
| 素体约束 | 左二与右二必须为无头素体（颈部以上截断留空），强制AI在特征提取时仅锁定左一人像特写，杜绝全身小脸畸变与特征冲突 |
| 特写展示 | 人像特写必须从头顶到锁骨完整入画，严禁裁切头顶 |
| 一致性 | 四视图的面容/妆容/发型/服饰/配饰/鞋履完全一致 |
| 光线 | 均匀柔光，自然阴影 |
| 画面比例 | 建议 4:1 或 3:1 |

## 十一、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 叠加后面容必须与底模一致 |
| R2 | 服饰必须用「衣服质感清晰 + 纹理清晰」 |

| R4 | 英雄角色必须有标志性元素（徽章/披风/头盔/独特配色） |
