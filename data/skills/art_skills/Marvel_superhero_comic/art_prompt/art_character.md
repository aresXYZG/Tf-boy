# 美式超级英雄漫画人物基础形象生成 · 约束手册

---

## 一、基础形象原则

1. **力量即灵魂** — 肌肉线条与力量姿态是角色唯一锚点，精细度适配美式超级英雄漫画风格
2. **角色为本** — 基础着装由角色描述（身份/职业/性别/阵营）决定其常规着装；后续特定服化为叠加层
3. **四视图一致** — 面容/体型/发型/基础服装跨视图高度统一
4. **轮廓辨识度** — 每个角色必须有独特的剪影轮廓，即使去掉颜色也能区分
5. **英雄比例** — 肩宽腰窄、倒三角体型、肌肉发达，符合美式英雄审美

## 二、面容约束

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型，但必须硬朗 |
| 风格底色 | 美式超级英雄漫画风格、硬朗墨线、肌肉感、戏剧性光影、高对比饱和色 |
| 气质 | 必须从角色描述提炼整体气质关键词（如坚毅/威严/阴险/阳光/冷峻），并写入提示词 |
| 表情 | 中性微表情，符合角色气质，但保留戏剧化潜力 |
| 轮廓 | 脸型轮廓硬朗，下颌线分明，避免圆润柔和 |

### 美式漫画英雄特征（必含）

| 特征 | 描述 | 提示词 |
|---|---|---|
| 方下颌 | 下颌线硬朗分明，下巴方正 | 方下颌、硬朗下颌线 |
| 浓眉 | 眉毛浓密，位置和形状随表情大幅变化 | 浓眉、英雄眉 |
| 锐利眼神 | 眼睛锐利有神，目光坚定 | 锐利眼神、目光如炬 |
| 高鼻梁 | 鼻梁高挺，轮廓分明 | 高鼻梁、挺拔鼻梁 |
| 硬朗轮廓线 | 面部轮廓用硬朗墨线勾勒，线条有力量感 | 硬朗墨线、力量感轮廓 |
| 表情戏剧化 | 表情幅度大，愤怒时咬牙、胜利时昂首、坚定时皱眉 | 戏剧化表情、表情有力 |

## 四、体型约束

### 通用

| 项目 | 约束 | 提示词 |
|---|---|---|
| 身高 | 由角色设定指定，通过头身比换算体现 | `{身高}cm tall`、`{身高描述}` |
| 头身比 | 美式英雄夸张比例，7-9头身为主，英雄角色偏高 | `7-9 heads tall proportion`、英雄比例 |
| 体型 | 必须有肌肉感，肩宽腰窄倒三角，避免瘦弱 | 肌肉发达、倒三角体型、肩宽腰窄 |
| 手部 | 手掌宽大，手指有力，握拳时肌肉明显 | 宽大手掌、有力手指 |
| 体态 | 符合角色性格的力量姿态（英雄挺胸/反派含胸/战士马步） | 力量姿态、{体态描述} |

### 体型类型速查

| 体型 | 描述 | 适用角色 | 提示词 |
|---|---|---|---|
| 英雄型 | 肩宽胸厚，倒三角，肌肉发达，八块腹肌 | 主角英雄、战士 | muscular、broad shoulders、heroic build |
| 巨人型 | 身高极高，体型庞大，肌肉夸张 | 巨人、力量型英雄 | giant、massive、huge build |
| 敏捷型 | 肌肉紧实但不夸张，四肢修长，灵活 | 速度型英雄、刺客 | athletic、lean muscle、agile build |
| 装甲型 | 体型被装甲覆盖，轮廓方正，金属感 | 装甲英雄、机械战士 | armored、mechanical build |
| 反派型 | 瘦削或畸形，姿态阴狠，不对称 | 反派、疯子 | lanky、sinister build |
| 标准型 | 比例匀称，有肌肉但不夸张 | 普通人、配角 | average build、proportionate |

## 六、基础服装约束

> 基础服装由角色描述（身份/职业/性别/阵营）决定其最自然的常规着装，作为该角色「日常默认态」；战斗服/特殊衍生在服化衍生环节叠加。

### 着装选择原则

| 角色身份 | 默认着装方向 |
|---|---|
| 超级英雄 | 特色战斗服/制服/装甲 + 披风/标志 |
| 普通人/市民 | 休闲装/T恤+牛仔裤/职业装 |
| 科学家/发明家 | 白大褂/实验服 + 内搭 |
| 军人/特工 | 军装/战术装备/黑色作战服 |
| 反派/恶棍 | 黑色装甲/怪异服装/西装（优雅反派） |
| 外星人 | 异星风格服装/金属质感/发光元素 |
| 角色描述未明确 | 美式休闲装，高饱和对比色 |

### 着装统一规则

- 服装风格须与美式超级英雄漫画美学一致（硬朗墨线、戏剧性光影、高对比饱和色）
- 颜色高饱和，对比强烈，每个角色有固定主服色
- 四视图服装款式完全一致
- 基础服装是「日常默认态」，焦点仍在面容与体型
- 英雄战斗服必须有标志性元素（徽章/标志/披风/头盔/独特配色）
- 服装可有夸张设计（大翻领、宽腰带、装甲板、披风等）

## 七、四视图设定图规范（双参考垫图融合与无头素体防干扰版）

### 双真人参考图（垫图）特征融合机制（核心必守）
系统在生成四视图设定图时，支持从人脸参考资产库中匹配抽取 2 张真人人脸参考底图（图1与图2）进行解耦融合，生成全新原创角色：
1. **图 2（主要参考 70%）**：主导人物面部五官排布、眼型神韵、唇形特征与生活化/故事感神态，确立角色的核心面孔基底；
2. **图 1（辅助参考 30%）**：提供骨相立体度、下颌线轮廓骨感、鼻骨结构与皮肤通透细腻质感；
3. **画风媒介属性转化**：模型将提取的双真人参考特征自动转化为当前【美式超级英雄美漫】的专属艺术媒介（如墨线描边、赛璐璐平涂、PBR渲染、黏土塑形等），严禁生硬贴图；
4. **原创独立与人种/年龄参数化**：生成完全独立的全新原创角色，杜绝千篇一律的 AI 网红模板脸。根据剧本设定动态适配人种（东亚/欧美/混血/非裔等）与年龄段（少年/青年/中年/老年）。若参考底图与设定有年龄差异，由提示词动态注入年龄修饰词，模型自动渲染对应年龄段的面部特征与皮肤质感。

### 视图定义

| 位置 | 视图 | 角度 | 景别 | 要求 | 提示词 |
|---|---|---|---|---|---|
| 左一 | 人像超大特写 | 正面平视 | 头顶至锁骨 | 从头顶到锁骨完整展示不裁切，面部占60%+，锁定基于两张垫图融合出的高精五官细节、神态与媒介质感 | `portrait closeup`, `face detail`, `ultra detailed face` |
| 左二 | 正视图全身（无头素体） | 正面 0° | 颈部以下至脚底 | 面对镜头、双臂自然、从颈部以下到脚底完整展示，**颈部以上完全截断留空不画头部**，展示体型与服装全貌 | `front view`, `headless body`, `full body neck to toe` |
| 右二 | 侧视图全身（无头素体） | 右侧 90° | 颈部以下至脚底 | 纯侧面轮廓、从颈部以下到脚底完整展示，**颈部以上完全截断留空不画头部**，展示体态与侧缝细节 | `side view`, `headless body`, `profile neck to toe` |
| 右一 | 后视图全身（完整后背与后脑） | 后方 180° | 全身立像 | 后脑发型、发尾、背部服装版型与鞋底完整清晰展示 | `back view`, `rear view`, `full body head to toe` |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面从左至右横排四视图（3:1 或 4:1）：左一人像超大特写 + 左二正视图无头素体 + 右二侧视图无头素体 + 右一后视图全身立像 |
| 背景 | 纯净中性灰 `#808080`（或画风适配纯色中灰背景纸） |
| 站姿 | 自然站立、双脚平行微分、双臂自然下垂或微展 |
| **无头防干扰机制** | **左二与右二必须为无头素体（颈部以上留空截断）**，迫使生图模型将面部注意力与像素算力100%集中在左一超大特写上，彻底根除全身小脸五官变形与多头特征冲突 |
| 特写展示 | 人像特写必须从头顶到锁骨完整入画，严禁裁切头顶 |
| 光线 | 均匀柔光，前方主光 + 双侧补光，自然阴影 |
| 画面比例 | 建议 4:1 或 3:1 |

## 九、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须包含「美式超级英雄漫画风格」+「硬朗墨线」+「肌肉线条分明」 |
| R2 | 必须根据角色描述声明合适的常规着装作为基础服装；英雄必须有标志性元素 |
| R3 | 必须声明角色有独特发型和倒三角肌肉体型 |
| R4 | 必须指定「纯净中性灰背景」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头顶到脚底完整展示，严禁裁切 |
| R7 | 必须声明角色身高并通过头身比换算约束全身比例 |
| R8 | 人像特写必须从头顶到锁骨完整展示，严禁裁切头顶 |
| R9 | 每个角色必须有固定主服色和标志性元素，跨镜头不得漂移 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 真人写实/摄影/3D渲染风格 |
| X2 | 低幼Q版/萌系/日系纯爱风格 |
| X3 | 正顶硬光/正底光/柔和漫射光 |
| X4 | 复杂场景背景（必须纯灰底） |
| X5 | 全身立像裁切头顶或脚底 |
| X6 | 人像特写裁切头顶 |
| X7 | 忽略身高和头身比约束 |
| X8 | 瘦弱/无肌肉体型（除非角色设定明确要求） |
| X9 | 在提示词中直接使用受版权保护的特定超级英雄角色名 |
