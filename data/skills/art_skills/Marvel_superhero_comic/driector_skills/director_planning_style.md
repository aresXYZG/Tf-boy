# 美式超级英雄漫画约束 · 漫画风格 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以英雄红（C3）、英雄蓝（C4）、能量金（C5）为基底色，整体色温中性（5500-6500K），饱和度高（70-90%），呈现高对比饱和色的美式漫画基调
- **撞色叙事对比** — 互补色（红/绿、蓝/橙、紫/黄）作为叙事转折的视觉信号，用于情绪爆发与场景切换。撞色对比应与故事弧线同步，而非随意混用
- **冷暖分配策略** — 悬疑/压迫/反派段落严格维持冷色调基底（英雄蓝 C4 + 暗影紫 C7 + 墨黑 C9），禁用能量金、爆炸橙等暖色调；暖色仅在英雄登场、胜利时刻、日常段落释放，用冷暖对比做叙事转折
- **色盘先行原则** — 段落规划需先绑定情绪场景（英雄登场/战斗冲突/对峙压迫/灾难救援/胜利时刻/内心挣扎/科幻基地），再确定主色+辅色与光影方案
- **禁用色域** — 低饱和灰调、莫兰迪色、日系清新淡色均与本风格不兼容

---

## 二、光影方案体系

- **光影即叙事** — 7 套光影方案对应不同情绪段落，导演规划阶段应在段落层面确定光影基调方向
- **美式漫画光影特征** — 硬朗的明暗分界线、戏剧性光影、高对比为核心手段；光影必须服务于情绪叙事，保持美式超级英雄漫画的力量感

| 光影方案 | 方案名 | 色调倾向 | 适用情绪 |
|---|---|---|---|
| A | 英雄登场光 | 能量金 C5 + 英雄红 C3 放射状 | 英雄登场、胜利时刻、张扬自信 |
| B | 硬侧高反差 | 墨黑 C9 + 英雄红 C3 硬光分割 | 对峙压迫、愤怒冷峻、紧张对抗 |
| C | 低调冷光 | 英雄蓝 C4 + 暗影紫 C7 低调打光 | 悬疑紧张、内心挣扎、孤独寂寥 |
| D | 科幻荧光 | 暗影紫 C7 + 能量金 C5 发光 | 科幻基地、异星场景、科技装置 |
| E | 暖光日常 | 爆炸橙 C8 + 健康肤 C1 侧光 | 室内日间、日常起居、都市生活 |
| F | 夜景霓虹 | 爆炸橙 C8 点缀 + 墨黑 C9 暗部 + 英雄蓝 C4 | 夜生活、城市夜景、战斗夜景 |
| G | 爆炸高光 | 爆炸橙 C8 + 英雄红 C5 强光 | 战斗爆发、爆炸特效、灾难场景 |

- **冷暖光分配** — 暖色光（能量金 C5、爆炸橙 C8）适用于英雄、胜利、日常段落；冷色光（英雄蓝 C4 + 暗影紫 C7 + 墨黑 C9）适用于悬疑、压迫、反派段落。导演可根据叙事需要调整冷暖切换点
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述光影方案（A-G）的某一方向，确保视觉一致性

## 三、质感方向

- **硬朗墨线为锚** — 美式超级英雄漫画的核心：硬朗墨线、肌肉线条分明、戏剧性光影、高对比饱和色、速度线与爆炸特效，呈现强烈的漫画力量感画面
- **面容与表情** — 面容硬朗坚毅、方下颌、浓眉锐利、表情戏剧化（愤怒时咬牙、胜利时昂首、坚定时皱眉）。表情是力量感的核心载体
- **体型与肌肉** — 肌肉发达、倒三角体型、肩宽腰窄、肌肉线条分明。英雄角色必须有力量感体型
- **服饰材质** — 衣物布料质感清晰、纹理细节清晰、布料折痕硬朗、衣物随动态飘逸。战斗服/装甲必须有金属质感和发光元件
- **场景材质** — 场景材质纹理清晰、空气透视、使用痕迹、战损灰尘、乱中有序。金属反光、玻璃通透、混凝土纹理、科技装置发光均需在美式漫画风格下清晰呈现
- **漫画不等于扁平** — 美式超级英雄漫画强调在平涂基础上叠加戏剧性光影与漫画分镜感，通过夸张构图与力量感设计放大感染力

## 四、美式漫画场景空间元素

美式超级英雄漫画世界观特有的场景元素及其视觉叙事功能：

- **城市天际线/摩天大楼** — 史诗感的天然载体，英雄在高楼间飞跃/站立 = 力量与责任。低角度仰拍摩天大楼 = 压迫感/英雄登场
- **天空战场/云层** — 宏大战斗的天然舞台，飞行轨迹、爆炸、碎片、能量光束。天空战场 = 史诗级战斗
- **科幻基地/实验室** — 科技感与怪诞感来源，外露电线、发光仪器、复杂按钮、全息投影。装置的科技感与角色的英雄姿态形成对比
- **废墟/灾难现场** — 紧张感与紧迫感来源，倒塌建筑、烟尘、碎片、火光。废墟 = 战斗后果/灾难救援
- **天台/屋顶** — 英雄登场/沉思的经典场景，城市景观为背景，栏杆/水塔/天线。天台 = 英雄独白/登场/对决
- **段落间用场景空镜过渡** — 本风格有丰富的场景资产（不同时段/天候变体），段落衔接建议用场景空镜做情绪缓冲，不要硬切。城市天际线、实验室全景、天空战场均可作为过渡空镜
- **转折点用视觉而非台词** — 优先使用画面手段（光影突变、景别跳切、空镜隐喻、爆炸定格）而非依赖对白解释

## 五、美式漫画配乐与环境音

美式超级英雄漫画世界观下的声音元素约束：

### 配乐乐器选择

- **管弦乐** — 核心乐器，适用范围最广：英雄主题、史诗战斗、胜利时刻、内心挣扎。铜管乐器（小号/长号/圆号）是英雄主题的核心
- **打击乐** — 节奏核心，定音鼓/军鼓/大鼓用于战斗和紧张段落，紧凑鼓点用于追逐/战斗
- **电吉他** — 现代英雄/反英雄主题，失真吉他用于战斗/爆发段落，清音吉他用于都市夜景
- **电子合成器** — 科幻场景/科技感段落的氛围铺底，低频电子pad用于太空/异星
- **钢琴** — 点缀乐器，用于真情流露/回忆/牺牲段落，不做主导
- **合唱** — 高潮/胜利/史诗段落，人声合唱增强宏大感

### 配乐组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 英雄登场/开场 | 铜管乐 + 定音鼓 + 弦乐全奏 |
| 日常/铺垫 | 轻管弦乐 + 钢琴 或 电吉他清音 + 轻鼓组 |
| 悬疑/紧张 | 低频弦乐 + 定音鼓滚奏 + 不和谐铜管 |
| 战斗/爆发 | 铜管乐全奏 + 打击乐全奏 + 失真电吉他 + 弦乐 |
| 胜利/辉煌 | 管弦乐全奏 + 合唱 + 定音鼓 |
| 内心挣扎/悲伤 | 钢琴独奏 + 大提琴 + 轻弦乐 |
| 科幻/太空 | 电子合成器铺底 + 弦乐 + 打击乐 |
| 都市夜景 | 电吉他清音 + 电子氛围音 + 轻鼓组 |

### 美式漫画环境音

- **典型环境音层次** — 城市车流远声 / 爆炸轰鸣声 / 玻璃碎裂声 / 金属撞击声 / 能量光束滋滋声 / 飞行呼啸声 / 人群惊呼声 / 警报声 / 建筑倒塌声 / 风声 / 仪器嗡嗡声
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越丰富，美式漫画场景越有沉浸感
- **夸张音效是漫画核心** — 美式漫画依赖夸张音效（爆炸、撞击、能量光束、飞行呼啸）强化力量感，不要用写实音效替代

## 六、视频生成工作流约束

- **关键帧先行** — 带文字画面（标题、拟声词、标语）必须先生成关键帧图片确认文字准确，再用图生视频
- **角色一致性锚定** — 每段视频prompt必须重复角色核心外观锚点（头盔/发型、服装主色、标志性装备/徽章/披风）
- **分段生成** — 单段不超过15秒，长视频按叙事段落拆分
- **后期合成** — Logo/徽标/标语等品牌元素预留空位后期合成
- **战斗场面** — 必须有速度线、爆炸特效、冲击线等漫画元素；英雄登场用低角度仰拍+放射状背景
