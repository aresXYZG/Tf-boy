# 分镜表美式超级英雄漫画约束 · 漫画风格 · 技法参考

---

## 一、分镜表定位

分镜表是导演将剧本转化为镜头语言的核心工具。以下仅提供美式超级英雄漫画风格在分镜表层面的约束规范。

---

## 二、光影与氛围

- **同场戏光影统一** — 一场戏内不应出现两种以上光影方案，除非有明确的叙事转折（如室内灯光切换→窗外暮色渐深、装置激活→荧光充满房间、爆炸→强光充满画面）
- **情绪色盘绑定** — 每场戏至少绑定 1 个情绪场景（英雄登场/战斗冲突/对峙压迫/灾难救援/胜利时刻/内心挣扎/科幻基地），并在镜头组内保持主色+辅色连续性
- **光源角度规范** — 正给镜头光源默认英雄登场光或戏剧性侧光，侧给镜头根据画面需要调整。描述光影时须区分自然光（窗光/阳光）与人造光（灯光/屏幕光/装置发光/爆炸光）的差异
- **冷暖色调与叙事阶段匹配** — 悬疑/压迫/反派段落严格使用冷色光（英雄蓝 C4 + 暗影紫 C7 + 墨黑 C9），禁用能量金/爆炸橙等暖色调；暖色调（能量金 C5 + 爆炸橙 C8 + 英雄红 C3）仅在英雄、胜利、日常段落使用
- **光影转场是高级手段** — 从窗外自然光渐变到室内暖灯光 = 日转夜的时间流逝；从明亮办公室到昏暗反派巢穴 = 情绪转折；从正常光到爆炸强光 = 战斗爆发。在分镜表中标注光影变化点
- **发光元素是叙事工具** — 科技装置/屏幕/能量核心/武器的发光状态变化（亮→灭、正常→过载、能量充能→释放）可作为叙事信号，在分镜表中标注发光状态变化点

## 三、环境动态

- **环境动态增加画面呼吸感** — 披风飞扬、仪器嗡嗡震动、烟尘弥漫、雨滴滑过玻璃、城市灯光明灭、树叶飘落、电线火花、装置冒泡、能量光束流动、碎片飞散。每 2-3 个镜头至少安排一个有环境动态的镜头，避免画面"死"掉
- **美式漫画环境元素优先** — 环境动态应选用美式超级英雄漫画世界观内的元素：披风飞扬、速度线、爆炸碎片、能量光束流动、烟尘弥漫、外露电线火花、科技装置冒泡、车流光影、雨丝划过玻璃、落叶飘过街道、路灯光晕闪烁、仪器仪表盘指针晃动，禁止出现古风/奇幻元素
- **漫画动态表现** — 环境动态应符合美式漫画的表现方式：速度线的手绘质感、披风飘动的线条美感、爆炸的卡通星形、能量光束的高饱和发光、烟尘的平涂渲染
- **夸张环境动态是力量感工具** — 美式漫画常用夸张环境动态强化力量感：英雄登场时背景线条放射、战斗时速度线充满画面、爆炸时碎片飞散+烟尘弥漫、胜利时披风飞扬+暖光放射。在分镜表中标注此类夸张背景变化

---

## 四、美式漫画人物动作节奏

- **动作要充满力量感** — 美式超级英雄漫画角色的动作应夸张有力，情绪通过大幅度肢体语言和肌肉线条传达。关键动作（出拳、飞行、冲击、落地）标注"夸张"或"力量感"
- **服饰动态** — 美式漫画服饰（披风、大衣下摆、战服飘带）的动态是天然的画面资产，可在画面描述中加入衣物随风/随动作的夸张飘动，增加画面的"活"感和力量感
- **仪态约束** — 美式漫画角色的举止应符合角色性格：英雄挺胸抬头、反派含胸阴狠、战士马步沉稳、普通人紧张蜷缩。不出现标准化的"优雅克制"仪态
- **表情优先于动作** — 以面部戏剧化表情（嘴角弧度、眉毛位置、眼睛大小、嘴巴张合、咬牙程度）传达情绪，表情幅度必须大。肢体动作为表情和力量感服务
- **预备-动作-冲击三段式** — 美式漫画动作遵循经典三段式：预备（蓄力/表情变化/肌肉绷紧）→ 动作（大幅度执行/速度线/能量聚集）→ 冲击（定格/爆炸/碎片飞散/夸张后果）。在分镜表中拆解动作时遵循此节奏
- **慢动作的戏剧功能** — 升格在美式漫画中用于"关键瞬间"：英雄登场、重拳命中、爆炸前一刻、披风飞扬、能量释放——慢动作让观众有足够时间感受力量感和戏剧张力，冲击力在慢动作中积蓄
- **英雄姿态库** — 经典英雄姿态：双手叉腰站立、单手叉腰另一手指向、双臂交叉胸前、单膝落地、空中飞行、重拳出击、盾牌防御、披风飞扬站立。在分镜表中根据情绪选择合适的英雄姿态

## 五、运镜禁忌

- **运镜要服务于力量感和戏剧节奏** — 美式漫画运镜可以比其他风格更灵活，但必须服务于力量感和情绪表达
- **低角度仰拍 = 英雄登场/力量感** — 英雄登场、胜利时刻、高大建筑/反派，用低角度仰拍强化力量感和压迫感。这是美式漫画中最高频的运镜之一
- **高角度俯拍 = 灾难/渺小/战场全貌** — 灾难场景、战场全貌、角色渺小感，用高角度俯拍。展示全局混乱和史诗规模
- **急推 = 反应放大/情绪爆发** — 某个角色听到/看到关键信息，快速推向其面部，放大"震惊/愤怒/坚定"的反应。强化情绪冲击力
- **甩镜 = 信息揭示/战斗切换** — 从角色A迅速甩到角色B/爆炸现场/敌人，速度本身带有"等等！那是什么？！"的紧张感
- **跟随 = 飞行/追逐/战斗** — 英雄飞行、追逐戏、战斗移动，用跟随运镜，保持角色在画面中心，背景流动
- **Dutch角 = 紧张/不安/怪诞** — 倾斜构图用于紧张场景、不安情绪、反派视角、精神异常。美式漫画常用Dutch角强化戏剧张力
- **固定 = 冷静旁观/对话/铺垫** — 对话场景、铺垫段落、日常场景用固定机位，稳定感
- **运镜即节奏** — 低角度仰拍 = 英雄/力量；高角度俯拍 = 灾难/全貌；急推 = 情绪爆发；甩镜 = 信息揭示；跟随 = 飞行/追逐；Dutch角 = 紧张/不安；固定 = 冷静/对话
- **不要过度运镜** — 战斗和英雄段落可以灵活运镜，但对话和日常段落保持稳定。运镜过多会分散对角色和力量感的注意力

## 六、转场设计

- **硬切为主** — 美式漫画场景内剪辑节奏偏快，硬切为主，不拖泥带水
- **英雄登场转场** — 从普通人视角/日常场景硬切到英雄低角度仰拍登场，反差本身就是戏剧效果
- **爆炸/冲击转场** — 用爆炸强光/冲击线做画面过渡，从一个场景硬切到另一个场景，强化战斗节奏
- **速度线转场** — 用速度线/冲击线做画面过渡，强化美式漫画的漫画感和动感
- **表情定格转场** — 角色戏剧化表情定格1-2帧后切下一镜，利用表情的冲击力做转场
- **假正经转场** — 用正式/庄重的转场方式（淡入淡出、字幕卡"Meanwhile"、光圈转场）来过渡英雄/战斗内容，反差出戏剧感
- **反差蒙太奇** — 英雄口述的"美好计划"与实际执行的"灾难现场"交替剪辑，理想vs现实的反差构成持续戏剧效果
- **打破第四面墙** — 角色突然看向镜头/对观众说话的瞬间用正面近景+突然静止，制造"你看到了吧？"的共谋感

## 七、文字画面处理

- **带文字画面必须关键帧先行** — 标题、拟声词（POW/BAM/WHAM）、口诀、标语、招牌、屏幕显示等带文字画面，必须先生成关键帧图片确认文字准确，再用图生视频
- **关键帧作为参考图** — 生成的关键帧图片作为图生视频的参考图传入，文字准确性由关键帧保障
- **视频prompt仍需描述文字** — 视频prompt中仍需描述文字内容和位置，但不依赖视频模型直接生成文字
- **拟声词是美式漫画核心** — POW/BAM/WHAM/KAPOW等拟声词是美式漫画的标志性元素，战斗场面建议加入拟声词。拟声词必须先生成关键帧确认文字准确
- **品牌元素后期合成** — Logo/徽标/官方标语等品牌元素建议在视频中预留空位，后期合成（AI直接画品牌物易乱码）
- **画内文字 vs 画外文字** — 故事世界内的道具文字（拟声词、招牌、屏幕、海报、标语）属于画内文字，应如实描写；字幕、水印、标题卡、旁白叠字属于画外文字，严禁出现
