# 人物衍生资产生成 · 约束手册

---

## 一、叠加原则

1. **面容不变** — 叠加后五官必须与底模完全一致，禁止面容偏移
2. **姿态不变** — 保持底模自然站立姿态，禁止任何姿态/动作/体态变化
3. **逐层可控** — 每层独立描述，便于按层替换（换装不换妆）
4. **风格统一** — 所有服化元素服从同一美学体系
5. **质感不降** — 叠加后质感标准不低于底模
6. **纯服化范畴** — 仅叠加妆容/发型/服饰/配饰，禁止引入道具、场景、环境、动作

---

## 二、叠加层级

| 层级 | 内容 | 说明 |
|---|---|---|
| L0 | 底模 | 基础形象底模，不修改 |
| L1 | 妆容（决策层） | 先分析用户线索，再决策「基础妆 / 轻妆 / 正式妆」强度 |
| L2 | 发型造型 | 发髻/束发/编发 + 发饰 |
| L3 | 中衣/内搭 | 替换白色基础中衣 |
| L4 | 外衣/主服 | 古风华服/礼服/常服等 |
| L5 | 配饰 | 头饰/耳饰/项饰/腰饰/手饰 |

> **范畴边界**：人物衍生资产仅包含 L0–L5 层级（服化妆造），不包含道具（伞/剑/扇/书/灯笼等手持物）、场景环境（室内/室外/天气等）、姿态动作（行走/回眸/举手等）。这些属于其他资产类型的范畴。

## 三、妆容约束（L1）

### 底模到衍生妆造策略（关键）

> 角色底模虽为素颜，但衍生资产默认进入妆造流程。系统应根据用户提供的线索分析妆造需求，并在基础妆、轻妆、正式妆之间决策强度，而不是保持素颜。

### L1 线索分析与妆容决策

| 步骤 | 处理内容 | 决策结果 |
|---|---|---|
| S1 | 提取用户线索：面部状态词、情绪词、强度词 | 形成妆容需求摘要 |
| S2 | 过滤非妆容线索：道具/场景/动作/姿态词不作为上妆依据 | 防止误判 |
| S3 | 匹配妆容风格矩阵并给出强度档 | 基础妆 / 轻妆 / 正式妆 |
| S4 | 生成最终 L1 提示词 | 只输出结论，不输出分析过程 |

### 线索到妆容映射（执行口径）

| 线索类型 | 典型线索 | L1 决策 |
|---|---|---|
| 无明显面部强调线索 | 仅服饰/发型变化，未强调情绪与状态 | 基础妆 |
| 轻微面部线索 | 轻柔、含笑、睫毛轻颤、气色微提 | 轻妆（极淡） |
| 明确日常线索 | 日常、外出、休闲 | 基础妆（自然清透） |
| 明确正式仪式线索 | 大婚、典礼、重要场合 | 正式妆（精致华贵） |

> 判定原则：所有衍生资产都要有妆造；先看面部线索决定强度与风格，道具、场景、姿态变化不得单独抬高妆容强度。

## 七、四视图设定图规范（通用无头素体与双参考图融合版）

### 视图定义
| 位置 | 视图 | 角度 | 景别 | 要求 | 提示词 |
|---|---|---|---|---|---|
| 左一 | 人像超大特写 | 正面平视 | 头顶至锁骨 | 从头顶到锁骨完整展示不裁切，面部占60%+，锁定高精五官细节与神态 | `portrait closeup`, `face detail`, `ultra detailed face` |
| 左二 | 正视图全身（无头素体） | 正面 0° | 颈部以下至脚底 | 面对镜头、双臂自然、从颈部以下到脚底完整展示，**颈部以上完全留空不画头部**，展示体型与服装 | `front view`, `headless body`, `full body neck to toe` |
| 右二 | 侧视图全身（无头素体） | 右侧 90° | 颈部以下至脚底 | 纯侧面轮廓、从颈部以下到脚底完整展示，**颈部以上完全留空不画头部**，展示体态与侧缝细节 | `side view`, `headless body`, `profile neck to toe` |
| 右一 | 后视图全身（完整后背与后脑） | 后方 180° | 全身立像 | 后脑发型、发尾、背部服装与脚底完整清晰展示 | `back view`, `rear view`, `full body head to toe` |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面从左至右并排四视图（左一人像特写 + 左二正视图无头素体 + 右二侧视图无头素体 + 右一后视图全身） |
| 背景 | 纯净中性灰 `#808080` 或风格适配纯色背景 |
| 站姿 | 自然站立、双脚平行微分、双臂自然下垂或微展 |
| 素体约束 | 左二与右二必须为无头素体（颈部以上截断留空），强制AI在特征提取时仅锁定左一人像特写，杜绝小脸特征干扰与冲突 |
| 特写展示 | 人像特写必须从头顶到锁骨完整入画，严禁裁切头顶 |
| 双参考图融合机制 | 支持从人脸参考图资产库按【人种+性别】匹配抽取两张真人参考图：**图2为主导（70%五官结构与神韵）**，**图1为辅助（30%骨相立体感与肌理质感）**，生成全新原创面孔，严禁机械克隆 |
| 全年龄动态适配 | 若参考底图与角色设定存在年龄差异，由提示词动态注入年龄修饰词（少年/青年/中年/老年），模型自动呈现对应年龄段的真实皮肤质感与面部沧桑/年轻特征 |
| 光线 | 均匀柔光，前方主光 + 双侧补光，自然阴影 |
| 画面比例 | 建议 4:1 或 3:1 |
