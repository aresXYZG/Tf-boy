# 竖屏超短剧 · 导演规划覆盖规则

> 本文件不是替代通用导演规划，而是 `vertical_episode` 的内容形态覆盖层。与通用规则冲突时，以本文件对时长、分集和竖屏节奏的具体规定为准。

## 形态定位

- 目标是竖屏短剧单集，默认约 55 秒；若项目配置已由剧本 Agent 推断出其他时长，以项目配置为准。
- 导演规划仍按剧情片方法拆场：地点/时间/戏剧单元发生变化时切场。
- 角色、场景、道具按工作区真实资产引用；不得因为竖屏节奏快而省略剧本中的关键角色和关键动作。

## 时长与节奏

- 先按项目配置核算单集时长，再按事件密度分配，不硬套固定镜头数量。
- 单集必须具备：开场抓人、冲突推进、信息/情绪兑现、集末悬念或付费卡点（以项目配置与剧本为准）。
- 付费卡点只记录在剧情节奏和场尾注意事项中，不改写剧本台词，不凭空增加情节。
- 同一场内优先保留动作连续性，避免为了快切造成空间关系和因果断裂。

## 输出侧重点

- 分场汇总表必须标出每场在单集中的功能：承接、升级、兑现或卡点前置。
- 逐场注意事项优先记录竖屏画面中必须被看见的冲突动作、表情反应和视觉信息。
- 场间过渡从简；若硬切更利于停留与节奏，则不增补过场。
