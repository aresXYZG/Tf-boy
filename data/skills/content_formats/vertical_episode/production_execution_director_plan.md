# 竖屏超短剧 · 导演规划覆盖规则

> 本文件只在项目 `contentFormat=vertical_episode` 时加载。它补充短剧商业与竖屏节奏，不替代通用导演规划，也不修改通用资产、台词和 XML 契约。

## 形态定位

- 目标是竖屏短剧单集，画幅和单集时长优先读取项目配置；没有配置时才使用项目默认值。
- 第一优先级是“单集局面发生变化”，第二优先级是停留与追看；每集至少完成目标推进、关系变化、信息揭示、危机升级或阶段性兑现中的一项。
- 短剧可以使用集末自然钩子和付费点，但只在项目配置启用、且原剧情提供真实节点时使用。

## 单集导演规划

- 场次汇总中标注每场功能：入局、目标建立、阻碍、行动、反击、兑现、余波或钩子前置。
- 前段优先安排本集核心异常/冲突/目标，但不为“前三秒”凭空添加剧情。
- 场尾记录真实落点：主角下一步行动、对手新动作、关系变化、信息缺口或规则后果；本集已经完成的局部问题不能被无理由抹掉。
- 付费点若启用，记录“剧情节点 + 已兑现内容 + 新问题”，不只写“戛然而止”。
- 投流素材点若启用，只从原剧情中标记可剪高光，不把它当作必须新增的剧情。

## 竖屏视觉注意事项

- 关键人物反应、手机/屏幕、核心道具和动作落点优先放在竖屏有效区域。
- 近景、中近景和特写可优先使用；需要交代空间时用短而必要的全景，不能因竖屏而破坏人物动线。
- 同一场内动作、视线和关系距离保持连续，避免为快切丢失因果。

## 时长与片段

- 单集总时长、台词容量和语速以项目配置或骨架推导为准。
- 每个 Track `≤15秒`，镜头拆分服从通用分镜表；不要把一次连续动作拆成互相跳跃的碎镜。
- 单集可以有“开场抓人 → 行动推进 → 阻碍/代价 → 阶段性兑现 → 新问题”，但不强制每集都出现打脸、反转或爽点。

## 输出补充

在通用分场汇总和注意事项中追加：

```markdown
### 竖屏单集节奏
- 本集功能：入局/发展/升级/兑现/余波/钩子前置
- 核心情绪或观看抓手：
- 可视进展：
- 阶段性兑现：
- 自然集末落点：
- 付费点：无/按项目配置的真实剧情节点
- 投流高光：无/原剧情高光
```
