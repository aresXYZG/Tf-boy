# 知识科普解说 · 分镜表覆盖规则

> 本文件是 `explainer_video` 的制作阶段覆盖层，不替代通用分镜表。通用层负责 Track、时长、台词/VO 原文、资产 ID、空间连续性、音效和 XML 契约；本层负责确保每个画面真正服务知识理解，而不是只做装饰性 B-roll。

## 一、分镜第一原则

- **先让观众看见问题，再让 VO 用证据和因果完成解释。** 画面可以有趣，但不得与 VO 的事实、因果或边界冲突。
- VO 是主要时间轴；画面是 VO 的视觉转译与证据承载，不是自动复述，也不是脱离内容的奇观。
- 本期可以无角色。固定主角、实验对象、历史人物、概念形象只有在能降低理解成本时才使用，不为“有戏”强行造角色或游客团。
- 镜头顺序服从 script skeleton / adaptation 已确定的知识结构，按功能需要灵活排布，不预设固定套路顺序。

## 二、知识主张到分镜的绑定

每条核心知识镜头必须能回答以下问题，并将答案写入对应字段（若当前表格无独立字段，则写入“画面描述”末句或“备注”，保持现有表格接口不变）：

- **主张/知识点**：这一镜对应哪条 Claim Chain（如 C1）。
- **视觉功能**：画面是在展示现象、解释机制、呈现证据、做尺度/时间/空间对比、提示边界，还是回收结论？
- **视觉事件**：画面中正在发生的一个主要可见动作或状态变化是什么？
- **证据落点**：画面或 VO 使用的是原文事实、实验、数据、历史记录、案例，还是“未提供”。

推荐在画面描述中采用：

```text
[对应 C1][视觉功能：展示现象/解释机制/呈现证据/对比/结论回收] 主体正在发生的具体动作；该动作让观众看见……
```

- 不能只写“展示原理”“体现复杂”“突出重点”“画面很震撼”。必须写清“谁/什么在何处做什么”，以及“这证明了什么”。
- 一镜只承担一个主要视觉事件；一条 VO 可因语义停顿拆成多镜，但拆镜后每镜必须有独立信息功能，不能只是换角度重复同一静帧。
- 一条视觉事件不能证明超出它实际呈现范围的结论；类比镜必须在描述或备注中标注“类比”，不能伪装成真实实验/真实机制。

## 三、视觉转译决策顺序

根据主张选择最能降低理解成本的方式，按以下优先顺序判断，不得默认拟人化：

| 知识内容 | 首选视觉方式 | 可拍事件示例 |
|---|---|---|
| 可观察现象 | 真实场景/对象动作 | 同一对象在两个条件下发生可见差异 |
| 因果机制 | 物理过程/连续动作 | 颗粒碰撞、液体流动、结构开合、路径改变 |
| 流程/方法 | 步骤动作/装配过程 | 输入进入第一步，依次经过处理并产出结果 |
| 微观过程 | 微观模型/有限拟人化 | 只表现材料明确的粒子/细胞/分子过程 |
| 数据关系 | 数量、尺度、时间、空间具象化 | 柱体高度变化、队列长度变化、时间牌推进 |
| 历史/事件 | 场景重演/人物决策 | 关键人物在材料明确的情境中作出选择并引发后果 |
| 抽象关系 | 生活类比/空间关系 | 两组物体按规则移动、连接或分离 |

- 拟人化是可选表达。使用时锁定“概念 → 固定形象 → 固定道具 → 核心动作”，同一概念跨镜头不得随意换形象。
- 画面不得凭空添加材料未提供的实验结果、数据、年份、人物行为或因果关系。
- 数据图形、屏幕文字和标签若确有必要，遵守通用层文字规则；不要用不可读的小字堆满画面。精确数据应由 VO 或后期文字层承担，画面只做清晰的数量/尺度关系。

## 四、VO、画面与音效的分工

- **VO**：负责概念定义、因果推导、证据说明、条件限制和结论回收；保持大白话，但不能为了幽默删掉必要限定词。
- **画面**：负责让观众看见现象、动作、变化、证据形态和变量关系；可以补充 VO 未明说但不矛盾的空间信息。
- **音效**：只服务可见事件，例如翻页、计数、碰撞、滴答、装配、脚步；不得让声音单独承担知识证据。
- 关键结论前可留 `0.3~0.8秒` 的视觉停顿，但只在不破坏 VO 语义和 Track 时长时使用。
- 连续 `2~4` 个高信息镜头后，可安排一个不新增知识的视觉缓冲；这是软规则，不固定每 30 秒安排梗，也不要求缓冲必须幽默。

## 五、通用字段的科普填写要求

- `scene`：写当前知识段的实际场景，如实验台、街道、历史地点、微观模型空间、数据演示空间；不默认写“谜题世界”。
- `action`：写正在发生的物理动作链；无角色时写对象变化，不写抽象心理。
- `emotion`：若内容没有人物情绪，写“平静说明”“紧张验证”“惊讶发现”等可感基调，不为科普强加戏剧性情绪。
- `lines`：VO/台词按原剧本逐字保留，不因科普格式删改、合并或替换限定词。
- `sound`：仅写环境音/动作音，禁止用音乐或配乐推动理解。
- `associateAssetsNames` / `associateAssetsIds`：只引用画面中实际可见且工作区真实存在的资产；没有角色时可以只绑定场景/道具，不能编造 ID。
- 不把镜头运动当成知识证据；运镜只负责引导注意力，`视觉功能`必须由画面主体的动作/变化承担。

## 六、分组与时长

- 每个 Track 仍遵守通用层 `≤15秒`；Track 是生成批次，不是知识逻辑单元。
- 按 VO 语义、信息功能和动作连续性切分；不得为了凑 15 秒拆断“现象 → 机制 → 结论”中的关键一步。
- 单镜时长服从通用分镜表及项目配置；科普语速只用于估算，不覆盖项目配置。单镜 VO 超载时按语义拆镜，不平均切割。
- 不为填满目标时长增加无关梗、重复解释或既无材料支持又未标注“假设/思想实验”的极端推演。

## 七、资产与一致性边界

- 固定主角团（若项目已有）沿用真实资产名称和 ID，可作为观察者、提问者、实验参与者或尺度参照；身份变化不等于新建资产。
- 本期知识角色只引用工作区已有资产；分镜表阶段不得创建基础资产，不得编造名称或 ID。
- 稳定且跨多个镜头复用的整体形态变化才考虑衍生资产；瞬时表情、局部变化和说明性颜色标记由画面描述承担。
- 资产绑定可为后续生成提供复用线索，但不要在分镜阶段宣称后续参考链路必然保证一致性；最终效果取决于实际生成模式与参考图传递。

## 八、完成前自检

逐镜检查：

1. 该镜对应哪条主张/认知段？若无法回答，删掉或合并。
2. 视觉事件是什么？是否只有一个主要事件？
3. 视觉功能是什么？它证明/解释/对比了什么？
4. 画面是否与 VO 事实、因果和边界一致？类比是否明确标注？
5. 是否添加了输入材料未提供的数字、年份、实验结果、人物行为或结论？
6. 是否保留全部 VO/台词原文、真实资产 ID、Track ≤15秒和通用禁用项？
7. 是否在高密度段后适度安排了无新增知识的视觉缓冲，而没有机械凑梗？

## 九、适用边界说明

本文件只在项目 `contentFormat=explainer_video` 时加载，其他形态不会读取本文件。
