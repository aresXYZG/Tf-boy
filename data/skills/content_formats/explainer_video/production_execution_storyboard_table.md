# 趣味科普解说 · 分镜表覆盖规则

> 科普解说可以使用角色资产。分镜阶段只引用真实资产，但必须区分“固定主角团复用”和“本期知识角色”两类角色。

## 角色资产引用规则

- **固定主角团**：使用项目选定的同一角色资产名称和 ID。跨故事、跨场景、跨镜头保持身份、基础外观和识别特征稳定；他们本期穿什么/站在哪里由剧本和画面描述决定，但不能换成另一张角色卡。
- **本期知识角色**：如红眼睛居民、蓝眼睛居民、岛上居民、游客以外的谜题参与者。优先引用项目资产库已有角色；没有才在资产阶段建立本期基础资产。分镜表阶段禁止临时创建基础资产。
- **身份与资产分离**：固定主角扮演“游客”是本期身份，不产生新游客资产；红眼睛/蓝眼睛是本期谜题身份，除非剧本明确要求固定主角承担该状态，否则不要把该状态覆盖到固定主角基础卡。
- **角色复用标记**：每个场头/片段的“引用资产名称/ID”中，固定主角沿用同一 ID；备注可写“固定主角团·跨故事复用”或“本期知识角色·仅本期”。
- **身份状态的实现**：若眼睛颜色、制服、徽章等是稳定且跨多个镜头的整体视觉状态，可引用对应衍生资产；若只是某一镜的局部特写/瞬时变化，用画面描述和 prompt 表达，不新建衍生。

## 解说分镜结构

- 以 VO 为主轴，但允许固定主角通过提问、观察、指认、走位、困惑和验证动作参与镜头。
- 每个片段至少明确三项：`VO/台词`、`画面动作`、`运镜与动态`。VO 负责谜题规则、推理链和结论；画面负责把逻辑变成可见的角色行动、标记、队列、日期变化或空间关系。
- 长 VO 按语义停顿拆镜；固定主角可以作为无台词反应镜承接 VO，不必为每个逻辑步骤硬写对白。
- 一镜一个主要视觉事件：游客团观察居民、居民按眼睛颜色分组、日期牌推进、某一组人作出选择等，避免把整段逻辑塞进一张静态图。

## “红眼睛与蓝眼睛”类谜题的可视化方法

- 用固定主角团作为镜头锚点：游客团站在群体边缘观察、提出问题或记录日期，始终保持同一角色资产。
- 用本期知识角色呈现群体规则：红眼睛居民和蓝眼睛居民按身份分组，颜色是明确视觉符号；不要让所有居民都长成固定主角。
- 用可拍的物理事件表现递归推理：第一天公开宣告、居民互相观察、日期牌逐日翻动、对应颜色群体同步做出选择。推理链由 VO 解释，画面给观众看“谁看见了谁、谁缺少哪条公共信息”。
- 颜色信息必须服务谜题逻辑：红/蓝只作为角色识别和推理条件，不把颜色扩展成无依据的超自然特效。

## 音画与节奏

- 语义转折（“但是”“如果”“直到有人公开说出”）优先切镜；关键结论前留 0.3-0.8 秒，让观众先看见反应再听结论。
- 机制解释段采用“固定主角反应镜 + 群体示意镜 + 具体日期/动作镜”交替，避免连续口播配同一张角色站立图。
- 视觉梗可以来自固定主角的正常反应（游客团集体记笔记、有人把日期牌翻错又默默翻回），不靠硬拗对白。
- 环境音和拟音服务可见事件：脚步、纸笔、翻牌、集体停步、门锁、沙滩风声；不要让声音替代画面中的逻辑证据。

## 跨故事连续性检查

- 检查固定主角是否在每个需要他们的故事中使用同一资产 ID。
- 检查本期知识角色是否与固定主角区分，是否误把上一故事的身份状态带入下一故事。
- 检查同一固定主角在故事间的身份变化是否由剧本明确，而非资产卡被重建。
- 检查分镜表中每个资产 ID 都存在于工作区，缺失时只保留真实名称/画面需求，不编造 ID。
